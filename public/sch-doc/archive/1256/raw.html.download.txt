        function handleLinkClick(event, type) {
            event = event || window.event;
            var target = event.target || event.srcElement;

            var link = findClosestLink(target);
            if (link) {
                var href = link.getAttribute('href');
                var label = link.textContent.trim();

                gaTrackerOutboundLink({ eventCategory: type, eventAction: 'click', eventLabel: label });
            }
        }

        function findClosestLink(element) {
            while (element && element.nodeName !== 'A') {
                element = element.parentNode;
            }
            if (element) {
                return element;
            }
            return null;
        }
        document.addEventListener('DOMContentLoaded', function () {
            const topNavSearch = document.getElementById('top-nav-search');
            const searchCancel = document.querySelector('.search-cancel');
            const searchInput = document.querySelector('.search-input');
            const realQuery = document.querySelector('.realQuery');
            const searchForm = document.querySelector('.site-search');

            // 点击搜索图标：显示输入框（添加 active 类）
            if (topNavSearch) {
                topNavSearch.addEventListener('click', function (event) {
                    event.stopPropagation();
                    document.querySelector('.top-nav-wrapper').classList.add('active');
                    searchInput.focus();
                });
            }

            // 点击取消按钮：移除 active 类
            if (searchCancel) {
                searchCancel.addEventListener('click', function (event) {
                    document.querySelector('.top-nav-wrapper').classList.remove('active');
                });
            }

            // 点击文档其他地方：移除 active 类
            document.addEventListener('click', function (event) {
                const wrapper = document.querySelector('.top-nav-wrapper');
                if (wrapper && !wrapper.contains(event.target)) {
                    wrapper.classList.remove('active');
                }
            });

            // 提交表单前处理搜索词
            if (searchForm) {
                searchForm.addEventListener('submit', function (e) {
                    e.preventDefault(); // 阻止默认提交

                    const val = searchInput.value.trim();

                    if (!val) {
                        alert("请输入关键词");
                        return;
                    }

                    // 设置 realQuery 的值为关键词 + site:xxx
                    realQuery.value = val + ' site:yz.chsi.com.cn';

                    // 手动提交表单
                    searchForm.submit();
                });
            }
        });

<p>2026年东南大学坚持服务战略、按需招生、全面衡量、择优录取和宁缺毋滥的原则，拟招收全日制攻读硕士学位研究生（包括学术学位和专业学位）和非全日制攻读硕士专业学位研究生共计6500名左右（最终以教育部正式下达的招生计划文件为准），其中拟招收校内外推荐免试生3000名左右（最终以在“全国推荐免试攻读研究生（免初试、转段）信息公开暨管理服务系统”（网址：https://yz.chsi.com.cn/tm，以下简称推免服务系统）接收的推荐免试硕士生人数为准）。</p><p>我校学术学位各专业只招收全日制硕士生，部分专业学位类别（领域）可招收非全日制硕士生。各招生专业见《东南大学2026年硕士研究生考试招生专业一览表》，具体详见《东南大学2026年硕士研究生考试招生专业目录及参考书目》（以下简称招生目录）。</p><p>原则上我校全日制硕士生均按“非定向就业”类别录取（部分专项计划除外），非全日制硕士生均按“定向就业”类别录取。</p><p>一、报考条件</p><p>（一）中华人民共和国公民。</p><p>（二）拥护中国共产党的领导，遵纪守法，品德良好。</p><p>（三）身体健康状况符合国家规定的体检要求。</p><p>（四）考生学业水平须符合下列条件之一：</p><p>1.国家承认学历的应届本科毕业生（含普通高校、成人高校、普通高校举办的成人高等学历教育等应届本科毕业生）及自学考试和网络教育届时可毕业本科生。</p><p>2.具有国家承认的本科毕业学历的人员。</p><p>3.获得国家承认的高职（专科）毕业学历后满2年及以上人员（毕业后到录取当年入学前，下同）或国家承认学历的本科结业生，且符合以下条件，可按本科毕业同等学力身份报考：</p><p>（1）提供由大学教务部门出具的本科专业全部必修课程学习证明及成绩单；</p><p>（2）参加全国大学英语四级考试取得合格证书或成绩在425分及以上；或进修过满2年（4个学期）的本科英语课程，成绩合格（须由所进修的高校教务处出具本科成绩证明原件）；</p><p>（3）以第一作者在核心期刊发表过与报考专业相关的学术论文。</p><p>4.已获硕士、博士研究生学历或学位的人员。</p><p>（五）报考035102法律（法学）专业学位的，须符合（一）（二）（三）（四）项要求，且报考前所学专业为法学专业（获得法学第二学士学位的人员可报考）。</p><p>报考035101法律（非法学）专业学位的，须符合（一）（二）（三）（四）项要求，且报考前所学专业须为非法学专业。</p><p>（六）报考医学类招生专业的，须符合（一）（二）（三）（四）项要求，且须满足招生目录中的备注要求，报考前请注意查看招生目录。</p><p>（七）报考125100工商管理、125200公共管理、125601工程管理专业学位的，须符合（一）（二）（三）项要求，且须符合下列条件之一：本科毕业后有3年以上工作经验；或获得国家承认的高职（专科）毕业学历或本科结业后，达到本科毕业同等学力并有5年以上工作经验；或获得硕士、博士研究生学历或学位后有2年以上工作经验。学习方式为“非全日制”，报考类别为“定向就业”。</p><p>125100工商管理硕士专业学位研究生相关考试招生政策同时按照《教育部关于进一步规范工商管理硕士专业学位研究生教育的意见》（教研〔2016〕2号）有关规定执行。</p><p>2027年招生起，125604物流工程与管理也须符合第（七）项要求。</p><p>（八）我校部分全日制专业接受退役大学生士兵计划（以下简称士兵计划）的考生报考，详见招生目录中的备注要求，未明确备注接受士兵计划报考的专业，不接受士兵计划报考。高校学生应征入伍退出现役且符合硕士研究生报考条件，可以申请报考（高校学生指全日制普通本专科（含高职）、研究生、第二学士学位的应（往）届毕业生、在校生和入学新生，以及成人高校招收的普通本专科（含高职）应（往）届毕业生、在校生和入学新生，下同）。报考士兵计划的考生，不再享受初试加分政策，且须在复试前向我校提供《入伍批准书》和《退出现役证》（限士兵）进行复核。</p><p>（九）现役军人报考须按军队相关部门及教育部文件规定执行。强军计划考生限报考我校部分专业，强军计划考生必须参加全国统一入学考试，复试分数线单独划定。报考类别为“定向就业”。</p><p>（十）我校理、工、医类全日制专业接受少数民族高层次骨干计划（以下简称少民计划）的考生报考，考生须符合少民计划报考条件，且报名时须如实填写少数民族身份及定向就业少数民族地区。报考少民计划的考生，不再享受初试加分、少数民族照顾政策。</p><p>（十一）东南大学-蒙纳士大学苏州联合研究生院、东南大学雷恩研究生学院均不接受强军计划、少民计划、士兵计划等专项计划的考生报考。该两个单位的硕士研究生招生简章另行公布。</p><p>二、报名</p><p>（一）报名包括网上报名和网上确认两个阶段。所有考生均须在规定时间内参加网上报名和网上确认，积极配合签署《考生诚信考试承诺书》并遵守相关约定，认真核对并确认本人报名信息，根据核验工作要求提交补充材料，逾期不得补办。在读研究生报考须在报名前征得所在培养单位同意。</p><p>网上报名时间为2025年10月16日至10月27日（网上预报名时间为2025年10月10日至10月13日），每日9:00～22:00。考生应在规定时间内登录“中国研究生招生信息网”（网址：https：//yz.chsi.com.cn，以下简称研招网）浏览报考须知，并按教育部、省级教育招生考试机构、报考点以及东南大学网上公告的要求报名。</p><p>（二）考生网上报名前应认真了解并严格按照报考条件及相关政策要求选择志愿。报名时应按要求如实填写并提供真实材料。因不符合报考条件及相关政策要求，或因网报信息填写错误、填报虚假信息而造成后续不能网上确认、考试（含初试、复试）或录取的，后果由考生本人承担。</p><p>（三）应届本科毕业生应选择就读学校所在地省级教育招生考试机构指定的报考点，其中成人高校应届本科毕业生也可选择教学点所在地省级教育招生考试机构指定的报考点；强军计划考生须选择东南大学报考点（3202）；初试科目第四门为910建筑设计基础、911风景园林设计基础的考生，须选择东南大学报考点（3202）；其他考生应选择工作或户籍所在地省级教育招生考试机构指定的报考点。</p><p>（四）残疾考生如需组考单位在考试期间提供合理考试便利服务，应于报名阶段与报考点所在地省级招生考试机构和招生单位沟通申请，以便提前做好安排。</p><p>（五）报名期间将对考生学历（学籍）信息进行网上校验，考生可上网查看学历（学籍）校验结果。考生也可在报名前或报名期间自行登录研招网查询本人学历（学籍）信息。未能通过学历（学籍）网上校验的考生应在复试前完成学历（学籍）核验。</p><p>（六）网上确认时间由各省级教育招生考试机构根据国家招生工作安排和本地区报考组织情况自行确定和公布，具体确认工作由相关报考点组织实施。考生网上报名成功后，应定期查阅省级教育招生考试机构、报考点、东南大学官方网站等，主动了解网上确认、考试安排及注意事项等，积极配合完成相关工作。</p><p>（七）选择在东南大学报考点（3202）参加初试的考生，须严格按照东南大学报考点公告的要求执行；选择在其他报考点参加初试的考生，须按照所选报考点公告的要求执行。</p><p>（八）根据相关规定，我校和报考点对考生报考信息和网上确认材料进行全面、认真审核，确定考生的考试资格。考生填报的报名信息与报考条件不符的，不予考试、录取，随时发现、随时处理。</p><p>（九）符合享受初试加分、少数民族照顾政策、免初试或报考专项计划有关条件的考生，须在网上报名时按要求填报申请信息。未按规定申报或审核（含复审）未通过的，不享受相应的加分、照顾、免初试政策，或不得参加有关专项计划初、复试。</p><p>（十）具有推荐免试资格的考生，须在国家规定时间内登录推免服务系统填报志愿并完成规定流程。已被录取的推免生，不得再报名参加当年硕士研究生招生考试。</p><p>符合免初试资格（服役期间获得三等战功、二等功以上奖励或者二级以上表彰，符合全国硕士研究生招生考试报考条件的退役人员）的考生，应在教育部规定的全国统考报名时间内登录推免服务系统报名，逾期不得补报。</p><p>三、初试</p><p>（一）考生在考前十天左右，凭网报用户名和密码登录中国研招网自行下载打印《准考证》。《准考证》使用A4幅面白纸打印，正、反两面在使用期间不得涂改或书写。考生凭下载打印的《准考证》及有效居民身份证参加初试。</p><p>（二）初试方式均为笔试。初试时间按国家教育部统一规定，于2025年12月20日至21日进行。</p><p>四、复试</p><p>（一）根据教育部相关文件精神，结合我校实际情况，确定并公布考生进入复试的初试成绩要求等，考生须达到报考院（系、所）专业/方向复试要求才能参加复试，复试不合格者不予录取。</p><p>（二）我校实行差额复试，差额比例一般不低于120%，合格生源比例不足的，按实际合格生源数组织复试。</p><p>（三）我校将按照教育部有关规定制订学校复试录取工作办法和各院（系、所）复试录取工作细则，提前在学校网站向社会公布并严格执行。工商管理、公共管理、工程管理、会计等专业学位的思想政治理论考试在复试中组织，成绩计入复试总成绩。外国语听力及口语测试均在复试中进行，成绩计入复试总成绩。</p><p>（四）以同等学力身份报考并参加复试的考生，在复试中须加试至少两门与报考专业相关的本科主干课程，加试方式为笔试，加试科目及要求将在复试录取工作细则中另行通知，加试不合格者不予录取。</p><p>（五）我校在复试前严格采取人证识别、相关信息库数据比对等措施，加强对考生的身份审核及报考专项计划、申请享受初试加分或少数民族照顾政策等资格的复审。对不符合规定条件者，不予复试。</p><p>（六）我校在复试期间加强复试过程管理和监督。采取随机选定考生次序、随机确定复试工作组成人员、随机抽取复试试题等措施，复试过程全程录像，选派专门人员到复试现场巡视，确保公平公正。考生应自觉遵守我校考场规则及考生所签署的《考生诚信考试承诺书》等内容，在我校复试工作结束前不得对外透露或传播复试试题内容等有关情况。</p><p>（七）考生体检工作在考生拟录取后组织进行，具体时间另行通知。我校体检标准根据《中华人民共和国残疾人教育条例》和《教育部办公厅 卫生部办公厅关于普通高等学校招生学生入学身体检查取消乙肝项目检测有关问题的通知》（教学厅〔2010〕2号）等文件规定，参照教育部、卫生部、中国残联印发的《普通高等学校招生体检工作指导意见》（教学〔2003〕3号）要求执行。</p><p>五、调剂</p><p>我校在第一志愿合格生源不足时，结合我校实际情况，确定是否组织开展调剂工作。如开展调剂工作，届时将制订并公布调剂工作办法。接受所有考生（含报考士兵计划与普通计划之间调剂的考生等）调剂申请均通过教育部“全国硕士生招生复试调剂服务系统”进行。</p><p>六、思想政治素质和品德考核</p><p>思想政治素质和品德考核主要考核考生本人的现实表现，包括考生的政治态度、思想表现、道德品质、遵纪守法、诚实守信等方面。考核结果由学校综合评判确定，对于思想品德考核不合格者不予录取。</p><p>拟录取名单确定后，我校向考生所在单位函调人事档案（或档案审查意见）和本人现实表现等材料，全面考查其思想政治和品德情况。函调的考生现实表现材料，须由考生本人档案或工作所在单位的人事、政工部门加盖印章。</p><p>七、录取</p><p>我校在研究生招委会的统一领导下，按照教育部有关招生政策规定及省招委会的管理和实施办法，根据我校招生计划、复试录取工作办法、各院（系、所）复试录取工作细则以及考生考试综合成绩、思想政治素质和品德考核情况、身心健康状况等择优确定拟录取名单。定向就业的考生应当在被录取前与东南大学、用人单位签订定向就业合同。考生因报考硕士研究生与所在单位产生的问题由考生自行处理。若因此造成考生不能复试或无法录取，招生单位不承担责任。</p><p>对报考资格、录取条件、录取程序等不符合规定者不予录取。对未通过或未完成学历（学籍）审核的考生不列入拟录取名单公示或上报。</p><p>应届本科毕业生及自学考试和网络教育届时可毕业本科生考生，在录取当年入学前未取得国家承认的国（境）内高校本科毕业证书或教育部留学服务中心出具的《国（境）外学历学位认证书》的，其录取资格无效。</p><p>八、其他说明</p><p>（一）我校2026年招生目录中公布的“拟考试招生人数”，不含拟招收推免硕士生人数。最终考试招生人数根据教育部正式下达的招生计划数和实际录取推免硕士生人数等因素而增加或减少。我校各招生专业近几年的复试分数线和报考录取情况统计参见“东南大学研究生招生网”（网址：https://yzb.seu.edu.cn）主页“历史数据”。</p><p>（二）我校硕士研究生所有专业的学制均为3年。根据国家财政部、教育部的相关文件精神，所有纳入招生计划的硕士研究生都要缴纳学费，我校2026年硕士研究生学费标准另见东南大学研究生招生网公告。</p><p>（三）我校全日制硕士生参加奖助学金评定，非全日制硕士生不参加奖助学金评定。我校统筹多方资源对录取的全日制硕士生安排住宿，对非全日制硕士生不安排住宿。</p><p>（四）我校部分学院涉及无锡校区培养，包括:信息科学与工程学院、自动化学院、交通学院、仪器科学与工程学院、网络空间安全学院、集成电路学院，详见招生目录中相关学院备注信息。</p><p>（五）我校不举办任何形式的考前辅导班，不提供历年试题及复习资料。</p><p>（六）若发现考生有申报虚假材料、考试作弊及其它违反考试纪律的行为，我校将通知其所在单位，并按教育部《国家教育考试违规处理办法》进行严肃处理。</p><p>（七）本章程未尽事宜以《2026年全国硕士研究生招生工作管理规定》为准。若2026招生年度国家出台新的研究生招生政策，我校将做相应调整，并及时在东南大学研究生招生网予以公布。</p><p>九、信息查询、联系方式</p><p>东南大学研究生招生网（网址：http://yzb.seu.edu.cn/）</p><p>东南大学研招办及各院（系、所）联系电话（网址：https://yzb.seu.edu.cn/2016/0511/c6690a158314/page.htm）</p><p>东南大学研招办电子邮箱：seuyzb@pub.seu.edu.cn</p><p>东南大学研招微信公众号：seuyzb</p><p>东南大学研招办地址：南京市四牌楼2号东南大学逸夫建筑馆203室</p>
