                            <h3>上海交通大学2026-2027学年秋季学期研究生选课通知</h3>
                            <div class="article-other">
                                <div class="article-otherBase">
                                                                        <span>
                                        <i class="iconfont icon-calendar-o"></i>2026.06.13
                                    </span>
                                                                                                            <span>
                                        <i class="iconfont icon-eye"></i>65952
                                    </span>
                                                                    </div>
                                <div class="share-btn">
                                    <span>分享至：</span>
                                    <span class="icon" id="shareToWeixin" style="background-color: #14BD03;"><i class="iconfont icon-weixin"></i></span>
                                    <span class="icon" id="shareToWeibo" style="background-color: #CE1C02;"><i class="iconfont icon-weibo"></i></span>
                                </div>
                            </div>
                        </div>
                        <div class="mce-content-body ">
                            <p style="text-indent: 2em;"><span style="text-indent: 2em;">各位研究生同学：</span></p>
<p style="text-indent: 2em;">2026-2027学年秋季学期研究生课程第一轮选课工作将于2026年春季学期第17-18周进行，第二轮选课工作将于2026年秋季学期第1-2周进行，现就选课相关事宜通知如下：</p>
<p style="text-indent: 2em;">一、研究生选课应在培养计划指导下进行，<strong>选课前</strong>请先在导师指导下根据学科或项目培养方案<strong>完成个人培养计划的制定、修订与提交工作</strong>。<strong>2025级及以前学生</strong>选课前，培养计划须经<strong>导师审核通过</strong>，个别院系、学科须经学院审核通过；除学院有特殊要求外，<strong>2026级学生</strong>选课时培养计划可以为&ldquo;<strong>待导师审核</strong>&rdquo;状态。<strong>具体要求请务必提前咨询所在学院，以免影响课程选课。</strong></p>
<p style="text-indent: 2em;">二、2026级全日制研究生的政治类、英语类、数学类、体育类公共课程由学生<strong>自行选择教学班</strong>，<strong>具体选课说明请见文末附件</strong>；部分专业课程及部分院系自行开设的英语类课程由院系根据培养方案统一安排；其它课程须在选课时段内根据个人培养计划自行选择教学班。院系统一安排教学班的课程，如需调整教学班请及时与院系确认，经院系同意后可由院系调整或自行在选课时段内退课、选课；<strong>学生自行退课后因教学班选课人数已满，无法再行选课的，请于下一开课学期自行选课修读。</strong></p>
<p style="text-indent: 2em;">三、2026级全日制研究生英语课程免修申请将在2026年秋季学期<strong>第1周</strong>进行，<strong>请提前准备好英语成绩证明; </strong>留学生、非全日制学生的英语免修申请另行通知。<strong>请各位2026级全日制研究生同学在2026年9月6日17:00前填写《上海交通大学2026级全日制研究生英语水平调查》问卷（问卷链接：</strong><a href="https://wj.sjtu.edu.cn/q/h3mNWbsX"><strong>https://wj.sjtu.edu.cn/q/h3mNWbsX</strong></a><strong>），填写情况将作为全日制研究生英语课程免修申请的重要依据，请务必认真如实填写。2026级研究生英语课程</strong>免修实施细则将另行通知。</p>
<p style="text-indent: 2em;"><strong>四、各系统入口与登陆方式如下：</strong></p>
<p style="text-indent: 2em;"><strong>培养计划</strong>制定、修订与提交请通过jAccount登陆到<a href="https://yjs.sjtu.edu.cn/">研究生应用管理平台</a>(<a href="https://yjs.sjtu.edu.cn">https://yjs.sjtu.edu.cn</a>)&ldquo;培养&rdquo;-&ldquo;我的培养计划&rdquo;进行。</p>
<p style="text-indent: 2em;"><strong>选课</strong>可直接通过jAccount登录研究生选课网址<a href="https://yjsxk.sjtu.edu.cn">https://yjsxk.sjtu.edu.cn</a>，进入&ldquo;我要选课&rdquo;，<strong>培养计划中的课程请到&ldquo;计划内选课&rdquo;界面选择教学班</strong>，培养计划外的任意选修课请到&ldquo;计划外选课&rdquo;界面选择教学班。</p>
<p style="text-indent: 2em;">需<strong>重修重考</strong>的同学，请通过jAccount登录到<a href="https://yjs.sjtu.edu.cn/">研究生应用管理平台</a>(<a href="https://yjs.sjtu.edu.cn">https://yjs.sjtu.edu.cn</a>)&ldquo;培养&rdquo;-&ldquo;学生重修申请&rdquo;<strong>提交重修重考申请</strong>。待审核通过后，务必通过&ldquo;<strong>重修选课</strong>&rdquo;界面选择教学班。</p>
<p style="text-indent: 2em;"><strong>五、系统开放时间如下：</strong></p>
<p style="text-indent: 2em;"><strong>（一）培养计划制订、修订时间： </strong></p>
<p style="text-indent: 2em;">第一轮（老生）：2026年6月15日9:00 - 2026年7月3日20:00</p>
<p style="text-indent: 2em;">第二轮（全部学生）：2026年9月10日9:00 - 2026年9月24日20:00</p>
<p style="text-indent: 2em;"><strong>（二）选课开放时间：</strong></p>
<p style="text-indent: 2em;">第一轮（老生）：2026年6月22日12:00 - 2026年7月3日20:00</p>
<p style="text-indent: 2em;">第二轮（全部学生）：2026年9月14日12:00 - 9月24日20:00</p>
<p style="text-indent: 2em;"><strong>（三）重修申请开放时间：</strong></p>
<p style="text-indent: 2em;">第一轮：2026年6月22日12:00 - 2026年7月3日17:00</p>
<p style="text-indent: 2em;">第二轮：2026年9月14日12:00 &ndash; 2026年9月24日17:00</p>
<p style="text-indent: 2em;"><strong>六、请务必注意，培养计划加入课程并不代表进入选课名单，请进入选课界面自行选择教学班。选课开放时间结束后，原则上不可再选课、退课</strong>；选课学生须<strong>按课表参加课程学习，所选课程（含计划外&ldquo;任意选修课&rdquo;）在毕业前均需考核通过</strong>，否则将影响毕业进程；未列入选课名单的，不得参加课程的学习和考核，所选课程及学分不予记载。</p>
<p style="text-indent: 2em;">七、需要<strong>重修（重考）</strong>的同学，请在系统开放后尽早<strong>提交重修申请</strong>，并在审核通过后，在选课系统开放时间内进入&ldquo;<strong>重修选课</strong>&rdquo;界面完成选课。<strong>公共课程重修选课说明请见文末附件。</strong></p>
<p style="text-indent: 2em;"><strong>八、9月21日起，各开课院系将对选课人数较少的课程进行调整，对达不到规定开课人数的教学班进行合并或取消</strong>，请同学们及时登录系统查询并确认个人课表。被取消开课的教学班，其选课结果也将同时被删除，请相关同学及时调整个人培养计划及所选课程（<strong>需在系统开放时间段内完成</strong>）。</p>
<p style="text-indent: 2em;"><strong>九、非全日制</strong>研究生原则上按本通知执行，各院系有特殊安排的按院系通知操作；<strong>医学院</strong>研究生选课安排按医学院研究生院分院通知执行；<strong>本研互选、交换生、旁听生</strong>选课事宜另行通知。</p>

            function utf16to8(str) {
                var out, i, len, c;
                out = "";
                len = str.length;
                for (i = 0; i < len; i++) {
                    c = str.charCodeAt(i);
                    if ((c >= 0x0001) && (c <= 0x007F)) {
                        out += str.charAt(i);
                    } else if (c > 0x07FF) {
                        out += String.fromCharCode(0xE0 | ((c >> 12) & 0x0F));
                        out += String.fromCharCode(0x80 | ((c >> 6) & 0x3F));
                        out += String.fromCharCode(0x80 | ((c >> 0) & 0x3F));
                    } else {
                        out += String.fromCharCode(0xC0 | ((c >> 6) & 0x1F));
                        out += String.fromCharCode(0x80 | ((c >> 0) & 0x3F));
                    }
                }
                return out;
            }
