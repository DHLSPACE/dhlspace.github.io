<div class="tit" style="font-weight:bold;">【博士】电子科技大学硕士生申请2026年硕博连读报名通知</div>
<div class="infor">发布时间：2025-10-20 点击数：<script>_showDynClicks("wbnews", 1645354162, 5604)</script></div>
 
    <div id="vsb_content" class="content"><div class="v_news_content">
<p style="text-align: justify; line-height: 32px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">各位考生：</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">为统筹做好我校硕士生的硕博贯通培养工作，根据学校有关安排，现就硕士生申请2026年硕博连读报名通知如下：</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">一、申请对象及要求</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">1.申请对象：本校在读研二、研三全日制硕士生。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">2.基本要求：</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（1）申请人<span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 14pt; mso-ansi-language: EN-US; mso-fareast-language: ZH-CN; mso-bidi-language: AR-SA;">须拥护中国共产党的领导，遵纪守法，品德良好</span>；</span>德才兼备，全面发展，对学术研究有浓厚兴趣、具有较强创新精神和科研能力。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（2）在读硕士二年级研究生在申请前须完成硕士培养方案要求的学位课学分；在读硕士三年级研究生在申请前须完成硕士培养方案要求的所有课程学分。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;">考生除应满足基本要求外，若报考学院另有要求的，还需符合报考学院和专业所要求的其他条件，</span><strong><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;">详见</span><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px; text-decoration: none;">各学院2026年硕博连读报名有关通知（<a href="https://yz.uestc.edu.cn/info/1082/5605.htm" target="_self">点击查看</a>）。</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">二、报名方式</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">1.报名流程（博士生报名系统填报说明见附件）：</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（1）查看本报名通知。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（2）访问报名系统（博士研究生招生）并注册账号。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（3）按照系统步骤准确填写或修改报名信息、上传报名材料。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（4）网上交费、核对并提交报名信息。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（5）向报考学院按时提交纸质报名材料。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">2.时间安排</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">（1）系统填报时间：2025年10月21日09:00至10月30日22:00。本批次硕博连读报名结束后，学校将不再开展2026年硕博连读的报名和遴选，请有意向报考的硕士生合理规划时间。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;">（2）系统填报网址：</span><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><a href="https://yzbm.uestc.edu.cn/logon"><span style="color: rgb(0, 0, 255); font-family: times new roman,serif; font-size: 19px;">https://yzbm.uestc.edu.cn/logon</span></a><span style="color: rgb(0, 0, 0); font-family: 仿宋; font-size: 19px;">。</span></span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">3.材料要求</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px; text-decoration: none;">报名材料要求详见各学院2026年硕博连读报名通知（<a href="https://yz.uestc.edu.cn/info/1082/5605.htm" target="_self">点击查看</a>）。</span></strong><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px; text-decoration: none;">相关材料由申请人在2025年10月31日前提交至报考学院。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">报名信息和申请材料在报名结束后原则上不得更改。<strong>考生提供的论文、专著、成果或奖励等发表/获得时间要求截至学校当年硕博连读报名结束前（2025年10月30日）。</strong>少数民族骨干计划考生身份以报考时经审核的报名材料为准。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">考生提交的纸质材料为复印件，学校不再退还。身份证、硕士阶段学生证或学历学位证书（证明）材料原件由招生学院在复试或入学时查验。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">请考生认真准备申请材料并按时提交。若提供材料不符合要求、材料弄虚作假或违反学术道德规范等造成后续不能参加考核、复试或录取的，责任由考生本人承担。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">三、其他要求及说明</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">1.复试考核工作由各学院按照有关要求组织，另行通知。本次硕博连读拟录取的博士生均安排在2026年春季入学（具体时间以研究生院有关通知安排为准）。未被录取的申请人继续按硕士生要求培养。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">2.项目制硕博连读、国家实验室/重点企业联合培养等有关专项报名，按照专项工作相关要求执行。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">3.定向就业硕士生须征得原定向单位的同意方可申请。联合培养专项硕士生的硕博连读要求由各专项培养部门根据实际确定。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">4.网上报名前考生应认真查看报名有关通知，并如实、准确填写报名信息，在规定时间内完成报名和交费。凡不按要求报名、交费、信息误填、错填或填报虚假信息而造成后续不能参加考核、复试或录取的，责任由考生本人承担。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">5.考生应当认真了解并核对本人是否符合相关学院专业报考条件，严格按照相关政策要求选择填报志愿。因不符合报考条件及相关政策要求，造成后续不能参加考核、复试或录取的，责任由考生本人承担。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">6.对弄虚作假或不符合报考、复试、录取资格者，不论何时，一经查实，即按有关规定取消报考、复试、录取或学习资格。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">7.报名费180元/人（川发改价格规〔2022〕484号）。报名费须在报名期间通过网上报名系统支付。请考生在安全场所上网报名，因自己操作失误或网上支付帐号和密码泄漏造成的损失，我校概不负责。网上支付费用前务必慎重考虑，因各种原因不能参加考核者，已支付费用概不退费。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">8.本通知由电子科技大学研究生招生办公室负责解释。如有与教育部2026年博士研究生考试招生政策不符之处，以教育部文件为准。报名工作或安排如有调整，请以学校最新通知为准。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">四、咨询方式</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;">研招办联系方式：</span><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋; font-size: 19px;"></span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: times new roman,serif; font-size: 19px;">028-61830152</span><span style="color: rgb(0, 0, 0); font-family: 仿宋; font-size: 19px;">、</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: times new roman,serif; font-size: 19px;">028-61830153</span><span style="color: rgb(0, 0, 0); font-family: 仿宋; font-size: 19px;">。</span></span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 19px;">各学院联系方式：</span><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;"><a href="https://yz.uestc.edu.cn/lxwm.htm"><span style="color: rgb(0, 0, 255); font-family: 仿宋; font-size: 19px;">https://yz.uestc.edu.cn/lxwm.htm</span></a></span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 37px;"><span style="color: rgb(0, 0, 0); font-family: 宋体,SimSun; font-size: 21px;">&nbsp;</span></p>
