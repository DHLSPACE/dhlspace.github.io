                                <div deep="4"><p style="white-space: normal;"><strong><span style="font-family: 宋体, SimSun;">一、报考点情况说明</span></strong></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（一）报考点接收报名的考生范围和报考点的具体要求，详见山东省教育招生考试院网站（https://www.sdzk.cn/）研究生招考一栏中的<strong>《2026年山东省硕士研究生招生考试报考点接收要求及条件》</strong>。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（二）山东省共设34个报考点，分别是：各市教育招生考试机构（16个）和山东大学、中国海洋大学、中国石油大学（华东）、山东科技大学、青岛科技大学、青岛理工大学、山东建筑大学、山东农业大学、青岛农业大学、山东中医药大学、山东师范大学、曲阜师范大学、聊城大学、山东财经大学、青岛大学、烟台大学、济南大学和齐鲁工业大学等18个招生单位。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">山东省所有报考点原则上只接收驻山东高校就读的应届本科毕业生（成人高校应届本科毕业生的教学点所在地为山东省）及工作（原则上须提供社保缴纳材料，具体请查阅报考点发布的网上确认公告）或户籍在山东省的其他考生(含往届、自考、网络教育等，下同)。报考山东省招生单位的单独考试、强军计划及初试第四门考试科目代码为910-929或考试时间超过3小时的考生只可选择报考单位为报考点。</span></p><p style="white-space: normal;"><strong><span style="font-family: 宋体, SimSun;">二、报名注意事项</span></strong></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（一）认真学习相关政策及规定。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生应认真查阅教育部《2026年全国硕士研究生招生工作管理规定》及所报考的招生单位硕士研究生招生章程，符合报考条件者方能报考。招生单位将在网上确认后审核已确认考生的报考资格。不符合报考资格者，将予以不准考处理。不准考考生将无法参加本次考试。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生在进行网上报名前须提前通过中国研究生招生信息网(网址：https://yz.chsi.com.cn)及报考点网站详细了解山东省各报考点发布的确认公告，以免因错选报考点而导致无法进行信息确认。考生因个人原因错选报考点造成后期无法确认，责任由考生承担。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（二）熟知报考点选择要求。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">1.报考全国统考的考生：应届本科毕业生，报考就读高校所在地（成人高校应届本科毕业生教学点所在地）的招生单位，且该单位为报考点的，须选择该单位为报考点进行报名；报考就读高校所在地（成人高校应届本科毕业生教学点所在地）的招生单位，但该单位为非报考点的，或报考非就读高校所在地的招生单位须选择就读高校所在地的市教育招生考试机构为报考点进行报名。<strong>各高校的异地分校（校区）的应届毕业生按分校（校区）所在地政策执行。</strong></span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">其他考生，报考工作或户籍所在地的招生单位且该单位为报考点的，须选择该单位为报考点进行报名。报考工作或户籍所在地的招生单位但该单位为非报考点的，或报考非工作或非户籍所在地的招生单位，须选择工作或户籍所在地的市教育招生考试机构为报考点进行报名。如工作和户籍所在地不一致，可就近选择所报招生单位或市教育招生考试机构为报考点进行报名。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">上述考生就读高校（含分校）所在地、户籍或工作所在地均为以设区市为单位。选择工作所在地的报考点的考生原则上须提供社保缴纳材料，具体请查阅报考点发布的网上确认公告。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">2.报考单独考试的考生（含外省考生）：只可选择报考单位为报考点。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">3.报考强军计划的考生：只可选择报考单位为报考点。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">4.初试第四门考试科目代码为910-929或考试时间超过3小时的考生，只可选择报考单位为报考点。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（三）熟练掌握网上报名流程。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">1.网报地址及填报报考信息</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">网报地址：https：//yz.chsi.com.cn。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生登录网报地址后按照报名操作要求先进行账号注册，注册成功后，在规定报名期间登录报名系统，按系统提示的操作步骤进行相关信息的填报，信息填报一定要真实、准确、完整。考生在提交报考信息后，由中国研究生招生信息网自动生成考生报考信息及报名号。此时考生应认真核对本人信息，特别是所选报考点是否有误，如有误须在网报结束前予以更正。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">2.网上报名时间</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">网上报名时间为2025年10月16日至10月27日，每天9:00—22:00。网上预报名时间为2025年10月10日至10月13日，每天9:00—22:00。<strong>预报名成功后，报名有效。</strong></span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">3.网上缴费</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">选择山东省各报考点的考生，提交网报信息后，在报名（含预报名）期间，考生采用网上支付方式缴纳报考费。请考生务必于网上报名期间完成网上缴费，截止时间为10月27日22:00。网上报名结束后一律不再进行补缴费。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">收费标准：报考的初试业务课二科目代码以“5”开头的专业收费标准为每人220元，其他专业收费标准为每人180元。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（四）网上确认。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">报名及缴费成功后，所有考生均应在规定的时间内进行网上确认。未完成网上确认的考生，报名资格无效。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">1.网上确认时间</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">山东省网上确认材料初次上传时间为2025年10月31日9:00至11月5日12:00。补充材料上传截止时间为11月5日16:00。逾期不能上传。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">2.网上确认要求</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">我省所有报考点均采用网上确认方式，请考生认真阅读所选报考点发布的网报公告，按报考点要求及时准确上传相关材料，完成网上确认。因考生不按照要求上传材料导致网上确认不通过的，责任由考生自行承担。 &nbsp;&nbsp;&nbsp;</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生要认真核对网上报名信息，经考生确认的报名信息在初试、复试及录取阶段一律不作修改。因信息填报错误造成的一切后果由考生承担。</span></p><p style="white-space: normal;"><strong><span style="font-family: 宋体, SimSun;">三、其他事项</span></strong></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（一）修改报考信息相关事项。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生在提交报考信息后，由中国研究生招生信息网自动生成考生报考信息，但不论是否已支付报考费，所填报的“报考单位”“报考点”和“考试方式”等关键性信息不能更改。关键性信息填报错误的考生须在网上报名截止时间（10月27日22:00）前，取消报名后重新报名，并重新缴纳报考费，逾期无法修改。<strong>重复缴纳的报考费将于网报结束后3个月内系统自动退还。</strong></span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生如修改非关键性信息，可在网上报名截止时间（10月27日22:00）前使用已注册的用户名和密码登录报名网站修改。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（二）报考费退费相关事项。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">已参加网上确认且已编排考场但未参加考试的考生，其缴纳的报考费将不予退还。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">若因考生网上支付时操作不当或因网络技术原因造成同一报名号重复缴费或已缴纳报考费但未进行网上确认的，网报结束3个月内系统自动退还相关报考费。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生请勿在缴纳报考费后立即注销银行卡，否则将影响退费。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（三）自考生报考相关事项。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">未取得毕业证的自考生在网上报名校验时会提示无学籍学历，届时考生可继续填报，后期按照报考单位要求提供相应自考有关材料，如自考成绩单等。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（四）特殊科目考生报考相关事项。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">初试第四门考试科目代码为910-929或考试时间超过3小时的考生，如对报考点选择有疑问，请及时联系报考单位。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（五）考点安排说明。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">各报考点统筹考虑报考人数、标准化考点建设及组考安全等因素后进行考点分配。具体考点信息请以准考证信息为准。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（六）残疾考生申请合理便利相关事项。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">如考生符合《教育部 中国残联关于印发&lt;残疾人参加普通高等学校招生全国统一考试管理规定&gt;的通知》（教学〔2017〕4号）文件规定的申请便利条件，请于11月14日前向报考点提出申请。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">（七）及时查阅有关报考信息。</span></p><p style="white-space: normal;"><span style="font-family: 宋体, SimSun;">考生要定期登录中国研究生招生信息网查阅“站内信”，及时了解报考点及招生单位的有关招生信息。</span></p><p style="white-space: normal; text-align: center;"><span         $(function () {
            $('#goToTop').hide();//隐藏go to top按钮
            $(window).scroll(function () {
                //当window的scrolltop距离大于1时，go to 
                if ($(this).scrollTop() > 100) {
                    $('#goToTop').fadeIn();
                } else {
                    $('#goToTop').fadeOut();
                }
            });
            $('#goToTop a').click(function () {
                $('html ,body').animate({ scrollTop: 0 }, 300);
                return false;
            });
