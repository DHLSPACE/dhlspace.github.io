                        <div class=TRS_Editor><p align="justify"><span>中国科学院上海高等研究院（以下简称“高研院”）是中国科学院与上海市人民政府共建的国立科研机构，在能源、环境、信息、生命科学、先进制造、交叉前沿等领域开展研究与开发工作。2017年5月，中国科学院院党组决定依托上海高研院，以在沪重大科技基础设施集群为基础，整合集聚有关科研资源和优势力量，筹建张江国家实验室，在上海科创中心、张江综合性国家科学中心建设中发挥核心骨干作用。</span>&nbsp;</p>
<p align="justify"><span>2020</span><span><span>年高研院预计招收推免研究生30名，其中硕士研究生</span></span><span>20名</span><span><span>，</span></span><span>直博生10名，招生专业可查阅相关招生专业目录。推免生实际招生情况预计将于2019年10月中旬左右在我院研究生教育网站公布，以公布信息为准。</span>&nbsp;</p>
<p align="justify"><span>热忱欢迎各校有化学、化学工程与技术、信息与通信工程、电子科学与技术、微电子学</span><span><span>与固体电子学、材料科学与工程、环境科学与工程、物理学、光学工程、计算机科学与技术、软件工程、动力工程及工程热物理、控制科学与工程、生物学、生物工程专业背景的优秀应届本科毕业生申请我院免试攻读硕士学位研究生或直博生。</span></span>&nbsp;</p>
<p align="justify"><strong><span>一、申请条件</span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>凡在高校获得推荐免试资格的优秀应届本科毕业生均可申请免试攻读我院硕士研究生或直博生。申请者应具备如下条件：&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．须获得考生所在毕业学校推免资格并在教育部“推免服务系统”中获得推免资格备案。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．道德品质良好，遵纪守法，诚实守信，无任何考试作弊和剽窃他人学术成果记录，无任何违法违纪受处分记录。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．申请人在大学本科阶段学习成绩优异，具有一定的科研创新实践或各类竞赛经历。</span></span>&nbsp;</p>
<p align="justify"><span><span>4</span></span><span><span>．热爱科学事业，具有较好的科研潜力，具有较强的独立调查研究、综合分析问题、解决问题能力。</span></span>&nbsp;</p>
<p align="justify"><span><span>5.<span>&nbsp;</span></span><span>外语程度良好，具有较强的外语听、说、读、写应用能力。</span></span>&nbsp;</p>
<p align="justify"><span><span>6</span></span><span><span>．身体健康状况符合规定的体检标准，心理健康状况良好。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>二、申请流程</span></span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>1.&nbsp;</span></span><span><span>申请时间：2019年9月11日至9月21日。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2.&nbsp;</span></span><span><span>预计自己能在所就读的高等学校取得推荐免试外推资格的考生，可通过我院网站查看推免生招生专业目录，了解招生专业和研究方向。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3.&nbsp;</span></span><span><span>登录中国科学院大学推荐免试生申请系统&nbsp;(<a href="http://zhaosheng.ucas.ac.cn/sign_up/TMS/views/index.aspx">http://zhaosheng.ucas.ac.cn/sign_up/TMS/views/index.aspx</a>)，填写申请表。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><strong><span>三、申请材料</span></strong></span><span><strong><span>&nbsp;</span></strong></span>&nbsp;</p>
<p align="justify"><span>推荐免试申请者通过国科大招生信息网推荐免试申请系统初步报名后，应向我院提交如下材料：</span>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．《中国科学院大学推荐免试攻读硕士学位研究生/直博生申请表》，申请表可以通过在线报名系统中的报表途径打印，经申请人签字确认并由校教务处或所在院系盖章有效。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．所在学校（或院系）教务部门加盖公章的大学本科前三年所修课程成绩单（五年制的提供前四年课程成绩单）。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．个人简历及专业学习情况介绍。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>4</span></span><span><span>．有效居民身份证、学生证复印件。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>自愿提供的材料：</span></span></strong>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．《专家推荐书》（由副教授或相当职称以上专家推荐，推荐书需密封并在封口骑缝处签字）。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．在公开发行的学术刊物或全国性学术会议上发表的学术论文、所获专利或其他原创性工作成果的复印件或证明。</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．英语、计算机等级证、大学期间获奖证书复印件。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>4.<span>&nbsp;</span></span><span>对申请有参考价值的其他材料。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>注：所有申请材料统一使用A4纸张打印或复印，并按以上顺序排列，最迟于复试报到前将以上纸质版申请材料寄送至我院研究生处。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>特别提醒：参加过我院2019年暑期夏令营和8月短期实践的同学，同样需要提交以上申请材料，并在中国科学院大学研究生招生网上报名申请。</span></span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>四、接收程序</span></span></strong><span><strong><span>&nbsp;</span></strong></span>&nbsp;</p>
<p align="justify"><strong><span>（一）初审</span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>我院将对申请人提交的申请材料进行初审，并通知符合条件的申请人参加复试。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>（二）复试</span></span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>复试预计将根据申请时间及申请人员等情况，分批进行。包含面试和体检，面试内容主要包括思想政治品德考核、专业知识、外语考核。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．思想政治品德考核主要考查考生的政治态度、思想品德、人生观、价值观、工作学习态度、团队合作精神、科研道德及遵纪守法等方面的基本情况。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>有下列情形之一且未能提供对错误的认识及改正错误的现实表现等证明材料的，应认定为思想政治品德考核不合格：&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>(1)</span></span><span><span>有反对宪法所确定的基本原则的言行或参加邪教组织，情节严重的；&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>(2)</span></span><span><span>触犯治安管理处罚法，受到治安管理处罚且情节严重、性质恶劣的。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．专业知识考核以面试为主，重点考查考生对知识掌握的深度和广度，对知识灵活运用的程度以及考生的实验技能和实际动手能力等，了解考生从事科研工作的潜力和创造性。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．外语考核主要考查考生的听、说能力及语言运用能力。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>4</span></span><span><span>．体检由我院组织考生进行。体检标准参照教育部、卫生部、中国残联印发的《普通高等学校招生体检工作指导意见》（教学〔2003〕3号）要求，按照人力资源和社会保障部、教育部、卫生部《关于进一步规范入学和就业体检项目维护乙肝表面抗原携带者入学和就业权利的通知》（人社部发〔2010〕12号）规定要求执行。新生入学后需进行体检复查。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>（三）拟接收及复审</span></span></strong><span><span>&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．我院招生领导小组对面试和体检结果进行审议，按照“德智体全面衡量、择优录取、保证质量、宁缺毋滥”的原则确定拟录取名单并进行公示。</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．所有被确定接收的推荐免试硕士生或直博生必须在规定的时间内，通过教育部“推免服务系统”完成网上报名、复试确认、拟录取等各项网上操作。此后，未完成相关接收手续或未落实接收单位的推荐免试生不再保留推荐免试生资格，原有的推免拟接收资格自动失效。</span></span>&nbsp;</p>
<p align="justify"><span><span>最终未获得所在学校推免资格或未在教育部“推免服务系统”平台获得推免资格备案的学生, 原有的推免拟接收资格及其名单公示自动失效。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3.</span><span>&nbsp;</span><span>录取层次（硕士研究生或直博生）、录取类型（学术型硕士研究生或专业型硕士研究生）、录取专业和学习方式（全日制）等以教育部“推免服务系统”确认的信息为准，后期各工作阶段原则上不得改变。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>4</span></span><span><span>．被拟录取的推荐免试生不得再以统考生身份报名参加全国硕士生统一入学考试。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>5</span></span><span><span>．推荐免试生的录取类别一般为计划内非定向，学习方式为全日制。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>6</span></span><span><span>．对拟录取的推荐免试生，通过教育部审核通过后与对应统考生同时发放录取通知书。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>五、学制</span></span></strong><span><strong><span>&nbsp;</span></strong></span>&nbsp;</p>
<p align="justify"><span>1</span><span><span>．推荐免试硕士研究生基本学制一般为3年，最长修读年限（含休学）不得超过4年。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．直博生基本学制一般为5年，最长修读年限（含休学）不得超过8年。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．录取为硕博连读方式的推免生，包括硕士阶段在内修读年限一般为5年，最长修读年限（含休学）不得超过8年。确定硕博连读的考生，应按要求在规定时间内提出硕博连读转博申请，且进行博士招生网上报名和转博考核。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>六、特别申明</span></span></strong><span><strong><span>&nbsp;</span></strong></span>&nbsp;</p>
<p align="justify"><span>申请人必须保证提交的申请表和其它全部申请材料的真实性和准确性。因申请人提交的信息不真实或不准确而造成的一切后果，由申请人自行承担。对拟录取的推荐免试生，出现下列情况之一的，取消其录取资格：&nbsp;</span>&nbsp;</p>
<p align="justify"><span><span>1</span></span><span><span>．在本科阶段最后一学年（四年制的指第七、八学期，五年制的指第九、十学期）专业主干课程学习成绩有不及格科目。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>2</span></span><span><span>．毕业设计（论文）未取得良好以上（含良好）成绩。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>3</span></span><span><span>．毕业时未获得本科毕业证书或学士学位。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>4</span></span><span><span>．政审不合格。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>5</span></span><span><span>．考试作弊者或违纪（法）受到“警告”以上处分的，或有其他情节严重的违法乱纪行为受到处罚者。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><span><span>6</span></span><span><span>．申请人提交的材料有弄虚作假者。&nbsp;</span></span>&nbsp;</p>
<p align="justify"><strong><span><span>七、</span></span></strong><span><span>本公告未尽报考事宜，请参看《中科院上海高等研究院2020年招收攻读硕士学位研究生简章》等文件，如有与国家新出台的招生政策或中国科学院大学相关文件要求不符的事项，以上级单位新政策或文件为准。&nbsp;</span></span>&nbsp;</p>

<script>
    $(document).ready(function(){
        // 将IP地址转换为数字形式
        function ipToNumber(ip) {
            return ip.split('.').reduce(function (acc, part) {
                return (acc << 8) + parseInt(part, 10);
            }, 0);
        }

        // 判断IP地址是否在指定的IP段内
        function isIpInRange(ip, startIp, endIp) {
            const ipNumber = ipToNumber(ip);
            const startIpNumber = ipToNumber(startIp);
            const endIpNumber = ipToNumber(endIp);
            return ipNumber >= startIpNumber && ipNumber <= endIpNumber;
        }

        // 监听带有ems类的a链接的点击事件
        $('a.ems').on('click', function(event) {
            const $this = $(this); // 保存当前点击的a标签
            event.preventDefault(); // 阻止默认的链接跳转行为

            // 获取当前IP地址
            $.get("https://cms.qysoft.cn/getIp.do", function(data, status){
                var currentIp = data.ip;
                // 定义IP段范围
                const ranges = [
                    { start: '119.78.66.0', end: '119.78.66.63' },
                    { start: '119.78.243.0', end: '119.78.243.255' },
                    { start: '159.226.222.0', end: '159.226.222.255' },
                    { start: '117.185.36.177', end: '117.185.36.182' },
                    { start: '180.169.133.113', end: '180.169.133.126' },
                    { start: '180.168.97.113', end: '180.168.97.126' } // 修正了这里缺少的逗号
                ];

                // 检查当前IP是否在任何一个IP段内
                let isInAnyRange = false;
                for (const range of ranges) {
                    if (isIpInRange(currentIp, range.start, range.end)) {
                        isInAnyRange = true;
                        break;
                    }
                }

                if (isInAnyRange) {
                    console.log('当前IP属于指定的IP段');
                    window.location.href = $this.attr('href'); // 直接访问链接
                } else {
                    console.log('请先登录VPN');
                    Swal.fire({
                        title: '提示',
                        text: '请先登录VPN',
                        icon: 'warning',
                        confirmButtonText: '确定'
                    });
                }
            });
        });
    });
</script>

            var tagObj = zoomObj.getElementsByTagName(tagName);
            if (tagObj.length == 0){
                zoomObj.style="font-size:"+size+'px !important';
