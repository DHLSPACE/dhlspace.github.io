<p style="text-indent:43px;line-height:37px"><span style="font-family: 黑体; font-size: 21px; color: rgb(0, 0, 0);">六、待录取</span></p>
<p style="text-indent:43px;line-height:37px"><span style="font-family: 仿宋_gb2312; font-size: 21px; color: rgb(0, 0, 0);">国优计划学生最终待录取将通过教育部推免服务系统进行。对已进行预报名并通过复试考核且最终获得所在高校推荐资格的考生，在教育部推免服务系统开放后，必须及时在系统内完成正式报名，提交各项要求的材料。</span></p>
<p style="text-indent:43px;line-height:37px"><span style="font-family: 仿宋_gb2312; font-size: 21px; color: rgb(0, 0, 0);">系统开放后，报考院系将依据复试考核结果及系统报名情况发放待录取通知，额满为止。逾期未正式报名的，则不能保证预留计划额度。</span></p>
<p style="text-indent:43px;line-height:37px"><span style="font-family: 仿宋_gb2312; font-size: 21px; color: rgb(0, 0, 0);">发放复试通知或待录取通知后，若考生超出院系规定时间未接受，院系可撤销对考生的复试通知或待录取通知。</span></p>
<p style="text-indent:43px;line-height:37px"><span style="font-family: 仿宋_gb2312; font-size: 21px; color: rgb(0, 0, 0);">考生要在院系规定时间内通过推免服务系统确认同意待录取，同意操作后不可更改。逾期未确认考生，视为放弃待录取资格。</span></p>
<p style="text-indent:43px;line-height:37px"><span style="font-family: 仿宋_gb2312; font-size: 21px; color: rgb(0, 0, 0);">如有计划余额，院系可根据报名情况决定是否再行补录。待录取结束后，学院汇总同意待录取的考生名单，报研究生院审核，学校根据审核情况统一公示拟录取名单。</span></p>
