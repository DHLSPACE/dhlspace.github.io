 <h2 style="text-align:center">中国科学院大连化学物理研究所2020年招收攻读硕士学位研究生复试程序</h2>
            <div class="fbt">发布时间：2020年04月27日　栏目：硕士招生</div>
    <div id="vsb_content"><div class="v_news_content">
&nbsp; &nbsp; 根据《教育部办公厅关于做好2020年全国硕士研究生复试工作的通知》（教学厅〔2020〕4号）要求，为保证我所招收攻读硕士学位研究生的质量，规范硕士研究生的复试工作，特制定本程序。<br />&nbsp; &nbsp; 一、总则<br />&nbsp; &nbsp; 复试是对拟录取的考生进行的复查性考试，从德、智、体等方面全面考察考生的综合素质和能力。复试包括英语听力与口语测试、业务能力面试。<br />&nbsp; &nbsp; 二、复试原则和办法<br />&nbsp; &nbsp; 拟录取的考生均应通过复试。复试体现公平性和公正性原则，进行德、智、体全面衡量。<br />&nbsp; &nbsp; 1. 英语听力与口语测试（30分）<br />&nbsp; &nbsp; 主要测试考生听解能力与口语表达能力的实际水平。它从发音的正确性，使用语言的准确性、流利程度以及得体性等几个方面测试考生的口头表达能力。<br />&nbsp; &nbsp; 2. 业务能力面试（70分）<br />&nbsp; &nbsp; 按学科门类组织复试专家小组对考生进行基础知识及专业知识、创造性思维能力、分析问题能力等综合能力的考核。<br />&nbsp; &nbsp; 三、体检<br />&nbsp; &nbsp; 体检主要考查考生的身体健康状况，也包括体能、体质和心理素质等方面的考查。体检要求参照教育部、卫生部、中国残联指定的《普通高等学校招生体检工作指导意见》（教学【2003】3号）、人力资源和社会保障部、教育部、卫生部《关于进一步规范入学和就业体检项目维护乙肝表面抗原携带者入学和就业权利的通知》（人社部发〔2010〕12号）以及《教育部办公厅 卫生部办公厅关于普通高等学校招生学生入学身体检查取消乙肝项目检测有关问题的通知》（教学厅〔2010〕2号）进行。<br />&nbsp; &nbsp; 四、录取资格确定<br />&nbsp; &nbsp; 1.<span style="white-space:pre">	</span>参加复试考生：在同一学科门类内以符合复试要求的考生的初试成绩排序, 根据本年度硕士研究生招生计划及推荐免试生的拟录取情况,对考生进行差额复试；<br />&nbsp; &nbsp; 2.<span style="white-space:pre">	</span>复试成绩不低于60分；<br />&nbsp; &nbsp; 3.<span style="white-space:pre">	</span>业务能力面试获得的复试专家同意票数不少于50%。<br />&nbsp; &nbsp; 4.<span style="white-space:pre">	</span>思想政治品德考核合格；<br />&nbsp; &nbsp; 5.<span style="white-space:pre">	</span>考生成绩核定：初试成绩（满分500分）占50％；复试成绩（满分100分）占50％。按照最终核定分数从高到低，在同一学科门类内排序（第一志愿优先）。<br />&nbsp; &nbsp; 录取成绩＝（初试成绩÷5）×50％+复试成绩×50％<br />&nbsp; &nbsp; 6.<span style="white-space:pre">	</span>根据师生“双向选择”的原则，考生需与导师签订“研究生接收确认书”确定拟录取资格；根据我所《关于支持引进人才和学科发展的实施方案》，部分考生需在指定的导师及其招生专业内与导师签订“研究生接收确认书”确定拟录取资格，具体招生导师名单及招生专业见后续通知。<br />&nbsp; &nbsp; 7.<span style="white-space:pre">	</span>在规定时间内，考生若没有与接收专业内导师签订“研究生接收确认书”，则不予录取，由后续考生按录取成绩依次递补。<br />&nbsp; &nbsp; 8.<span style="white-space:pre">	</span>中国科学院大连化学物理研究所2020年硕士研究生拟录取名单由招生工作领导小组审核确定。<br />&nbsp; &nbsp; 9.<span style="white-space:pre">	</span>拟录取新生入学前出现下列任意情况之一者，取消其录取资格。<br />&nbsp; &nbsp; A：未取得学士学位<br />&nbsp; &nbsp; B：未取得本科毕业证书<br />&nbsp; &nbsp; C：受到处分<br /><p>&nbsp; &nbsp; 四、本复试程序由中科院大连化学物理研究所研究生部负责解释。</p><p>&nbsp; &nbsp; 举报联系方式：0411-84379006 xiongbh@dicp.ac.cn 辽宁省大连市中山路457号大连化物所研究生部</p><p>&nbsp; &nbsp; 北京教育考试院研招办监督电话：010-82837456</p><p>&nbsp; &nbsp; 国科大校招办监督电话：010-88256714&nbsp;<br /></p>&nbsp; &nbsp; &nbsp; &nbsp;
