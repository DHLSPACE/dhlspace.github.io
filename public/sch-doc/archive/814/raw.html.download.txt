								<div class="fl w100 mart15 swwls_content">
										<h1 class="fl w100 text-center"><abbr>【<abbr class="sss"></abbr>】</abbr>中国科学院生物物理研究所2022年生命科学希望之星夏令营报名通知</h1>
										<div class="fl w100 swwls_con_ly marb15 text-center">    
											<font>发布时间：2022年05月18日</font> 
										</div>
										<div class="TRS_Editor">
 <p align="justify">　　中国科学院生物物理研究所是国家生命科学基础研究所，创建于1958年，是中国科学院大学研究生培养点之一。建所以来，在贝时璋、邹承鲁、梁栋材和杨福愉等老一辈科学家的带领下，历经几代科技工作者的辛勤努力，取得了一批高水平研究成果，开发了一批高技术产品，孵化和创办了数家高技术公司，创造了良好的社会效益和经济效益，为国家生命科学事业发展做出了重要贡献。</p> 
 <p align="justify">　　生物物理所的战略定位是：充分发挥多学科交叉的综合优势，在蛋白质科学、脑与认知科学、感染与免疫科学、非编码核酸和蛋白质与多肽药物等学科前沿领域实现基础性、前瞻性、战略性突破，加强生命科学领域关键装备的创新研制，实现关键技术和实验方法的重点突破，构建以生物制药和体外诊断为重点的转化型研究体系，在国家创新体系中发挥源头创新和骨干引领作用。</p> 
 <p align="justify">　　 <strong>一、活动宗旨</strong></p> 
 <p align="justify">　　加强研究所和高校之间的沟通和交流，为热爱生命科学的广大学子提供了解科研、深入科研的机会，激发科研兴趣，鼓励和帮助学子们尽早思考和确立学术发展目标，选拔有潜质的优秀学生继续深造，为国家发现并培养科研人才。</p> 
 <p align="justify">　　 <strong>二、活动时间</strong></p> 
 <p align="justify">　　 2022年7月上旬</p> 
 <p align="justify">　　<strong> 三、活动内容</strong></p> 
 <p align="justify">　　 前沿学术讲座、参观研究所、师生座谈交流等。具体形式待定，另行通知。　　</p> 
 <p align="justify">　　<strong> 四、申请方式</strong></p> 
 <p align="justify">　　 1、申请条件</p> 
 <p align="justify">　　 （1）大学在校生命科学及相关专业、化学、物理、基础医学、药学等专业本科三年级学生（2023届毕业生为主）；</p> 
 <p align="justify">　　 （2）符合本校推免生条件或计划参加全国研究生招生考试；</p>

function isValid(str){
  if(str.indexOf('&') != -1 || str.indexOf('<') != -1 || str.indexOf('>') != -1 || str.indexOf('\'') != -1
    || str.indexOf('\\') != -1 || str.indexOf('/') != -1 || str.indexOf('"') != -1 
    || str.indexOf('%') != -1 || str.indexOf('#') != -1){
    return false;
  }
  return true;
}

    var searchword = $.trim($('#searchword').val());
	if(searchword == "" || searchword == "请输入关键字" || !isValid(searchword)){

      return false;
	}
	$('input[name="keyword"]').val(encodeURI(searchword));
	$('form[name="searchform"]').submit();
  });
