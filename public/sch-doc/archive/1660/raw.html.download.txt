                            <h3>中国科学院大学2027年接收推荐免试生章程</h3>

                            <div class="b-abody sanji_content">
                                <p style="text-align:center;line-height:33px"><strong><span style=";font-family:仿宋;font-size:19px">第一章 </span></strong><strong><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px">&nbsp;</span></strong><strong><span style=";font-family:仿宋;font-size:19px">总则</span></strong></p><p style="text-indent:37px;text-align:justify;text-justify:inter-ideograph;line-height:33px"><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">第一条</span> </span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px">&nbsp;</span><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">为加强中国科学院大学（以下简称</span><span style="font-family:仿宋">“国科大”）接收优秀应届本科毕业生免试攻读研究生（以下简称“推免生”）工作的</span></span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">管理，</span></span><span style=";font-family:仿宋;font-size:19px">保证接收推免生工作的顺利进行，保障</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">推免生选拔质量</span></span><span style=";font-family:仿宋;font-size:19px">，特制定本章程。</span></p><p style="text-indent:37px;text-align:justify;text-justify:inter-ideograph;line-height:33px"><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">第二条</span> </span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px">&nbsp;</span><span style=";font-family:仿宋;font-size:19px">推免生接收工作坚持公开、公平、公正原则，在对推免申请</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">者</span></span><span style=";font-family:仿宋;font-size:19px">进行全面考查综合评价的基础上，择优选拔、程序透明、操作规范、结果公开。</span></p><p style="text-indent:37px;text-align:justify;text-justify:inter-ideograph;line-height:33px"><span style=";font-family:仿宋;font-size:19px">第三条</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px">&nbsp;&nbsp;</span><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">推免生招收类型分为推免硕士生和直博生。</span><span style="font-family:仿宋">招生单位对报考本单位的推免生组织综合考核，择优录取为硕士或博士研究生。</span></span></p><p style="text-indent:37px;text-align:justify;text-justify:inter-ideograph;line-height:33px"><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">第四条</span> </span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px">&nbsp;</span><span style=";font-family:仿宋;font-size:19px"><span style="font-family:仿宋">除专业学位中的</span><span style="font-family:Times New Roman">125100</span><span style="font-family:仿宋">工商管理、</span><span style="font-family:Times New Roman">125200</span><span style="font-family:仿宋">公共管理、</span><span style="font-family:Times New Roman">125601</span><span style="font-family:仿宋">工程管理及</span><span style="font-family:Times New Roman">125603</span><span style="font-family:仿宋">工业工程与管理</span></span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">专业</span></span><span style=";font-family:仿宋;font-size:19px">以外，国科大各培养单位（具体指中国科学院所属研究院、所、中心、园、台、站及国科大所属各院系，下同）所有硕士招生专业均有接收推免硕士生资格。</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">各培养单位</span></span><span style=";font-family:仿宋;font-size:19px">推免</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">硕士</span></span><span style=";font-family:仿宋;font-size:19px">生具体招生专业及拟接收人数见</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span style="font-family:仿宋">当年</span></span><span style=";font-family:仿宋;font-size:19px">公布的</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:19px"><span
