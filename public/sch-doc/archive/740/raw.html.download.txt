  <!--文章正文--><div class="trs_editor_view TRS_UEDITOR trs_paper_default trs_word"><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">为做好2027年“推免生”（全称为“推荐优秀应届本科毕业生免试攻读研究生”)的接收工作，中国科学技术大学能源科学与技术学院（中国科学院广州能源研究所）现启动预报名工作。现将有关事项说明如下：</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">一、关于能源学院</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">为贯彻中国科学院“全院办校、所系结合”的办学方针，深化科教融合，促进学科发展和人才培养，中国科技大学与中国科学院广州能源所共建中国科学技术大学能源科学与技术学院（简称能源学院）。能源学院录取的研究生属于中国科学技术大学学籍，硕士研究生和直博生第一年在中国科大本部完成主要课程学习，第二年开始在广州能源所进行科研实践和学位论文，毕业时颁发中国科学技术大学毕业证书和学位证书。研究生在学期间的学籍管理、培养方案、学位授予等按照中国科大统一要求执行，日常管理按能源学院要求执行。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">能源学院目前设有动力工程及工程热物理和化学工程与技术两个一级学科硕士、博士学位点及博士后流动站、地质学、环境科学与工程和材料科学与工程三个学术型硕士学位点，能源动力、材料与化工专业领域工程硕士、博士学位点。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">推免生专业背景需求：能源动力、化学、化工、电气、环境科学与工程、材料等相关专业。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">二、网上报名</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">请登录中国科学技术大学研究生报考服务系统https://xspt.ustc.edu.cn/，进入“推免生预报名”，选择能源科学与技术学院（广州能源所），学院代码：178，按照报名要求填写信息和上传相关材料（已参与过科学营的同学无需参加本次预报名）。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">网上报名时间：即日起至9月11日24:00</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">三、申请条件</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">1．拥护中国共产党的领导，愿为祖国建设服务。品德良好，遵纪守法，诚实守信，学风端正，无考试作弊和剽窃他人学术成果以及其他违纪言行受纪律处分情况（处分期内）；录取后至开学前，若受到所在学校处分，将取消研究生录取资格；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">2．已获得推荐免试资格的优秀应届本科毕业生；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">3．学术研究兴趣浓厚，有良好的科学精神，有较强的创新意识、创新能力和专业能力倾向；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">4．本科阶段学习成绩特别是专业成绩突出；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">5．外语水平良好，具有较强的外语听、说、读、写应用能力；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">6．身心健康，符合申请学科的体检要求。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">四、提交材料</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">将以下所有申请材料（含各种证明材料）按线上提交顺序汇总至一个PDF文件，上传到报名系统的“个人材料汇总”处，否则将视为材料不完整。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">1.报名登记表（网上报名后生成的表格打印后必须本人手写签名）；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">2.有效身份证件正反面扫描件；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">3.学生证扫描件（含个人信息页和学期注册页）；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">4.截止目前的成绩单（有学校教务部门或所在院系公章）与总评成绩排名证明（有学校教务部门或所在院系公章）；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">5.外语水平证明材料（大学生英语四/六级、托福、雅思等证书）；</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">6.个人能力证明材料（能体现自身能力的获奖证书复印件、专利、学术论文等）。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);"><strong>申请人务必承诺提交的申请材料真实、准确，若弄虚作假，一经发现，将取消其研究生资格，并通报申请人所在学校。</strong></span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">五、材料审核及录取</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">1.我院对申请材料进行初审，面试名单将通过中国科学技术大学研究生报考服务系统公布并通过系统短信通知；未入选者，不再另行通知。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">2.面试时间初定9月中下旬，采取现场面试方式进行（地点:广州），具体安排另行通知。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">3．凡通过面试，拟接收的推免生，应在规定时间内，通过教育部“推免服务系统”与能源学院互动完成报名、复试确认、拟录取等各项系统操作。超过规定时间，未完成相关操作或未落实接收单位的申请人不再保留拟接收资格，原有的拟接收资格自动失效。</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;; color: rgb(0, 0, 0);">六、其他</span></p><p style="text-indent: 2em; text-align: justify;"><span style="font-family: &quot;times new roman&quot;;
