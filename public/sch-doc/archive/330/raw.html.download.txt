<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">一、招生计划及专业安排</span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">我校</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2027</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年通过推免方式接收优秀应届本科毕业生攻读研究生（简称“推免生”），包括学术学位硕士生、专业学位硕士生以及直接攻读博士生（简称“直博生”）。</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">可接收推免生的招生学科专业及名额详见我校研究生招生信息网公布的</span><span style="color: rgb(0, 0, 0); font-family: times new roman; font-size: 21px;">202</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">7</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年各院系接收推免生工作细则。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">二、申请基本条件</span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．国内高校</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2027</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">届优秀应届本科毕业生（</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2027</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年我校研究生入学报到前可获得本科毕业证书），已获得本科所在学校的推免资格。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．品德优良，遵纪守法，身心健康。诚实守信，学风端正，无考试作弊、剽窃他人学术成果或其他违法违纪行为，无受处分（处罚）记录。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．申请直博生的考生，除满足以上条件外，本科阶段的学习成绩应名列专业前茅，有较强的科研创新能力，具有博士生培养潜质。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">三、工作程序</span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">（一）推免生预报名</span></strong></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">为规范考生申请我校</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2027</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年推荐免试研究生及参加我校组织的复试，我校自即日起开通“华中科技大学推免研究生预报名系统”。该系统为我校接收推免研究生的辅助系统，用于采集考生信息、组织复试考核等。所有考生均通过预报名系统提交申请材料。院系对已报名考生进行审核后确定进入复试考核的考生名单，组织复试考核。复试考核成绩作为推免生录取的依据。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">（二）正式报名</span></strong></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">已获得所在高校推荐免试资格的考生，应按照工作安排通过教育部“全国推荐免试攻读研究生（免初试、转段）信息公开管理服务系统”（以下简称“推免服务系统”）完成正式报名及后续程序。各院系根据考核结果和报名情况，分批发放复试通知及待录取通知。如果考生超出院系规定时间未接受复试通知，院系可撤销对考生的复试通知。如果考生超出院系规定时间未接受待录取通知，院系可撤销对考生的待录取通知。如果相关院系拟招收推免生计划仍有余额，且有预推免考核合格生源，可按照前述程序继续通过“推免服务系统”接收考生。</span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">（三）拟录取名单上报</span></strong></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">根据我校拟接收推免生计划数，按期确认待录取的考生，视为同意将我校作为其唯一录取学校。学校在规定时间审核待录取考生名单，并将拟录取名单公示后上报教育部审核。</span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">四、有关工作规定</span></p>
<p style="background: rgb(255, 255, 255); line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．学校和院系不断完善推免生选拔工作机制，加强复试考核工作规范管理，落实信息公开公示，确保择优选拔、公平公正。复试考核成绩低于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">6</span></span><span style="color: rgb(0, 0, 0); font-family: times new roman; font-size: 21px;">0</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">分者（按满分</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span></span><span style="color: rgb(0, 0, 0); font-family: times new roman; font-size: 21px;">00</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">分折算后），不予录取。对考生进行思想政治素质和品德考核，思想品德考核不合格者，不予录取。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．建立常态化培训。加强对考核专家、工作人员的遴选管理，对考核专家、工作人员进行政策、业务、纪律等方面的培训，明确工作纪律、工作程序、工作规则和考核标准。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．落实回避制度。对利益相关人员，分类落实回避制度，分类进行监督管理。申请或报名我校推免生招生的考生均应按照要求主动报备在我校是否存在利益关系人。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: times new roman; font-size: 21px;">4</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．考生应保证提交的申请材料的真实性和准确性。若考生提交虚假信息，一经查实，取消其录取资格。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;">五、有关说明</span></p>
<p style="background: rgb(255, 255, 255); line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．根据学校研究生奖助学金管理文件，推免生可优先参评各类奖学金。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．学费、住宿费等按照有关规定执行，以报湖北省物价部门备案标准为准。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．推免招生过程中未按回避制度规定报备且影响推免招生工作过程和结果公平公正的学生，我校将取消其推免录取资格。拟录取的推免生在本科毕业后至研究生入学前出现严重违法违规违纪行为的，我校将取消其推免录取资格。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">4</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">拟录取推免生不得再报名参加当年全国硕士研究生招生考试，否则取消其推免录取资格。</span></span></p>
<p style="line-height: 36px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312,fangsong_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">5</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．推免生的正式录取通知书预计于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2027</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">6</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">月发放。</span></span></p>
