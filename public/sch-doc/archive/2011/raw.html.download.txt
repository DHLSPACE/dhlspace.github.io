				<h1>中国科学院新疆理化所“2023走进中科院，看大美之疆”大学生夏令营报名通知</h1>
				<h5><span id="author">作者：</span><span id="source">来源：</span><font>发布时间：2023-05-16</font></h5>
				<div class="detail">
					<div class=TRS_Editor><div class="Custom_UnionStyle">
<p align="justify">　　<span>中国科学院新疆理化技术研究所始建于1961年。研究所围绕国家发展战略，面向国家重大需求、面向新疆区域经济社会发展需求，在资源化学、多语种信息技术、光电晶体、固体辐射物理、热敏电阻、环境功能材料、痕量检测技术等领域为国家和新疆科技发展做出了突出贡献，是中国科学院部署在新疆的国家战略科技力量。1987年国务院学位委员会批准的硕士学位授予权单位之一，2004年经中国科学院批准增列博士培养点，拥有有机化学、材料物理与化学两个双一流学科，共有在学研究生400人（其中硕士生139人、博士生165人、国际学生17人、联培生79人），累计培养1581名研究生，在站博士后30人。</span>&nbsp;</p>
<p align="justify">　　<span>根据中科院和教育部“协同育人”的要求，新疆理化所决定举办“202</span><span>3</span><span>走进中科院，看大美之疆”大学生夏令营，旨在引导青年学生接触化学、</span><span>药学、</span><span>材料科学、计算机、电子电气学科</span><span>等</span><span>前沿热点问题，培养对科研的兴趣，促进优秀在校大学生之间的交流，增进对新疆、乌鲁木齐、新疆理化所了解。期间，将安排参观实验室、近距离聆听科学家专题报告、与导师和研究生座谈、</span><span>参与科研项目、市内参观</span><span>、组织推免生面试等丰富多彩的活动。&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>欢迎广大优秀学子踊跃报名！&nbsp;</span>&nbsp;</p>
<p align="justify"><strong>　　</strong><span><strong>一、活动时间和规模</strong>&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>20</span><span>23</span><span>年7月1</span><span>6</span><span>日-</span><span>23</span><span>日（具体时间和活动安排</span><span>以通知为准）</span>&nbsp;</p>
<p align="justify">　　<span>二、营员人数及招募对象&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>1</span><span>.</span><span>学员录取人数为</span><span>5</span><span>0名左右&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>2</span><span>.</span><span>化学、药学、中药学、材料、</span><span>物理、</span><span>电子科学与技术、计算机或相近专业本科生（202</span><span>4</span><span>年毕业）</span>&nbsp;</p>
<p align="justify">　　3<span>.</span><span>在学期间学习成绩优秀，可获得推免资格</span><span>及一志愿报考者</span><span>优先；对有出色科研成果的申请者成绩标准可适当放宽&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>4.</span><span>英语达到国家四</span><span>/</span><span>六级水平（</span><span>425</span><span>分以上）</span>&nbsp;</p>
<p align="justify">　<strong>　<span>三、申请</span><span>流程</span></strong>&nbsp;</p>
<p align="justify">　　<span>1.报名时间：</span><span>即日起至6月2</span><span>5</span><span>日&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>2.</span><span>请登录科教结合协同育人网站<a href="http://kjxt.ucas.ac.cn">http://kjxt.ucas.ac.cn</a>，点击页面右侧的“夏令营报名入口”，注册成功以后登录系统</span><span>后</span><span>选择</span><span>80028新疆理化技术研究所</span><span>并</span><span>按要求如实填写各项信息，</span><span>并发送电子版材料（材料清单见下）</span><span>。&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>3.入选通知将通过邮件发送至入选人员邮箱，届时未接到入选通知的同学为未入选者，不再另行通知。</span>&nbsp;</p>
<p align="justify">　　<strong><span>四、</span><span>提交材料</span><span>清单</span></strong>&nbsp;</p>
<p align="justify">　　<span>1.</span><span>《中国科学院大学</span><span>2023</span><span>年大学生夏令营活动申请表》（从报名系统中下载，并手写签名）</span>&nbsp;</p>
<p align="justify">　　<span>2.</span><span>本科成绩单和专业排名证明（加盖教务处公章）</span>&nbsp;</p>
<p align="justify">　　<span>3.身份证正反面及学生证扫描件</span>&nbsp;</p>
<p align="justify">　　<span>4.</span><span>英语四</span><span>/</span><span>六级成绩单复印件</span>&nbsp;</p>
<p align="justify">　　<span>5.其它材料：如推荐信、获奖证书、发表论文、专利及其它具有参考价值的证明材料（如有则提供）</span>&nbsp;</p>
<p align="justify">　　<span>请6月</span><span>25</span><span>日前将以上材料电子版按照上述顺序合并生成一份PDF文件（大小不要超过10M）发至邮箱</span><span><a href="mailto:xtipce@ms.xjb.ac.cn"><span>xtipce@ms.xjb.ac.cn</span></a></span><span>。文件命名为“20</span><span>23</span><span>夏令营</span><span>-</span><span>姓名-</span><span>学校名称</span><span>-</span><span>专业名称</span><span>”，邮件主题同上。营员的申请材料如有弄虚作假，一经查实，取消营员所获得的资格。</span>&nbsp;</p>
<p align="justify">　<strong>　</strong><span><strong>五、其他事项</strong>&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>1</span><span>.</span><span>夏令营期间评为优秀营员，获得本校外推资格的营员可直接接收为我所推免生，同时优先获得直博资格。&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>2.</span><span>新疆理化所将为营员提供夏令营期间免费食宿。另外，按疆内生源</span><span>3</span><span>00元/人，疆外生源</span><span>10</span><span>00元/人的标准发放一次性交通补贴。&nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>3.</span><span>夏令营活动期间学生安全由本人负责，我所将会为每位营员购买人身意外伤害保险。</span>&nbsp;</p>
<p align="justify">　　<span>4</span><span>.参加夏令营的营员必须遵守新疆</span><span>理化所</span><span>的相关规定，服从安排，注意安全。</span>&nbsp;</p>
<p align="justify">　　<span>5</span><span>.营员报到后须全程参加夏令营活动，无故擅自离营者，将取消相关费用资助。</span>&nbsp;</p>
<p align="justify">　<strong>　</strong><span><strong>六、联系方式</strong>&nbsp;</span>&nbsp;</p>

<p align="justify">　　<span>地址：乌鲁木齐市</span><span>新市区科学二街181</span><span>号中国科学院新疆理化技术研究所研究生部 &nbsp;</span>&nbsp;</p>
<p align="justify">　　<span>邮编：830011&nbsp;</span>&nbsp;</p>

<script type="text/javascript">
	function isValid(str){
		if(str.indexOf('&') != -1 || str.indexOf('<') != -1 || str.indexOf('>') != -1 || str.indexOf('\'') != -1
			|| str.indexOf('\\') != -1 || str.indexOf('/') != -1 || str.indexOf('"') != -1
			|| str.indexOf('%') != -1 || str.indexOf('#') != -1){
			return false;
	}
	return true;
}
$(function(){
	$('#sub-pc').click(function(){
		var searchword = $.trim($('#searchword').val());
		if(searchword == "" || searchword == "请输入关键字" || !isValid(searchword)){
			alert("请输入关键词后再进行提交。");
			return false;
		}
		$('input[name="keyword"]').val(encodeURI(searchword));
		$('form[name="searchform"]').submit();
	});

	$('#sub-mobile').click(function(){
		var iptSword = $.trim($('#iptSword').val());
		if(iptSword == "" || iptSword == "请输入关键字" || !isValid(iptSword)){
			alert("请输入关键词后再进行提交。");
			return false;
		}
		$('input[name="keyword"]').val(encodeURI(iptSword));
		$('form[name="searchforms"]').submit();
	});
});

         }
     });
});
