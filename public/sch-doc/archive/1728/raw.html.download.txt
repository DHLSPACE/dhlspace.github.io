</span></p><p><span style="font-size:19px;font-family:宋体">　　（八）身体健康状况符合规定的体检标准，心理健康状况良好。</span><span style="font-size:19px;font-family:宋体">  </span></p><p><span function isValid(str){
  if(str.indexOf('&') != -1 || str.indexOf('<') != -1 || str.indexOf('>') != -1 || str.indexOf('\'') != -1
    || str.indexOf('\\') != -1 || str.indexOf('/') != -1 || str.indexOf('"') != -1 
    || str.indexOf('%') != -1 || str.indexOf('#') != -1){
    return false;
  }
  return true;
}
