<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">学校按照学科门类、专业学位类别或专业确定初试成绩基本要求，各学院根据招生计划、考试成绩和差额复试比例确定本单位初试成绩基本要求（不低于学校初试成绩基本要求），并以此确定复试考生名单。复试形式和内容由学校和各学院根据各学科（类别）、各专业（领域）培养要求、相关知识及能力考核标准确定。复试具体安排和要求在复试前通过学校研招网和各学院网站向考生公布。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">说明：</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">1.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">复试由报考学院负责组织，复试前将对考生毕业证（结业证）、学生证等报名材料原件及考生资格进行审查，对不符合教育部规定者，不予复试或取消成绩。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">我校复试采取差额形式，差额比例一般不低于</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">120%</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">，各专业可根据生源情况进行适当调整，若合格生源比例不足，则按实际合格生源数组织复试。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">3.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">调剂工作的具体要求和程序在复试前通过学校研招网向考生公布。</span></span></p>
<p style="text-align: justify;"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">六、录取</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">根据国家下达的招生计划、教育部当年录取工作的有关规定，考生入学考试总成绩（含初试和复试）及其在校学习成绩和思想品德表现、业务素质以及身体健康状况等，确定拟录取考生的名单。复试、体检、思想品德考核不合格者，均不予录取。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">思想政治素质和品德考核是保证入学新生质量的重要工作环节，对于思想品德考核不合格者不予录取。考生诚信状况是考生思想品德考核的重要内容和录取的重要依据。对在全国硕士研究生招生考试中违规或作弊的考生，按照《国家教育考试违规处理办法》严肃处理。根据《中华人民共和国刑法修正案</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">(</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">九</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">)</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">》和《关于办理组织考试作弊等刑事案件适用法律若干问题的解释》，研究生招生考试为国家教育考试，触犯刑法的，一律移交公安机关处理，将依法追究法律责任。相关单位将考生在硕士研究生招生考试中的违规或作弊事实记入《国家教育考试考生诚信档案》，并将考生的有关情况通报其所在学校或单位，记入考生人事档案，作为其今后升学和就业的重要参考依据。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">拟录取名单确定后，考生须提交本人思想政治和品德情况的现实表现材料。考生现实表现材料，需由考生本人档案或工作所在单位的人事、政工部门加盖印章。</span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">新生录取通知书由录取学院发放，其中录取类别为非定向的新生由学院研究生科发放调档函，个人档案必须在入学前（以学校当年开学报到时间为准）调入学院；录取类别为定向（强军计划除外）的考生必须在录取前将签订好的定向协议书（电子科技大学研招网</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">“</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">资料下载</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">”</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">）、定向就业合同（复印件）交至录取学院。非全日制硕士研究生原则上录取为定向。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">按照教育部要求，凡是对考生的学历（学籍）信息有疑问的，学校可要求考生在规定时间内出具教育部学历（学籍）认证书（网址：</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">yz.chsi.com.cn</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">），否则不予录取。</span></span></p>
<p style="text-align: justify;"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">七、学制</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">金融</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">(025100)</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">、（全日制）工商管理</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">(MBA 125100)</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">专业的学制为</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">年，其他专业学制为</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">3</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">年，具体以入学当年培养方案为准。</span></span></p>
<p style="text-align: justify;"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">八、学费</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">学费标准按入学当年国家及四川省有关文件执行。根据川发改价格〔</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2019</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">〕</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">357</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">号规定，对于提前毕业或延期毕业的学生，按实际学习年限收费。</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2025</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">年学费标准详见电子科技大学计划财务处网站或电子科技大学研究生招生网公布的《<a href="https://www.jcc.uestc.edu.cn/article/detail?cid=718" target="_self" textvalue="2025级研究生教育收费一览表">2025级研究生教育收费一览表</a><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">》。</span></span></span></span></p>
<p style="text-align: justify;"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 19px;">九、说明</span></strong></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">1.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">考生应当按要求准确填写个人网上报名信息并提供真实材料。考生因网报信息填写错误、填报虚假信息而造成不能考试（含初试和复试）或录取的，后果由考生本人承担。对报考中弄虚作假者（含推免生），不论何时，一经查实，即按有关规定取消报考资格、录取资格、入学资格或学籍。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">研究生培养地点主要在清水河校区、沙河校区以及相关研究生联合培养基地。全日制和非全日制研究生在规定学习年限内，完成培养方案规定的内容，且学位论文答辩通过，达到毕业要求，经学院毕业鉴定合格，学校毕业审核会议通过，准予毕业，颁发毕业证书；其按照培养要求完成规定的培养环节和学分，通过学位论文答辩，达到相应学术水平者，授予硕士学位。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">3.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">我校为全日制硕士研究生提供住宿，非全日制硕士研究生不提供住宿。学校可根据招生情况、培养需要、校区容量及房源情况安排硕士研究生住宿校区、住宿地点及住宿标准。部分录取到联合培养项目的研究生将根据培养需求确定住宿地点（包括其他城市）。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">4.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">学校根据国家相关政策设立有各类研究生奖助学金，包括：国家奖学金、学业奖学金、国家助学金、“三助”助学金以及各类研究生荣誉奖励等。非全日制硕士研究生不参评奖助学金，但可参评部分荣誉奖励（以奖项具体评选办法为准），不参加成都市大学生医疗保险。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">5.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">我校研究生就业根据录取类别：非定向考生自主择业；定向考生按定向协议（合同）就业；其他特殊类型考生按照相关要求办理。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">6.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">考生因报考研究生与所在单位产生的问题由考生自行处理。若因上述问题造成考生不能复试、无法被录取或其他问题，我校不承担责任。</span></span></p>
<p style="text-align: justify; line-height: 32px; text-indent: 32px;"><span style="color: rgb(0, 0, 0);"><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">7.</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">本招生简章由电子科技大学研究生院负责解释，如有与教育部</span><span lang="EN-US" style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 16px;">2025</span><span style="color: rgb(0, 0, 0); font-family: 宋体; font-size: 16px;">年硕士研究生考试招生政策不符之处，以教育部文件为准。招生简章内容如有调整，请以学校最新通知为准。</span></span></p>
