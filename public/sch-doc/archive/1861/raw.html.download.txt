									<h1 class="fl w100 text-center">中科大应用化学与工程学院（长春应化所）2022年硕士研究生调剂简章</h1>
									<div class="fl w100 ccyhsyjs_con_ly marb15 text-center">
										<font>撰稿： </font>
										<font>来源：</font>
										<font>发布时间：2022年03月23日</font>
									</div>
									<div class="TRS_Editor">
 <div style="text-indent: 0px;">
  <div style="text-indent: 0px;">
   <b><font style="line-height: 200%;" size="3">一、拟调剂学科专业</font></b>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 化学（070300）、化学工程与技术（081700）、材料与化工（085600）。</font>
  </div>
  <div style="text-indent: 0px;">
   <b><font style="line-height: 200%;" size="3">二、调剂要求</font></b>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 1. 初试成绩不低于我院2022年硕士研究生复试分数线（详见官网http://yjsb.ciac.cas.cn/zsxx/zxxx/）。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 2. 调入专业与第一志愿报考专业相同或相近，应在同一学科门类范围内；专业背景及科研实践经历满足我所科技发展需求。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 3. 由于各学校初试科目设置及难度存在差异，从我院对考生日后学习和高质量科学研究的要求出发，调剂遵循考试难度与我校相同或相近的原则：优先接收第一志愿报考我校的优秀生源，其他考生第一志愿报考单位原则上应是国内重点高校或中科院科研院所等重要科研机构，欢迎来自双一流大学或化学、化工、材料、生物、物理、电子等一流学科的优秀考生申请调剂。</font>
  </div>
  <div style="text-indent: 0px;">
   <b><font style="line-height: 200%;" size="3">三、调剂流程</font></b>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 1. 申请调剂考生首先须关注“中科院长春应化所科技信息平台”公众号，登录注册后，在功能菜单内“考研调剂”中进行报名，报名截止时间视报名情况在长春应化所教育处主页另行公告。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 2. 申请调剂考生需提供以下材料：</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ①准考证、身份证；</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ②考研成绩单；</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ③往届毕业生本科毕业证、学位证扫描件，应届毕业生学生证；</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ④本科期间成绩单（应届生加盖教务部门公章，往届生加盖档案所在单位人事部门公章）；</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ⑤国家英语等级证书及各类获奖证书；</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; ⑥在网报中学历（学籍）审核未通过的考生，提交学历（学籍）认证报告。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; <b>以上材料按顺序扫描成一个PDF文件（文件命名：姓名-考生编号）发送至yjsb@ciac.ac.cn。</b></font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 3. 我院对申请调剂考生进行资格审查和择优遴选，并电话通知考生参加复试，未获复试资格的考生不再另行通知。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 4. 复试内容及时间</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 复试采取网络复试，复试内容及要求请参照我院的《2022年硕士研究生招生复试工作方案》执行。具体复试时间另行通知。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 5. 调剂考生待“全国硕士研究生招生调剂服务系统”开通后，须在该调剂系统进行网上报名。</font>
  </div>
  <div style="text-indent: 0px;">
   <font style="line-height: 200%;" size="3">&nbsp; &nbsp; &nbsp; 6. 未按本调剂流程进行调剂报名和复试的，调剂申请无效。</font>
  </div>

	$("a.font").click(function(){
		var _obj = $("div#cas-article");
		var _nsize = parseFloat(_obj.css("font-size"), 10);
		var _unit = _obj.css("font-size").slice(-2); //获取单位 
		if ($(this).attr("class") == "bigger font") {
			if (_nsize <= 22) {
				_nsize += 2;
			}
		} else if ($(this).attr("class") == "smaller font") {
			if (_nsize >= 12) {
				_nsize -= 2;
			}
		}
		_obj.css("font-size", _nsize + _unit).find("p,div,span,font").css("font-size", _nsize + _unit);
	});
	
	
		
		//附件
		var appLinkArr = new Array(); //附件路径
		var appLinkStr = '';
		appLinkArr = appLinkStr.split('|');
		var appDescArr = new Array(); //附件名称
		var appDescStr = '';
		appDescArr = appDescStr.split('|');
		if(appLinkArr[0] != '' && appDescArr[0] != ''){
			var appHtml = "";
			$.each(appLinkArr, function(i, str) {
				if(str.indexOf('doc') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-word-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
				if(str.indexOf('xls') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-excel-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
				if(str.indexOf('ppt') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-powerpoint-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
				if(str.indexOf('pdf') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-pdf-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
				if(str.indexOf('txt') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-text-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
				if(str.indexOf('rar') != -1 || str.indexOf('zip') != -1){
					appHtml += '<li><a href="' + str + '"><i class="fa fa-file-archive-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
				}
			});
			$(".cas-wrap-appendix ul").html(appHtml);
		}else{
			$(".cas-wrap-appendix").hide();
		}
	});

	
	//文档浏览量
		$("#pageview").casclick({//此处的id与span的标签id对应即可
			platId : "2",//平台id，中文主站平台1，院属单位平台2，重要网站平台3
			siteId : "414",//站点id，
			docId : "553935"//文档id
		});

		//文档点赞量
		$("#like").caslike({//此处的id与span的标签id对应即可
			platId : "2",//平台id，中文主站平台1，院属单位平台2，重要网站平台3
			siteId : "414",//站点id，
			docId : "553935"//文档id
		});
		
		//作者
		var docauthor = "";
		if(docauthor == ""){
			$("#author").hide();
		}
		
		//来源
		var docsourcename = "";
		if(docsourcename == ""){
			$("#source").hide();
		}
</script>


</body>
	
</html>
