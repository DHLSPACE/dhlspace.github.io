          <span class="gp-f22 gp-bold">国际中文教师奖学金</span>

             <div>

<a href="#">国际中文教师奖学金</a>
             </div>

           </div>
        <div class="gp-subRight-con">
          <div class="subCon">
             <div class="gp-article gp-f16">
 <p style="text-align: justify; color: rgb(0, 0, 0);"><span style="font-family: 宋体; font-size: 16px;">&nbsp;</span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0;text-align:justify;text-justify:inter-ideograph"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 为满足国际社会对日益增长的中文教育类人才的需求，促进世界各国中文教育的发展，助力国际中文教育人才的成长，教育部中外语言交流合作中心（以下简称中心）设立国际中文教师奖学金（以下简称奖学金），聚焦培养合格的海外 中文教师。孔子学院、独立设置的孔子课堂，部分中文考试考点，外国相关教育机构、高校中文师范专业/中文院系、国外有关中文教学行业组织、中国驻外使（领）馆等（以下简称推荐机构）可推荐优秀学生和在职中文教师到中国大学（以下简称接收院校）学习和进修国际中文教育及相关专业。</span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0;text-align:justify;text-justify:inter-ideograph"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 北京师范大学作为接收院校，2026学年度招生类别包括国际中文教育专业博士研究生、国际中文教育专业硕士研究生、汉语国际教育专业本科生(北师大珠海校区培养，地址：广东省珠海市)、一学年研修生和一学期研修生(<span style="font-family: 宋体, SimSun; font-size: 16px; text-align: justify; text-wrap-mode: wrap;">汉语国际教育</span>专业在北师大珠海校区培养，地址：广东省珠海市）。</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="font-family: 宋体, SimSun;"><strong><span style="color: #0000FF; letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 一、资助对象</span></strong></span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 1.非中国籍人士;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 2.对华友好，无违法犯罪记录，遵守中国政府的法律、 法规和学校的规章制度;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 3.身心健康，品学兼优;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 4.有志于从事中文教育、教学及相关工作;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 5.年龄为16-35周岁(统一以2026年9月1日计)。在职中文教师放宽至45周岁，本科奖学金申请者一般不超过25周岁。</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp;</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="font-family: 宋体, SimSun;"><strong><span style="color: #0000FF; letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 二、奖学金类别及申请条件</span></strong></span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0"><span style="font-family: 宋体, SimSun;"><strong><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 第一类:中文师资类项目</span></strong></span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0"><span style="font-family: 宋体, SimSun;"><strong><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 1. 国际</span></strong><strong><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">中文</span></strong><strong><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">教育专业博士研究生</span></strong></span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0;line-height:21px"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 2026年9月入学，资助期限为4年。</span></p> 
<p style="margin-top:4px;margin-right:0;margin-bottom:14px;margin-left:0;text-indent:0;line-height:21px"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 具有硕士学历，硕士专业为对外汉语、语言学、国际中文教育或者教育相关专业。中文水平考试成绩达到HSK(六级)240分、HSKK(高级)65分，且有3年（含）以上国际中文教育或相关领域全职工作经历。提供毕业后拟任教机构工作协议或相关证明者优先。</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="font-family: 宋体, SimSun;"><strong><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 2.&nbsp;国际中文教育专业硕士研究生</span></strong></span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 2026年9月入学，资助期限为2年。</span></p> 
<p style="margin: 4px 0 14px;text-indent: 0"><span style="letter-spacing: 0px; font-size: 16px; font-family: 宋体, SimSun;">&nbsp; 具有大学本科学历。中文水平考试成绩达到HSK(六级)220分、HSKK(高级)65分。提供毕业后拟任教机构工作协议或相关证明者优先。</span></p>
