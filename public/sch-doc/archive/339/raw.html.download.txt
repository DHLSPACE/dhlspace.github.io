<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="font-family: 仿宋_GB2312; font-size: 21px;">为深入贯彻落实习近平新时代中国特色社会主义思想和关于研究生教育的重要指示精神，根据教育部关于硕士研究生招生复试录取工作的相关要求，结合学校实际情况，制定</span><span style="font-family: Times New Roman; font-size: 21px;">2024</span><span style="font-family: 仿宋_GB2312; font-size: 21px;">年硕士研究生招生复试录取工作方案，具体如下。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">一、组织机构</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">学校研究生招生工作领导小组全面领导硕士研究生招生复试录取工作；研究生院负责落实相关规定并组织考务工作；各院系研究生招生工作领导小组具体负责本单位的复试录取工作，拟定复试工作细则并组织实施。学校成立复试突发事件应急管理领导小组，研究处置研究生招生复试工作中的突发应急事件。学校和院系设立监察组，监督复试各环节工作情况，组织现场督查。</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">二、招生计划</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．根据</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">教育部下达</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">给</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">学校的硕士</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">研究生</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">招生</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">总</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">计划，</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">学校按院系进行分配，院系可进一步按内设系所、学科（专业）、类别（领域）等对</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">计划进行</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">细分。因正式计划下达或实际录取推免生人数等影响，最终拟招考计划数以复试前公布的复试工作细则为准。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．根据学校划定的分数线，部分合格生源不足的学科（专业）可按照教育部和学校调剂工作相关规定申请生源调剂，并按</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">规定</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">公布拟调剂计划数和调剂细则。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．院系未完成的招生计划退回学校统筹再分配。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">三、复试组织</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">（一）复试资格</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．学校公布</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">2024</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">年硕士研究生招生复试基本分数要求和各院系复试分数线。院系在复试前要对满足分数线考生的报考资格和复试资格进行审核，考生须提供的具体材料详见学校研究生招生</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">信息网</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">（以下</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">简称</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">“</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">研招网</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">”）</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">公告</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">及各院系复试工作细则。复试前要严格采取“两识别”（人脸识别、人证识别）、“四比对”（报考库、学籍学历库、人口信息库、诚信档案库数据比对）等措施，加强对考生特别是报考专项计划、申请加分等有关考生的身份复核。未通过资格审核的考生不得参加复试。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．复试采取差额形式，合格生源充足的院系差额比例一般不低于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">120%</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">。合格生源不足</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">120%</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">，按实际情况组织复试。复试名单由各院系在发布复试工作细则时公布。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">（二）复试方式</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2024</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">年硕士研究生复试采取线下现场复试方式，具体安排以学校研招网公布的院系复试工作细则为准。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．所有参加复试的考生均需通过学校硕士生复试报到系统进行网上报到确认。考生须确认复试信息，提交复试资格审核材料，并在线签署《考试诚信承诺书》。招生院系将对考生提交的复试资格审核材料进行线上审核。资格审查不合格者不予复试。对个人信息或材料弄虚作假者，一经查实，按有关规定取消报考资格、复试资格、录取资格或学籍。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">（三）复试收费</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">按照湖北省有关文件，对参加复试的考生按每人</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">100</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">元标准收取复试费。考生可在复试报到确认时进行网上缴费。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">（四）复试时间</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．学校综合考虑招生规模、学科专业特点，在</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">月</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">29</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">日至</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">31</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">日集中组织复试。考生可关注学校研招网及各院系网站通知，提前做好准备。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．考生未按时进行复试报到确认及缴费；或在经联系后，在院系复试全部结束时仍未参加复试的，视为自动放弃复试资格。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．根据教育部招生工作管理规定，如学校认为有必要，可对相关考生再次复试。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;">（五）复试内容及要求</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．各院系根据学科专业特点确定复试内容和形式，并在复试工作细则中予以公布。复试内容包括思想政治品德表现考核、专业理论知识测试、综合素质和能力测试、外语听说能力测试等。复试形式一般包括口头问答、笔试、上机、实验</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">/</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">实践技能测试、综合面试等。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．各院系可要求考生提供个人简历、学习成绩单、各类奖励情况、科研成果、毕业论文或实习实践报告等材料，加强对考生既往学业、一贯表现、科研能力、综合素质和思想品德等情况的全面考察。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．参加管理类综合能力科目</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">考试</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">的考生、同等学力考生、成人教育应届本科毕业生及复试时尚未取得本科毕业证书的自考和网络教育考生，在</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">符合复试资格的前提下，还</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">须按规定参加相关科目的加试。具体方式和内容详见相关院系复试工作细则。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">4</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．考生须</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">遵守线下复试的各项规定。</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">统一开考</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">的笔试</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">、上机</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">等测试，</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">开考后</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">15</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">分钟</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">未到场</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">者</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">不得入场</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">；采取</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">逐</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">个面试等</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">考核</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">方式</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">的，</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">须</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">在</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">规定</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">时间内在指定地点候</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">考</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">四、调剂工作</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．申请调剂的考生须符合教育部及学校相关规定要求。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．符合条件的申请调剂考生超过计划数时，参照教育部相关规定和院系发布的调剂细则，择优</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">遴选，</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">差额确定进入调剂复试的考生名单。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．所有调剂工作均</span></span><span style="color: rgb(0, 0, 0); font-family: times new roman; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">通过教育部指定的</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">“</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">全国硕士生招生调剂服务系统</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">”</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">进行</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">五、录取工作</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．总成绩</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">=</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">初试成绩（按百分制折算）×</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">60%+</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">复试成绩×</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">40%</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">2</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．复试成绩总分为</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">100</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">分，复试不及格者（低于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">60</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">分）不予录取。未参加复试者不予录取。各类加试成绩不及格者（低于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">60</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">分）不予录取。思想政治素质和品德考核不合格者不予录取。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．各院系按要求公示复试成绩。在考生思想政治素质和品德考核合格、复试成绩及格、加试成绩及格（对需加试的考生）的前提下，各院系研究生招生领导小组根据本单位招生计划、复试录取规则、考生综合成绩、思想政治表现、身心健康状况等择优确定拟录取名单。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">4</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．对符合国家、教育部等相关文件精神，提供证明材料经过核实的考生，予以加分或在同等条件下优先录取。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">5</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．考生体检安排在拟录取后进行。体检不合格者不予录取。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">6</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．拟录取名单由学校统一公示，公示时间不少于</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">10</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">个工作日。未经公示的考生一律不予录取。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">7</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．按规定</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">符合</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">保留入学资格条件</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">的</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">考生，须在拟录取前提出书面申请，由院系审核同意</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">后，</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">报研究生院招生办公室。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">8</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．所有非定向考生的人事档案须转入学校。定向就业考生须在拟录取前提供与单位签订的定向就业协议、</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">劳动合同</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">或</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">工作单位证明</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">。各院系在复试、调剂过程中，应提前将相关管理规定告知报考非全日制专业学位的考生，满足有关要求才能拟录取。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">9</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">．入学后</span><span style="color: rgb(0, 0, 0); font-family: Times New Roman;">3</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">个月内，学校将按照《普通高等学校学生管理规定》有关要求，对所有考生的入学</span></span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">资格</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">进行全面复查。复查不合格的，取消入学资格（或学籍）；情节严重的，移交有关部门调查处理。</span></span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 黑体; font-size: 21px;">六、有关工作要求</span></p>
<p style="line-height: 37px; text-indent: 43px; -ms-layout-grid-mode: char;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; font-size: 21px;"><span style="color: rgb(0, 0, 0); font-family: Times New Roman; font-size: 21px;">1</span><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312; font-size: 21px;">．学校和各院系不断完善复试工作制度，加强复试工作规范管理，建立“一岗多控、多岗监督”机制；发挥和规范研究生导师在复试选拔中的作用，择优选拔、公平公正。</span></span></p>
