<p class="vsbcontent_start">2022年全国硕士研究生招生考试将于12月25-26日举行。16日下午，我校考点工作部门协调会在物质科研楼一楼会议室召开，校党委常委、副校长王晓平，副校长杨金龙出席会议，党政办、宣传部、学工部、保密办、教务处、资产与后勤管理处、基本建设处、保卫与校园管理处、物业中心、校医院、校车队、饮食服务集团、研究生院等相关部门负责人参加了会议。会议由研究生院常务副院长龚流柱主持。</p>
<p class="vsbcontent_img"><img onclick="imgShow(this)" width="400" height="267" src="/__local/7/6D/4D/3019AEF9D1EA5512536F0B26D9A_F06ED068_C89C3.png" border="0" vspace="0" hspace="0" title="" alt="" vsbhref="vurl" vurl="/_vsl/76D4D3019AEF9D1EA5512536F0B26D9A/F06ED068/C89C3" vheight=" 267px" vwidth=" 400px" orisrc="/__local/7/6D/4D/3019AEF9D1EA5512536F0B26D9A_F06ED068_C89C3.png" class="img_vsb_content" style="width: 400px; height: 267px;"> </p>
<p>首先，研究生院常务副院长龚流柱对研究生招生考试工作形势进行分析，今年研究生报考人数持续增加，疫情形势依旧严峻，应严格按照国家要求，做好考试安全与疫情防控工作，特别是提醒黄码考生的及时转码工作。研招办主任朱玉春重点介绍了研究生招生考试防疫方案和部门联动方案。随后，各部门负责人就工作方案进行交流讨论，根据今年的具体情况提出意见和建议，并表示将加强配合、通力协作，全力保障研究生招生考试顺利进行。</p>
<p class="vsbcontent_img"><img onclick="imgShow(this)" width="400" height="300" src="/__local/3/05/13/22689813E6323049286F316CED6_8E141B26_E18C0.png" border="0" vspace="0" hspace="0" title="" alt="" vsbhref="vurl" vurl="/_vsl/3051322689813E6323049286F316CED6/8E141B26/E18C0" vheight=" 300px" vwidth=" 400px" orisrc="/__local/3/05/13/22689813E6323049286F316CED6_8E141B26_E18C0.png" class="img_vsb_content" style="width: 400px; height: 300px;"> </p>
<p>会上，王晓平副校长强调，各部门要提高认识，认真筹备此次研究生招生考试，严格落实各项工作，细化工作方案。考前进行实地演练，扎实做好考务与疫情防控工作，做到工作责任可追溯。</p>
<p class="vsbcontent_end">杨金龙副校长提出要做好突发情况预案，各部门加强联动、及时沟通，确保考试安全与疫情防控相结合。最后杨金龙副校长对各职能部门积极参与本次研究生招生考试工作表示感谢，并希望各部门相互协作，确保本次研究生招生考试工作安全、平稳、有序的完成。</p>
<p class="vsbcontent_end"><br></p>

    $(bigimg).attr("src", src);//设置#bigimg元素的src属性

    $("<img/>").attr("src", src).load(function(){
        var windowW = $(window).width();//获取当前窗口宽度
        var windowH = $(window).height();//获取当前窗口高度
        var realWidth = this.width;//获取图片真实宽度
        var realHeight = this.height;//获取图片真实高度
        var imgWidth, imgHeight;
        var scale = 0.8;//缩放尺寸，当图片真实宽度和高度大于窗口宽度和高度时进行缩放
        
        if(realHeight>windowH*scale) {//判断图片高度
            imgHeight = windowH*scale;//如大于窗口高度，图片高度进行缩放
            imgWidth = imgHeight/realHeight*realWidth;//等比例缩放宽度
            if(imgWidth>windowW*scale) {//如宽度扔大于窗口宽度
                imgWidth = windowW*scale;//再对宽度进行缩放
            }
        } else if(realWidth>windowW*scale) {//如图片高度合适，判断图片宽度
            imgWidth = windowW*scale;//如大于窗口宽度，图片宽度进行缩放
                        imgHeight = imgWidth/realWidth*realHeight;//等比例缩放高度
        } else {//如果图片真实高度和宽度都符合要求，高宽不变
            imgWidth = realWidth;
            imgHeight = realHeight;
        }
                $(bigimg).css("width",imgWidth);//以最终的宽度对图片缩放
        
        var w = (windowW-imgWidth)/2;//计算图片与窗口左边距
        var h = (windowH-imgHeight)/1.8;//计算图片与窗口上边距
        $(innerdiv).css({"top":h, "left":w});//设置#innerdiv的top和left属性
        $(outerdiv).fadeIn("fast");//淡入显示#outerdiv及.pimg
    });
    
    $(outerdiv).click(function(){//再次点击淡出消失弹出层
        $(this).fadeOut("fast");
    });
