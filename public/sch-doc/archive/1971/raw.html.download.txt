text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><br/></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><strong>三、复试内容与要求</strong></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">1.复试内容包括英语面试、专业复试、思想政治品德考核三部分。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">第一部分：英语面试：</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">包括英语听力和口语测试，二者同步进行，由英语面试专家用英语提问，考生需用英语回答，3分钟以内。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">第二部分，专业复试：</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">重点考查考生对专业知识掌握的深度和广度及解决实际问题的能力，对知识灵活运用的程度，了解考生从事科研工作的潜力和创造性。专业复试以面试为主，面试小组对每个考生进行百分制评分和评语记录。该项工作由各专业复试小组负责实施，时间在15分钟左右。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">第三部分，思想政治品德考核：</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">考察考生政治态度、思想品德、工作学习态度、团队合作精神、科研道德及遵纪守法等方面的基本素质。（2分钟左右，与专业复试同时进行。）</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">2.复试环节考生需做3分钟PPT自述，中文、英文均可；请考生于3月30日12：00前将PPT发各复试小组秘书邮箱（邮箱地址请注意后续邮件通知）；PPT自述内容应包括但不限于以下方面：</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">①简要个人简介（教育背景、学习表现等）；②重点介绍本科期间的参与的科研工作情况（含参与的科研活动情况、成果、获奖、毕业论文进展情况等）；　　③攻读硕士学位期间的科研设想、计划等。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><br/></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><strong>四、成绩计算办法</strong></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">1．英语面试（占复试成绩的10%）：采用百分制打分。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">2．专业复试（占复试成绩的90%）：采用百分制打分。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">由各专业复试小组依据专业面试要求（包括对考生思想政治品德考核的内容）对考生进行专业复试，并分别对考生打分，取其平均分作为专业复试成绩。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">3. 成绩计算办法：</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">复试成绩以100分计算，复试成绩=专业复试成绩*90%+英语面试成绩*10%。复试成绩不及格者（60分为及格）不予录取。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">考生总成绩由初试成绩和复试成绩各占50％组成，总成绩=初试成绩/5*50%+复试成绩*50%。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">根据考生总成绩和各专业招生指标数，分专业按总成绩由高到低的顺序录取；复试成绩不及格者（复试成绩低于60分为不及格）不予录取。具体要求以我所《2026年硕士研究生复试规程》为准。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><br/></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;"><strong>五、复试纪律</strong></p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">1.考生在复试前应签署《中国科学院大学2026年硕士研究生招生考试诚信复试承诺书》,承诺学历、学位、个人其它报考信息的准确性和真实性，存在学术道德、专业伦理、诚实守信等方面问题者，一经查实，取消考试、录取或学习资格。</p><p data-index="9" style="text-indent: 2em; text-align: left; font-size: 16px; margin-bottom: 16px; line-height: 1.5em;">2.研究生复试是国家研究生招生考试的重要组成部分，请考生自觉遵守相关考试纪律，不得向他人透露复试内容；其他形式的违纪、作弊行为，一经查实，即按照《国家教育考试违规处理办法》《普通高等学校招生违规行为处理暂行办法》等规定严肃处理，取消录取资格，记入《考生考试诚信档案》。入学后3个月内，将按照《普通高等学校学生管理规定》有关要求，对所有考生进行全面复查。复查不合格的，取消学籍；情节严重的，移交有关部门调查处理。</p><p data-index="9" style="text-indent: 2em; 	function isValid(str){
	  if(str.indexOf('&') != -1 || str.indexOf('<') != -1 || str.indexOf('>') != -1 || str.indexOf('\'') != -1
	    || str.indexOf('\\') != -1 || str.indexOf('/') != -1 || str.indexOf('"') != -1 
	    || str.indexOf('%') != -1 || str.indexOf('#') != -1){
	    return false;
	  }
	  return true;
	}

        var appLinkStr = './P020260325479959248972.docx|./P020260325479959443072.doc|./P020260325479959638398.doc|./P020260325479959811890.doc';
        appLinkArr = appLinkStr.split('|');
        var appDescArr = new Array(); //附件名称
        var appDescStr = '附件1 2026复试规程-考生.docx|附件2 2026考生简历及自述.doc|附件3 考生政审表.doc|附件4. 体检注意事项.doc';
        appDescArr = appDescStr.split('|');
        if(appLinkArr[0] != '' && appDescArr[0] != ''){
            var appHtml = "";
            $.each(appLinkArr, function(i, str) {
                if(str.indexOf('doc') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-word-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
                if(str.indexOf('xls') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-excel-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
                if(str.indexOf('ppt') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-powerpoint-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
                if(str.indexOf('pdf') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-pdf-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
                if(str.indexOf('txt') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-text-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
                if(str.indexOf('rar') != -1 || str.indexOf('zip') != -1){
                    appHtml += '<li><a href="' + str + '"><i class="fa fa-file-archive-o" aria-hidden="true"></i>' + appDescArr[i] + '</a></li>';
                }
            });
            $(".wrap-appendix ul").html(appHtml);
        }else{
            $(".wrap-appendix").hide();
        }
    })
