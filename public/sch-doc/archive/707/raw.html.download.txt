font-family: 宋体, SimSun;">　　<strong>一、报名时间</strong></span></p><p style="text-align:left;text-indent:37px"><span style="font-family: 宋体, SimSun;"><strong><span style="font-size: 19px; font-family: 宋体, SimSun;">报名时限为2026年7月17日-8月14日。</span></strong><span style="font-size: 19px; font-family: 宋体, SimSun;">后续批次招生安排将根据年度招生计划及招录进度另行通告，请持续关注。</span></span></p><p style="margin-left:37px;text-indent:0"><span style="font-family: 宋体, SimSun;"><strong><span style="font-size: 19px; font-family: 宋体, SimSun;">二、</span></strong><strong><span style="font-size: 19px; font-family: 宋体, SimSun;">报名条件   </span></strong></span></p><p style="margin-left:37px;text-indent:0"><span style="font-size: 19px; font-family: 宋体, SimSun;">（一）化学、材料、生物、物理等相关专业2023级本科生（2027届毕业生）</span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">    （二）高水平大学在读，具备推免资格（学校未明确推免资格的，可参照本科学校上一年度推选办法初步判断）。 </span></p><p style="text-align:left;"><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（三）热爱科学事业，有较好的科研潜力，道德品质良好，遵纪守法。 </span></p><p style="text-align:left;"><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（四）品行端正，诚实守信，学风优良，无违法违纪、学术不端、考试作弊记录。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（五）学业成绩优异，专业主干课无重修、补考记录。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（六）英语达到国家四级水平及以上。   </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　  （七）具有较强的调查研究、综合分析问题、解决问题能力。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（八）身体健康状况符合规定的体检标准，心理健康状况良好。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">    招收2027级推免生导师名单（见附件1，持续更新中）</span></p><p style="text-align:left;"><span style="font-size: 19px; font-family: 宋体, SimSun;">    说明：可查阅化学所官网、研究生教育公众号或化学所Bilibili官方账号等，了解化学所总体情况、各实验室及导师研究方向。</span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　<strong>　（二）报名材料   </strong></span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">    1.材料提交要求：全部材料按顺序整合为单个PDF文档，文件命名和邮件主题均为：报考导师姓名/专项名称+本人姓名+本科学校，发送至xialingying@iccas.ac.cn。</span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　2.必交材料  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（1）《中国科学院化学研究所接收2027级推荐免试研究生报名表》（附件2）。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（2）个人简历及专业学习情况介绍（自行撰写，字数不限）。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（3）所在学校教务部门（或院系）盖章的本科成绩单原件(截止当前学习阶段）。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（4）英语等级证书复印件。  </span></p><p style="text-align:left;"><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（5）身份证正反面复印件（置于一页A4纸）。 </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　3.选交材料  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（6）大学期间各类获奖证书。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（7）专家推荐书（1-2份，由副教授或相当职称以上专家推荐）（附件3）。  </span></p><p><span style="font-size: 19px; font-family: 宋体, SimSun;">　　（8）学术论文、专利或其他原创性工作成果的复印件或证明。  </span></p><p style="text-indent:37px"><span style="font-size: 19px;     || str.indexOf('\\') != -1 || str.indexOf('/') != -1 || str.indexOf('"') != -1 
    || str.indexOf('%') != -1 || str.indexOf('#') != -1){
    return false;
  }
  return true;
}

$(function(){
  $('#sub-pc').click(function(){
    var searchword = $.trim($('#searchword').val());
	if(searchword == "" || searchword == "请输入关键字" || !isValid(searchword)){
	  alert("请输入关键词后再进行提交。");
      return false;
	}
	$('input[name="keyword"]').val(encodeURI(searchword));
	$('form[name="searchform"]').submit();
  });
  
  $('#sub-mobile').click(function(){
    var iptSword = $.trim($('#iptSword').val());
	if(iptSword == "" || iptSword == "请输入关键字" || !isValid(iptSword)){

      return false;
	}

	$('form[name="searchform"]').submit();
  });
});
