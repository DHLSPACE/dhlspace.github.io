<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">根据学校奖学金评审工作整体要求和研究生奖励管理办法的有关规定，现就202</span>6年研究生国家奖学金及校级研究生奖学金评审工作通知如下：</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">一、奖励对象</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0);">1.奖励对象为学校在读的具有中华人民共和国国籍、纳入全国研究生招生计划的全日制（全脱产学习）研究生，原则上包括以下各类研究生：非定向学术型硕士研究生、非定向专业学位硕士研究生、非定向学术型博士研究生、非定向专业学位博士研究生以及非在职的少数民族高层次骨干人才计划研究生。</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:16px;margin-left:0;text-indent:28px;text-justify:inter-ideograph;line-height:42px"><span style="letter-spacing: 0px; font-size: 20px; background: rgb(255, 255, 255); color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">2.在规定学制内的研究生，因国家和单位公派出国留学或校际交流在境外学习的，仍具备研究生国家奖学金参评资格。由于以下三种情况的研究生，原则上不具备研究生国家奖学金参评资格：由于因私出国留学、疾病、创业等原因休学未在校学习的研究生；当年毕业的研究生；超出学制的研究生。</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:16px;margin-left:0;text-indent:28px;text-justify:inter-ideograph;line-height:42px"><span style="letter-spacing: 0px; font-size: 20px; background: rgb(255, 255, 255); color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">3.硕博连读研究生在注册为博士研究生之前，按照硕士研究生身份申请；注册为博士研究生后，按照博士研究生身份申请；直博生按照博士研究生身份参与评定；当年入学的博士研究生按照博士研究生新生身份参与评定。</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">二、评审条件</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">研究生国家奖学金及校级奖学金的基本申请条件参见《同济大学学生奖励管理办法》（同济学[2025]23 号）及我院研究生奖学金评定实施细则。</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">三、研究生网上申请流程</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">1.登录</span><strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">同济大学一网通办-办事大厅-服务主题-学工-奖学金</span></strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">，在“奖学金”模块下单击“奖学金申请”。</span></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">2.学制内的研究生统一先申请“ </span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">博士研究生国家奖学金</span></strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;"> <span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">”或 </span></span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">“硕士研究生国家奖学金”</span></strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;"> <span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">（不要同时申请校级奖学金）。届时未获得研究生国家奖学金的申请者的相关材料，学院将按照校级研究生奖学金的具体要求，进行排序和调整。校级研究生奖学金的申请者，学院也将根据评审情况以及各个具体奖项的要求，调整至各个具体的校级研究生奖项当中。</span></span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">系统默认所有研究生均接受调剂，不服从调剂的学生，请在奖学金申请截止日之前，向学院提交书面申请，</span></strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">写明不服从调剂的缘由，学院将遵照其意愿，不进行调剂。</span></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">3.</span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">认真填写申请表。</span></strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">请首先核对页面显示的“基本信息”内容是否正确，如遇系统默认基本信息错误，请第一时间联系学院研究生奖学金负责老师进行更改；“联系电话”“电子邮箱”“外语等级”为可编辑信息，请务必填写准确的信息。评奖评优、学生干部任职、论文情况、专利情况等信息请据实填写并提供相应证明材料。</span></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">4.</span><strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">单击“提交”按钮。</span></strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">提交后如发现需要修改，只要学院尚未进行网上审核且在可申请的时间段内，可以单击“我的申请”按钮“撤回申请”，修改完成后保存，再次提交即可。 </span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">特别注意，所有申请以提交申请成功为准，切勿忘记提交！</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">5.提交申请后，单击“ </span><strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">打印”按钮-“导出 Word”文件并再次核对个人填写的信息</span><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_gb2312;">&nbsp;&nbsp;</span></strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;"><span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">（为保证字体及格式的准确，请导出</span> <span style="color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">Word 后再打印纸质版）。请用黑色钢笔或水笔签名。</span></span></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">四、评审支撑材料要求</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">1. 2026年硕士研究生国家奖学金、博士研究生国家奖学金及研究生校级奖学金的评审支撑材料起止时间段为：</span><strong><span style="letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0); font-family: 仿宋_GB2312;">原则上从上一年度9月1日至申请年度8月31日，申请的各类支撑材料不得重复使用。</span></strong></span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px; color: rgb(0, 0, 0);">2. 除博士研究生新生外，作为评审支撑材料使用的公开发表的学术论文，第一署名单位应当为同济大学。</span></p>
<p style="text-align:justify;margin-top:24px;margin-bottom:0;margin-left:0;text-indent:28px;padding:0 0 0 0 ;text-justify:inter-ideograph;line-height:42px;background:rgb(255,255,255)"><span style="color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">3. 博士研究生新生申请国家奖学金，原则上可使用入学前三年内的各类支撑材料，</span><strong><span style="color: rgb(0, 0, 0); font-family: 仿宋_gb2312; letter-spacing: 0px; font-size: 20px;">但不含之前获得国家奖学金曾经使用过的材料。</span></strong></span></p>
