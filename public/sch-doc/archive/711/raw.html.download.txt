                <h5 class="noticetitle">中国科学院半导体研究所关于2027年推荐免试生申请报名及面试时间安排通知</h5>
                <div class="meta"> 发布于： 2026-08-20</div>
                <div class="text"><p><strong>一、研究所概况</strong></p><p>中国科学院半导体研究所（以下简称“半导体所”）于1960年在北京成立，目前已发展成为集半导体物理、材料、器件研究及系统集成应用于一体的国家级半导体科学技术综合性研究机构。半导体所是中国科学院大学材料科学与光电技术学院的主办单位，材料科学与工程入选国家一流学科。近年来，半导体所在半导体物理、材料、器件研究及系统集成应用等领域取得一系列重大原创性成果，获得国家自然科学奖、国家科技进步奖等多项奖励。</p><p><strong>二、招生方向</strong></p><p>半导体所是国家首批博士后流动站设站单位，也是国家首批博士、硕士学位授予单位和中国科学院博士生重点培养基地之一，拥有8个学术型学科专业博士和硕士培养点（包括：凝聚态物理、光学工程、材料物理与化学、半导体材料与器件、物理电子学、电路与系统、微电子学与固体电子学、集成电路科学与工程），同时具有2个专业学位博士和硕士培养点（包括：电子信息、材料与化工）。</p><p>目前在学研究生近800人，其中近一半为博士生。半导体所实行研究生兼任研究助理的方式，为研究生提供优越的科研和生活条件，研究生可以直接参与研究所承担的重大课题项目及前沿研究与攻关。半导体所招收的研究生在读期间享受国家、中国科学院、国科大及半导体所的各项奖助学金待遇。<strong>欢迎全国各高校2027届优秀本科生积极报考半导体所！</strong></p><p><strong>三、申请条件</strong></p><p>（一）全日制普通高等学校2027届本科毕业生，<strong>获得母校推免生资格并在教育部“推免服务系统”</strong> <strong>中获得备案</strong>；</p><p>（二）热爱科学事业，有较好的科研潜力，道德品质良好，遵纪守法；</p><p>（三）诚实守信，学风优良，无任何考试作弊和剽窃他人学术成果记录，无任何违法违纪受处分记录；</p><p>（四）在大学本科阶段学习成绩优异，在学期间专业主干课无重修科目或补考记录；</p><p>（五）外语程度良好，具有较强的外语听、说、读、写应用能力；</p><p>（六）具有较强的调查研究、综合分析问题、解决问题能力；</p><p>（七）身体健康状况符合规定的体检标准，心理健康状况良好。</p><p><strong>四、申请步骤</strong></p><p><span style="color: rgb(0, 0, 0);"><strong>（一）网上报名：推荐免试申请人，须通过</strong><strong>半导体所招生报名系统申请报名，</strong>网址：</span></p><p><a href="https://oa.semi.ac.cn/ui/views/app/bandaotisuo/fillintheentrance.html" style="text-decoration: underline; color: rgb(0, 0, 0);"><span style="color: rgb(0, 0, 0);"><strong>https://oa.semi.ac.cn/ui/views/app/bandaotisuo/fillintheentrance.html</strong></span></a><span style="color: rgb(0, 0, 0);"><strong>。</strong></span></p><p><span style="color: rgb(0, 0, 0);"><strong><span style="color: rgb(0, 0, 0); text-wrap-mode: wrap;">路径：推免生报名-注册用户-学生登录，登录系统后按要求填写基本信息并上传电子版申请资料。</span></strong></span></p><p><span style="text-wrap-mode: wrap; background-color: rgb(255, 255, 255); color: rgb(0, 0, 0);">（申请材料具体要求详见本通知第五部分）</span></p><p>申请人须确保填报信息真实有效。</p><p>（二）提交材料：完成报名后的推荐免试申请人<strong>通过半导体所招生报名系统填写意向导师（仅限1位），并在“报名资料”栏目提交申请材料电子版</strong>。</p><p><strong>申请资料纸质版请自行携带至报到现场提交。</strong></p><p>（三）资格审核：<span style="color: rgb(0, 0, 0);"><strong>凡符合申请条件并已进行网上报名且纸质申请材料可以按时提交的考生，均可参加面试，不再通过推免申请系统通知资格审核结果。</strong></span>资格审核将贯穿于整个招生过程，申请人须保证所提交申请材料的真实性和准确性，任何时候发现申请人提交的信息不真实或不准确，及不符合申请条件者均将取消面试资格或拟录取资格。</p><p><span style="color: rgb(0, 0, 0);"><strong>（四）报名截止时间：2026年9月4日（周五）17:00。</strong></span></p><p><span style="color: rgb(0, 0, 0);"><strong>五、申请材料</strong></span></p><p>（一）必须提交的材料：</p><p>1.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;个人简历及专业学习情况介绍（无固定格式）；</p><p>2.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;所在学校教务部门（或院系）出具并加盖公章的大学本科前三年所修课程成绩单（五年制的提供前四年课程成绩单）；</p><p>3.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;英语等级证书复印件；</p><p>4.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;第二代居民身份证正反面复印件（复印在一页纸）；</p><p>5.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;学生证复印件；</p><p>6.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;学信网学籍验证报告。</p><p>（二）自愿提交的材料：</p><p>1.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;在公开发行的学术刊物或全国性学术会议上发表的学术论文、所获专利或其他原创性工作成果的复印件或证明；</p><p>2.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;大学期间的获奖证书复印件；</p><p>3.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;对申请有参考价值的其他材料。</p><p>（三）申请材料提交方式：</p><p>1.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;电子版：请将所有申请材料按顺序合并为一个PDF文件， PDF文件命名格式：“推免申请材料+申请人姓名+申请人本科学校名称”（例如“推免申请材料+张三+中国科学院大学”）。通过<strong>半导体所推免生报名系统“报名资料”上传PDF文件，点击保存即可。</strong></p><p>2.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;纸质版：<strong>申请资料纸质版请自行携带至报到现场提交（简装）。</strong></p><p><strong>六、面试安排</strong></p><p>（一）原则要求：<strong>申请人须在规定的时间内报到、提交资料并参加半导体所组织的面试。</strong>面试由半导体所人事教育处组织专家小组对考生的专业素质和能力、创新精神和创新能力、思想状况、外语听说能力等进行重点考察，包括考生所学专业基础知识、所报考的学科专业的基础知识及英语口语、简单科技文献翻译等。面试不指定具体科目及参考书目。专家小组根据考生回答问题的综合情况给出面试成绩、参加本组复试考生的排序及是否录取建议。</p><p>（二）时间安排：</p><p><strong><span style="color: rgb(255, 0, 0);">1.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;报到</span></strong></p><p><strong><span style="color: rgb(255, 0, 0);">时间：2026年9月10日（周四）9:00-11:00，14:00-17:00</span></strong></p><p>地点：<strong>半导体所办公区图书馆101会议室（北京市海淀区清华东路甲35号）</strong></p><p>办理事项：<strong>交验本人身份证及学生证原件</strong>；<strong>提交纸质申请材料。</strong></p><p><strong><span style="color: rgb(255, 0, 0);">2.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;面试</span></strong></p><p><strong><span style="color: rgb(255, 0, 0);">时间：2026年9月11日（周五）</span></strong></p><p>地点：<strong>半导体所</strong></p><p><strong>面试具体时间和地点待报到工作结束后另行通知。请根据具体面试时间安排个人后续行程。</strong></p><p><strong>七、拟录取</strong></p><p>（一）研究所按照“德智体全面衡量、择优录取、保证质量、宁缺毋滥”的原则确定拟录取名单并进行公示。</p><p>（二）被确定拟接收的推荐免试生必须在规定的时间内，与我所招生办通过教育部“推免服务系统”（网址：http://yz.chsi.com.cn/）互动完成网上报名、复试确认、拟录取确认等各项网上操作。逾期未通过教育部“推免服务系统”完成相关接收手续的拟录取推荐免试生不再保留拟录取资格，其拟录取资格自动失效。</p><p>（三）被拟录取的推荐免试生不得再以统考生身份报名参加全国硕士生统一入学考试。</p><p>（四）推荐免试生的录取类别一般为计划内非定向。对拟录取的推荐免试生，教育部审核通过后与统考生同时发放录取通知书。</p><p>（五）半导体所所有招生专业（含专业学位）均可接收推荐免试生，包括8个学术型学科专业（凝聚态物理、光学工程、材料物理与化学、半导体材料与器件、物理电子学、电路与系统、微电子学与固体电子学、集成电路科学与工程）、2个专业学位（包括：电子信息、材料与化工）。</p><p>（六）拟录取的推荐免试生（含直博生）须在拟录取公示发布后十个工作日内向我所提交体检表。届时将在我所网站发布相关通知，请注意及时查看。</p><p>（七）拟录取的推荐免试生（含直博生）须在2027年4—5月份向我所提交大学本科最后两学期的学习报告和政审表。内容包括本科最后两学期所学课程及已结课的课程成绩、毕业论文（毕业设计、实践活动）选题及进展情况。遵纪守法情况等，届时将在我所网站发布相关通知，请注意及时查看。</p><p>（八）对拟录取的推荐免试生，出现下列情况之一的，取消其录取资格：</p><p>1.&nbsp;&nbsp;在本科阶段最后一学年（四年制的指第七、八学期，五年制的指第九、十学期）主干课程学习成绩有不及格科目；</p><p>2.&nbsp;&nbsp;毕业设计（论文）未取得良好以上（含良好）成绩；</p><p>3.&nbsp;&nbsp;毕业时未获得本科毕业证书或学士学位；</p><p>4.&nbsp;&nbsp;政审不合格；</p><p>5.&nbsp;&nbsp;考试作弊或违纪（法）受到“警告”以上处分的，或有其他情节严重的违法乱纪行为受到处罚者；</p><p>6.&nbsp;&nbsp;申请人提交的材料有弄虚作假者。</p><p><strong>八、其他</strong></p><p>未尽事宜或与中国科学院大学相关规定不符之处，均以中国科学院大学的相关规定为准。</p><p>&nbsp;</p><p>联系人：吴老师</p><p>电话：010-82304192</p><p>E-mail:
