                	<h6>中国科学院福建物质结构研究所关于2026年在所研究生暑假及秋季开学学生工作的通知</h6>
                    <span><script language="javascript"> var temp=''; if(temp!="" && temp!=null){document.write("作者：" + temp + "&nbsp;&nbsp;|&nbsp;&nbsp;")}</script><script language="javascript"> var temp1=''; if(temp1!="" && temp1!=null){document.write("新闻来源：" + temp1 + "&nbsp;&nbsp;|&nbsp;&nbsp;")}</script>更新日期：2026-07-20&nbsp;&nbsp;</span>

                     <div class="trs_editor_view TRS_UEDITOR trs_paper_default trs_word"><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">根据所办公会会议精神，2026年在所研究生暑假及2026-2027学年秋季学期开学工作安排有关事项通知如下：</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;"><strong>一、暑假放假和秋季学期开学时间</strong></span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">1.暑假时间：<span style="background: rgb(255, 255, 255); font-family: 宋体, SimSun; font-size: 16px;">8月3日(星期一)</span>至<span style="background: rgb(255, 255, 255); font-family: 宋体, SimSun; font-size: 16px;">8月14日（星期五）</span>。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">2.秋季学期<span style="background: rgb(255, 255, 255); font-family: 宋体, SimSun; font-size: 16px;">8月17日正式开学。</span>学生注册、报到时间为8月17日，福州园区在高新园区综合楼1003室报到注册，厦门园区在稀土中心A区1号楼909办公室报到注册，泉州园区在晋江园区1号科研楼706室报到注册。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">3.2026级国科大硕士、海西联培硕士秋季学期开学时间按国科大和各高校规定执行。协议期内课题组联培生参照在所研究生管理。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;"><strong>二、暑假回家、外出以及秋季开学返所要求</strong></span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">1.<span style="letter-spacing: 0px; font-family: 宋体, SimSun; font-size: 16px;">假期期间留所研究生请于7月28日前提交留所学生备案表，链接如下</span>：https://v.wjx.cn/vm/mSskQa2.aspx。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">2.根据国科大《关于2026年暑假及秋季开学学生工作的通知》精神，对于因科研工作申请留所或提前来所的学生，导师是学生教育管理的第一责任人，原则上导师（或指定的负责老师）须在所在岗，确保学生安全及实验安全。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">3.如需在暑假期间开展实验，请严格按照科技处的要求进行，遇有突发事件，要按规定及时报告并妥善处置。已入所新生未经过安全培训，不得开展实验工作。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">4.离所时，要切断电源、关好水电门窗，贵重物品（如电脑、现金等）不要放在寝室，需妥善寄存保管。离所同学请于7月28日前填写暑期去向登记表，链接如下：https://v.wjx.cn/vm/OAaGtwU.aspx。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">5.假期期间要提高安全意识，注意交通安全、食品安全、消防安全、防范电信诈骗、网络诈骗和非法团伙诱骗、夏季防洪防溺水等；不要前往未开发的景点、危险场所或参加冒险性活动，避免发生意外伤害事件；遵守学生公寓各项管理规定，严禁在宿舍内使用违章电器，严禁留宿外来人员；自觉遵守国家法律法规和社会主义公民道德规范，不参与任何非法活动，不参加任何形式的封建迷信和赌博活动，遵守网络文明规范；严禁参与危害社会和谐稳定的活动。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">6.正值暑假回家、返所途中要特别注意人身、财物和交通安全，做到平安回家，顺利返所。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;">7.严格遵守“福建物构所研究生考勤请假制度的通知”（所主页/研究生教育/培养/学籍管理），不得以“买不到车票”等理由，未经请假提前离所或推迟返所，违反规定的将视情节轻重，予以批评教育或纪律处分。</span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun; font-size: 16px;"> </span></p><p style="text-indent: 43px; font-size: 16px; line-height: 1.75em;"><span data-index="9" style="font-family: 宋体, SimSun;
