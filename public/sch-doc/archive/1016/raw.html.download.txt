        <h3 class="gp-f24 gpFontSize" id="shareTitle">北京理工大学2026年接收优秀应届本科毕业生推荐免试攻读研究生（含本直博生）办法</h3> 
        <h4 class="gp-f20 gpFontSize1 gp-hide" data-gp-articletitle-h4="gp-hide"></h4> 
       </div>
       <div class="gp-articleAuthor gp-articleAuthor1">
  
          <span class="date">日期：2025-09-04 <i>|</i> </span> 
         <span>访问量：<strong><script src="/cms/web/writeLog.jsp?siteID=b145&channelID=b22824&contentID=1f63040825294e62b5cc2889b5ef49e5"></script></strong></span> 
       </div>

       <div class="gp-article1 gp-article gp-f16">
         <p style="margin-top: 10px; text-indent: 43px; font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">欢迎国内各高校优秀应届本科毕业生推荐免试攻读北京理工大学研究生！</span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><strong><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">一、申请条件</span></strong></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">拥护中国共产党的领导，愿为社会主义现代化建设服务，品德良好，遵纪守法。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">学习期间未受过任何处分。身心健康，符合国家和招生单位规定的体检要求。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">已获得所在高校推荐免试资格的优秀应届本科毕业生。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">勤奋好学，思维敏捷，专业基础知识扎实，具有较强的实践能力和创新能力。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><strong><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">二、申请程序</span></strong></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">申请人可登陆各招生学院网站，查看各招生单位推免生接收工作安排或直接联系各学院（各招生单位联系方式见附件</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">），按照招生单位要求提交相关材料，完成预报名工作。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">各招生单位根据申请情况，对申请人提交的材料进行评审，审核通过后，由招生单位通知申请人复试时间、地点和具体要求。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">复试通过的申请人应在教育部规定时间内登录“全国推荐免试攻读研究生（免初试、转段）信息公开管理服务系统”（以下简称“推免服务系统”，</span></span><a href="http://yz.chsi.com.cn/tm" style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">http://yz.chsi.com.cn/tm</span></a><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）进行网上报名。</span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">招生单位通过“推免服务系统”向复试合格的申请人发放待录取通知，考生须网上确认“同意待录取”才能完成录取过程，未在规定时间内确认“同意待录取”的，视为自动放弃待录取资格，我校将不再保留其拟录取资格。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">5.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">考生可在即日起向报考单位咨询相关报考事项。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><strong><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">三、提交材料</span></strong></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">有效期内的学生证、身份证原件（复试时出示原件）。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">加盖所在学校教务处公章的本科成绩单一份。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">获奖证书复印件一份。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">其他体现学术水平的代表性学术论文、出版物、专利证书或具有学术水平工作成果的复印件或证明。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">5.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">除上述材料，申请本直博的考生还须提交：《</span></span><a href="http://grd.bit.edu.cn/ziyuan/tongzhi/zbtjsx.doc" style="font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">北京理工大学</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2026</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">年招收优秀应届本科毕业生直接攻读博士学位研究生专家推荐书</span></span></a><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">》（附件</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）一式两份（推荐人须是</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">名副教授或相当职称以上专家，推荐书须由推荐人密封并在封口处签字）。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">所有材料均需使用</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">A4</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">纸，申请人的全部申请材料均在复试时提交学院审核备案，提交的材料恕不退还。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><strong><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">四、其它</span></strong></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">《北京理工大学</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2026</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">年硕士学位研究生招生专业目录》中的全日制学科专业（不含教育部规定不能接收推免生的专业）均可接收免试攻读硕士学位研究生。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">我校将于</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2026</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">年</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">月</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">-5</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">月对拟录取推免生进行思想政治品德考核，录取类别为定向就业的考生须签订相应协议。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">有下列情况之一者，我校将取消其录取资格：</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">（</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">1</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）思想政治品德考核未通过；</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">（</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）提供的材料、个人信息与事实不符，存在舞弊现象；</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">（</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）录取当年未获得本科毕业证书；</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">（</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">）不符合规定的体检标准或因身体缺陷、疾病而不能继续学习。</span></span></p> 
<p style="text-indent: 43px; font-size: 20px;"><span style="font-size: 20px;"><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">4.</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">考生体检工作在考生拟录取后组织进行，体检标准参照教育部、原卫生部、中国残联印发的《普通高等学校招生体检工作指导意见》（教学〔</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2003</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">〕</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">3</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">号）、《教育部办公厅</span> <span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">卫生部办公厅关于普通高等学校招生学生入学身体检查取消乙肝项目检测有关问题的通知》（教学厅〔</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2010</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">〕</span><span style="font-family: 'Times New Roman', serif; color: black; font-size: 20px;">2</span><span style="font-family: 方正仿宋简体; color: black; font-size: 20px;">号）和学校相关规定执行。</span></span></p>
