    <h2 class="title" id="ccc">2027年推荐免试直硕、直博生履行正式报名手续的通知及资格复审要求</h2>
    <div id="vsb_content" class="content"><div class="v_news_content">
<p style="text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; color: rgb(102, 102, 102);"> &nbsp;</span><span style="font-size: 16px;"><span style="font-family: 仿宋; color: rgb(102, 102, 102);">根据上级相关要求，推荐免试直硕、直博生（以下简称“推免生”）都应在“全国推荐优秀应届本科毕业生免试攻读研究生信息公开暨管理服务系统”（以下简称“推免服务系统”）完成正式报名手续。</span><b><span style="text-decoration-line: underline; font-family: 仿宋; color: rgb(255, 0, 0);">其中，我校强基计划学生无需按此通知履行正式报名手续</span></b><b><span style="text-decoration-line: underline; font-family: 仿宋; color: rgb(255, 0, 0);">。</span></b></span></p>
<p style="text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="color: rgb(102, 102, 102); font-family: 仿宋; font-size: 16px;"> &nbsp;现将有关要求通知如下：</span></p>
<p style="text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px; font-family: 仿宋; color: rgb(102, 102, 102);">一、</span><span style="font-size: 16px; font-family: 仿宋;">推免生查询初步录取信息</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋; color: rgb(102, 102, 102);"> &nbsp;被我校初步录取的</span><span style="font-family: 仿宋;">推免生</span><span style="color: rgb(102, 102, 102); font-family: 仿宋;">可登录“清华大学研究生申请服务系统”（</span></span><a href="http://yzbm.tsinghua.edu.cn/" style="font-family: 仿宋; color: rgb(0, 0, 255); font-size: 16px;">http://yzbm.tsinghua.edu.cn/</a><span style="font-family: 仿宋; color: rgb(102, 102, 102); font-size: 16px;">）查询初步录取信息。</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px; font-family: 仿宋; color: rgb(102, 102, 102);">二</span><span style="font-size: 16px; font-family: 仿宋;">、初步录取推免生网上报名手续</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="color: rgb(102, 102, 102); font-family: 仿宋;"> &nbsp;所有被我校初步录取的推免生应及时完成“推免服务系统”的报名手续。</span><span style="font-family: 仿宋; color: rgb(255, 0, 0);">9月21日</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">起，推免生可登录</span></span><a href="https://yz.chsi.com.cn/tm" style="font-family: 仿宋; color: rgb(0, 0, 255); font-size: 16px;">https://yz.chsi.com.cn/tm</a><span style="font-family: 仿宋; color: rgb(102, 102, 102); font-size: 16px;">进行注册和报名。</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋; color: rgb(102, 102, 102);"> &nbsp;所有被我校初步录取的推免生应于</span><span style="font-family: 仿宋; color: rgb(255, 0, 0);">9月22日上午08：00前</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">完成报名、网上支付报名费等手续。</span><b><span style="text-decoration-line: underline; color: rgb(102, 102, 102); font-family: 仿宋;">推免生在“推免服务系统”中所填报志愿的直硕/直博类型、初步录取院系、专业、研究方向、导师（直博生需填）等信息必须与在“清华大学研究生申请服务系统”中查询到的初步录取信息保持一致。</span></b></span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋; color: rgb(255, 0, 0);"> &nbsp;9月22日上午10:00</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">左右起，我校将向所有完成报名手续并正确填写了志愿信息的推免生分批次发送复试通知，推免生应于</span><span style="font-family: 仿宋; color: rgb(255, 0, 0);">9月24日08:00前在复试通知要求的时间范围内</span><span style="color: rgb(102, 102, 102); font-family: 仿宋;">在“推免服务系统”中接受复试。</span></span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋; color: rgb(255, 0, 0);"> &nbsp;9月24日上午10:00</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">左右起，分批次发送待录取通知，推免生应于</span><span style="font-family: 仿宋; color: rgb(255, 0, 0);">9月24日17:00前在通知要求的时间范围内</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">签约待录取。</span></span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 19px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><b><span style="text-decoration-line: underline; color: rgb(102, 102, 102); font-family: 仿宋;"> &nbsp;特别提醒，由于“推免服务系统”的通知发送和接收可能存在一定的时延，请所有被我校初步录取的推免生耐心等待，并在接收到复试通知和待录取通知后尽快按要求进行相应操作。未按要求完成相关报名及相关确认手续者视为自动放弃。</span></b></span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;">三、拟录取推免生资格复审</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; text-indent: 29px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px; font-family: 仿宋;">我校将在2027年6月前后对所有拟录取的推免生进行资格复审。通过资格复审并经我校调档案审查合格后，方可被正式录取，我校予以发放录取通知书。未通过资格复审者，取消其拟录取。资格复审的要求规定如下：</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;"> &nbsp; &nbsp;1.应已完成本科培养方案规定的所有课程及实践环节的学分要求;</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;"> &nbsp; &nbsp;2.本科最后一学年课程考核成绩不得出现不及格记录；</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋;"> &nbsp; &nbsp;3.从考生报名</span><sup><span style="vertical-align: super; font-size: 16px; font-family: 仿宋;">1</span></sup><span style="font-family: 仿宋;">至入学报到之日，未受到任何处分；</span></span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;"> &nbsp; &nbsp;4.本科综合论文训练（毕业设计）应优良或80分（含）以上；</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;"> &nbsp; &nbsp;5.我校研究生新生入学前获得本科毕业证书和学士学位证书；</span></p>
<p style="margin-top: 14px; margin-bottom: 3px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-family: 仿宋; font-size: 16px;"> &nbsp; &nbsp;6.符合我校各拟录取院（系）自定的不低于学校复审要求的标准（具体咨询相应院系）。</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 13px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px; font-family: 仿宋;"> &nbsp;外校推免生应在</span><span style="font-size: 16px; font-family: 仿宋; color: rgb(255, 0, 0);">2027年6月</span><span style="font-size: 16px; font-family: 仿宋;">本科最后一学期结束前将本人最后一学年正式成绩单（含毕业设计成绩，加盖教务处公章）交（寄）到我校拟录取院（系）研究生教学办公室。</span></p>
<p style="margin-top: 7px; margin-bottom: 3px; text-indent: 13px; background: rgb(255, 255, 255); line-height: 1.5em;"><span style="font-size: 16px;"><span style="font-family: 仿宋;"> &nbsp;注</span><sup><span style="vertical-align: super; font-size: 16px; font-family: 仿宋;">1</span></sup><span style="font-family: 仿宋;">：考生报名时间指在“</span><span style="font-family: 仿宋; color: rgb(102, 102, 102);">全国推荐优秀应届本科毕业生免试攻读研究生信息公开暨管理服务系统</span><span style="font-family: 仿宋;">”提交志愿的时间。</span></span></p>
