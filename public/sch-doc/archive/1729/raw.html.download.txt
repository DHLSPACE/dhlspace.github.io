						<h1 class="fl w100 text-center">理化所2026年招收秋季入学博士研究生（普通招考）招生规程</h1>
						<div class="fl w100 lhsyjs_con_ly marb15">
							<font class="col-md-6 col-sm-6 col-xs-6 text-center">来源：</font>
							<font class="col-md-6 col-sm-6 col-xs-6 text-center">时间：2026-03-27</font>
						</div>
						<div class="trs_editor_view TRS_UEDITOR trs_paper_default trs_word"><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">根据教育部和中国科学院大学有关文件精神，结合我所实际情况，制定以下规程：</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">一、考核工作的组织管理</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">所招生工作小组全面负责研究生招生工作；具体按专业成立若干考核小组，负责对普通招考博士研究生进行考核。</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">二、考核形式</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">普通招考博士研究生考核采取“申请</span><span style="font-size: 16px; color: rgb(0, 0, 0);">-</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">考核”制。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">三、考核内容</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; color: rgb(0, 0, 0);">1. </span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">笔试：笔试科目为一门，形式为开卷，考试内容为硕士期间研究工作及博士期间工作计划等。时间</span><span style="font-size: 16px; color: rgb(0, 0, 0);">120</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分钟，满分为</span><span style="font-size: 16px; color: rgb(0, 0, 0);">100</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分。笔试成绩不及格（百分制成绩低于</span><span style="font-size: 16px; color: rgb(0, 0, 0);">60</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分）者，不予录取。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; color: rgb(0, 0, 0);">2. </span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">面试：面试考核内容包括外国语能力考核、专业基础考核、专业能力测试、综合素质考核。考生准备</span><span style="font-size: 16px; color: rgb(0, 0, 0);">10</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分钟的</span><span style="font-size: 16px; color: rgb(0, 0, 0);">PPT</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">报告，专家组提问</span><span style="font-size: 16px; color: rgb(0, 0, 0);">10</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分钟。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">外国语能力考核：针对基础英语和专业英语进行考核，满分为</span><span style="font-size: 16px; color: rgb(0, 0, 0);">100</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">专业基础考核：考生以</span><span style="font-size: 16px; color: rgb(0, 0, 0);">PPT</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">形式介绍本人的硕士研究工作以及攻读博士学位期间将开展研究工作的设想，报告内容：个人简介、硕士研究生阶段的课程成绩、研究课题、成果、研究兴趣及对拟开展研究工作的设想。评委就其硕士研究工作、研究兴趣及对拟开展研究工作的设想等内容展开提问。满分</span><span style="font-size: 16px; color: rgb(0, 0, 0);">100</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">专业能力考核：考生回答考核小组专业提问。重点考查考生对本领域知识的掌握情况以及综合运用所学知识解决问题的能力、实验技能和实际动手能力等；考查考生对本学科前沿知识及最新研究动态的了解情况。满分</span><span style="font-size: 16px; color: rgb(0, 0, 0);">100</span><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">分。</span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">综合素质考核：内容主要包括申请人的思想政治表现、学习（工作）态度、道德品质、遵纪守法情况、人文素质以及举止、表达和礼仪以及心理状况等方面。</span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px; font-family: 宋体; color: rgb(0, 0, 0);">四、考核时间安排</span><span style="font-size: 16px; color: rgb(0, 0, 0);">  </span></span></p><p style="text-indent: 2em;"><span style="font-size: 16px; color: rgb(0, 0, 0);"></span></p><p style="text-indent: 2em;"><span style="color: rgb(0, 0, 0);"><span style="font-size: 16px;
