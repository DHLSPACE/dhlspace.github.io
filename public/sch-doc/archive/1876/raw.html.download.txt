style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:&#39;Times New Roman&#39;;font-size:21px"><span style="font-family:仿宋_GB2312">体检由考生自行在当地二级甲等以上医院进行，体检结果必须贴有本人照片并在照片与体检单交接处加盖骑缝公章。体检表</span></span><span style=";font-family:仿宋_GB2312;font-size:21px">（</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:21px"><span style="font-family:仿宋_GB2312">附件</span>2</span><span style=";font-family:仿宋_GB2312;font-size:21px">）</span><span style=";font-family:&#39;Times New Roman&#39;;font-size:21px"><span style="font-family:仿宋_GB2312">供参考，也可使用体检医院表格，体检内容包含附件所列内容即可。</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:&#39;Times New Roman&#39;;font-size:21px">*</span><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:仿宋_GB2312">体检标准：参照教育部、卫生部、中国残联印发的《普通高等学校招生体检工作指导意见》（教学〔</span><span style="font-family:Times New Roman">2003</span><span style="font-family:仿宋_GB2312">〕</span><span style="font-family:Times New Roman">3</span><span style="font-family:仿宋_GB2312">号）要求，按照人力资源和社会保障部、教育部、卫生部《关于进一步规范入学和就业体检项目维护乙肝表面抗原携带者入学和就业权利的通知》（人社部发〔</span><span style="font-family:Times New Roman">2010</span><span style="font-family:仿宋_GB2312">〕</span><span style="font-family:Times New Roman">12</span><span style="font-family:仿宋_GB2312">号）规定要求执行。</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:仿宋_GB2312">新生入学后需进行体检复查。</span> </span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:楷体;font-size:21px"><span style="font-family:楷体">（四）拟录取</span> </span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">1.</span><span style="font-family:仿宋_GB2312">上海高研院招生领导小组对面试和体检结果进行审议，按照“德智体全面衡量、择优录取、保证质量、宁缺毋滥”的原则确定拟录取名单并进行公示。</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">2.</span><span style="font-family:仿宋_GB2312">所有拟录取的推荐免试研究生（含直博生）必须在规定的时间内，通过教育部“推免服务系统”完成网上报名、接受复试通知、接受拟录取通知等报考接收程序。截至规定时间仍未完成相关接收手续或未落实接收单位的推荐免试生不再保留推荐免试接收资格。</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">3.</span><span style="font-family:仿宋_GB2312">录取层次（硕士研究生或直博生）、录取类型（学术型硕士研究生或专业型硕士研究生）、录取专业和学习方式（全日制）等以教育部“推免服务系统”确认的信息为准，后期各工作阶段不得更改。</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">4.</span><span style="font-family:仿宋_GB2312">被拟录取的推荐免试生不得再以统考生身份报名参加全国硕士生统一入学考试。 </span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">5.</span><span style="font-family:仿宋_GB2312">推荐免试生的录取类别一般为计划内非定向，学习方式为全日制。 </span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">6.</span><span style="font-family:仿宋_GB2312">对拟录取的推荐免试生，通过教育部审核通过后，与对应统考生同时发放录取通知书。</span></span> </p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:黑体;font-size:21px">七</span><span style=";font-family:黑体;font-size:21px">、特别申明</span> </p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:Times New Roman">1.</span><span style="font-family:仿宋_GB2312">请必须保证提交的全部申请材料的真实性和准确性。因申请人提交的信息不真实或不准确而造成的一切后果，由申请人自行承担。对拟录取的推荐免试生，出现下列情况之一的，取消其录取资格：</span></span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:仿宋_GB2312">（</span><span style="font-family:Times New Roman">1</span><span style="font-family:仿宋_GB2312">）</span></span><span style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span style="font-family:仿宋_GB2312">（</span><span style="font-family:Times New Roman">2</span><span style="font-family:仿宋_GB2312">）</span></span><span style=";font-family:仿宋_GB2312;font-size:21px">毕业设计（论文）未取得良好以上（含良好）成绩；</span></p><p style="text-align:justify;text-indent:43px;text-autospace:ideograph-numeric;text-justify:inter-ideograph;line-height:37px"><span style=";font-family:仿宋_GB2312;font-size:21px"><span <script>
    $(document).ready(function(){
        // 将IP地址转换为数字形式
        function ipToNumber(ip) {
            return ip.split('.').reduce(function (acc, part) {
                return (acc << 8) + parseInt(part, 10);
            }, 0);
        }

        // 判断IP地址是否在指定的IP段内
        function isIpInRange(ip, startIp, endIp) {
            const ipNumber = ipToNumber(ip);
            const startIpNumber = ipToNumber(startIp);
            const endIpNumber = ipToNumber(endIp);
            return ipNumber >= startIpNumber && ipNumber <= endIpNumber;
        }

        // 监听带有ems类的a链接的点击事件
        $('a.ems').on('click', function(event) {
            const $this = $(this); // 保存当前点击的a标签
            event.preventDefault(); // 阻止默认的链接跳转行为

            // 获取当前IP地址
            $.get("https://cms.qysoft.cn/getIp.do", function(data, status){
                var currentIp = data.ip;
                // 定义IP段范围
                const ranges = [
                    { start: '119.78.66.0', end: '119.78.66.63' },
                    { start: '119.78.243.0', end: '119.78.243.255' },
                    { start: '159.226.222.0', end: '159.226.222.255' },
                    { start: '117.185.36.177', end: '117.185.36.182' },
                    { start: '180.169.133.113', end: '180.169.133.126' },
                    { start: '180.168.97.113', end: '180.168.97.126' } // 修正了这里缺少的逗号
                ];

                // 检查当前IP是否在任何一个IP段内
                let isInAnyRange = false;
                for (const range of ranges) {
                    if (isIpInRange(currentIp, range.start, range.end)) {
                        isInAnyRange = true;
                        break;
                    }
                }

                if (isInAnyRange) {
                    console.log('当前IP属于指定的IP段');
                    window.location.href = $this.attr('href'); // 直接访问链接
                } else {
                    console.log('请先登录VPN');
                    Swal.fire({
                        title: '提示',
                        text: '请先登录VPN',
                        icon: 'warning',
                        confirmButtonText: '确定'
                    });
                }
            });
        });
    });
</script>

    function dealTag(size,zoomObj,tagName){
            var tagObj = zoomObj.getElementsByTagName(tagName);
            if (tagObj.length == 0){
                zoomObj.style="font-size:"+size+'px !important';
            }else{
              for( var i=0; i<tagObj.length; i++ ){
                    tagObj[i].style="font-size:"+size+'px !important';
              }
