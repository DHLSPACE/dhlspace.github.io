                      <h1 class="arti_title">面对面交流 心贴心动员 | 国防科技大学校长雷勇军深入中学开展招生宣传</h1>
                      <p class="arti_metas"><span class="arti_update">发布日期：2026-06-26</span><span>|</span><span class="arti_views">访问量：<span id="visit_count"><script src="/wm/api/visit/get/article?siteID=9686902889fb4fbb80d61d1f90d3e386&articleID=d0cbd0b40ad4406ca113719a9d109f4a" async></script></span></p>
                      <div class="entry">
                         <p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">6月26日上午，国防科技大学校长雷勇军赴湖南师范大学附属中学、湖南省长沙市第一中学开展招生宣传，看望慰问招生宣传老师。</p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-06/c6658baaec0d4584a2df637f53c396f0jpg" width="1000" height="643" border="0" vspace="0" title="" style="width: 1000px; height: 643px;"></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">在与中学校领导交流中，雷勇军强调，现代战争是体系与体系的对抗，本质上是人才的较量。随着我军加速向机械化信息化智能化融合发展，对人才的知识结构、创新能力、科技素养提出了前所未有的高要求，只有源源不断地吸纳最优秀的地方青年进入军校，才能确保我军在未来战场上占据人才优势，掌握制胜先机。</p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-06/d56d598662e14e37bf59aa695b807904jpg" width="1000" height="678" border="0" vspace="0" title="" style="width: 1000px; height: 678px;"></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">在学校招生咨询点，雷勇军与考生和家长亲切交谈，祝贺同学们完成中学学业并取得理想成绩，肯定同学们志愿献身国防的青春担当，勉励同学们将个人成长融入强军兴军事业，融入国家发展需要，融入民族复兴伟业。还向考生家长介绍了学校办学育人的综合实力，讲述了军校人才培养的特色优势，指出报考军队院校将是青年学生的无悔选择。</p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">学校教育训练部、空天科学学院有关领导参加活动。</p>

	// 复制到剪贴板
function copyToClipboard(text) {
	if (navigator.clipboard && navigator.clipboard.writeText) {
		// 现代浏览器 API
		navigator.clipboard.writeText(text).then(function() {
			showCopySuccess();
		}).catch(function(err) {
			fallbackCopy(text);
		});
	} else {
		// 兼容旧浏览器
		fallbackCopy(text);
	}
}

// 备用复制方法
function fallbackCopy(text) {
	var textarea = document.createElement('textarea');
	textarea.value = text;
	textarea.style.position = 'fixed';
	textarea.style.opacity = '0';
	document.body.appendChild(textarea);
	textarea.select();
	try {
		document.execCommand('copy');
		showCopySuccess();
	} catch (err) {
		alert('复制失败，请手动复制');
	}
	document.body.removeChild(textarea);
}

// 显示复制成功提示
function showCopySuccess() {
	// 使用 layui 的提示
	if (typeof layui !== 'undefined' && layui.layer) {
		layui.layer.msg('链接已复制到剪贴板', {time: 2000, icon: 1});
	} else {
		alert('链接已复制到剪贴板');
	}
}
