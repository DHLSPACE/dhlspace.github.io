                    中国科学院宁波材料所2026年“梦启甬城，心动科苑”大学生暑期夏令营招募通知
                 </div>

                     <!--发布：本站-->    日期：2026-04-21
                 </div>
                 <div class="html">
                    <p align="center"><strong><span style="font-size:20px;">中国科学院宁波材料所2026年&ldquo;梦启甬城，心动科苑&rdquo;大学生暑期夏令营招募通知</span></strong></p>

<p>&nbsp; &nbsp; &nbsp; 为加强科研院所与重点高校之间的沟通合作，推动高校育人传统、学科门类优势与科研院所丰富的科研资源、高水平人才队伍实现优势互补，同时促进优秀大学生之间的深度交流，<strong>中国科学院宁波材料所将于2026年举办&ldquo;梦启甬城，心动科苑&rdquo;大学生暑期夏令营</strong>，为广大学子提供深入了解科研的平台，让优秀大学生在体验研究所精神与文化的同时，培育科研兴趣、激发创新精神与创新潜力。</p>

<p><strong>&nbsp; &nbsp; &nbsp; 欢迎有志于新材料、新能源、先进制造及生物医学工程领域研究的优秀学子踊跃报名！</strong></p>

<p><strong>&nbsp; &nbsp; &nbsp; <span style="font-size:18px;">一、宁波材料所简介</span></strong></p>

<p>&nbsp; &nbsp; &nbsp; 中国科学院宁波材料技术与工程研究所(简称宁波材料所)成立于2004年，是由中国科学院、浙江省、宁波市三方共建的浙江省首家中国科学院系统研究所。创立以来，宁波材料所紧密结合国际科技发展趋势和国家创新驱动发展需求，围绕&ldquo;材料研究&rdquo;，先后布局了材料技术、材料+制造、材料+能源、材料+医工4大领域。搭建了集基础研究、产业技术、工程化、检测评估于一体的全链条创新平台，拥有超16亿元的先进科研装备，建成海洋关键材料全国重点实验室、国家石墨烯创新中心等省部级以上各类平台43个。至2025年12月底，宁波材料所共承担各类科研项目9400多项，在Science、Nature等期刊累计发表论文13000余篇，材料科学学科连续三年居ESI全球前1&permil;。累计申请专利近8500件，授权专利近4500件。荣获国家和省部级科技奖励41项。</p>

<p>&nbsp; &nbsp; &nbsp; 宁波材料所围绕国家重大战略需求，秉承&ldquo;料要成材、材要成器、器要好用&rdquo;的定位，形成&ldquo;海洋关键材料与应用技术、磁性材料及应用、特种高分子与复合材料、激光和原子尺度制造与智能装备&rdquo;四大主攻方向和四个前沿方向与未来技术。</p>

<p>&nbsp; &nbsp; &nbsp; 宁波材料所组建了一支高水平的科研队伍，海外人才云集，师资力量雄厚，全所员工950多人，其中院士9人、杰青7人，从海外引进高层次人才400多人，累计获得各类人才计划支持近900余人次。全所博导173人、硕导128人，拥有10个研究生学位授予点（包括4个一级学科学术型博士点、1个专业学位博士点），3个博士后流动站，在学研究生2000多人，已培养输送研究生5400多人。</p>

<p><strong>&nbsp; &nbsp; &nbsp; <span style="font-size:18px;">二、夏令营活动详情</span></strong></p>

<p><strong>&nbsp; &nbsp; &nbsp; 1、活动形式</strong></p>

<p>&nbsp; &nbsp; &nbsp; 宁波材料所2026年大学生暑期夏令营拟采用<span style="color:#FF0000;"><strong>线上与线下相结合</strong></span>的方式举办。届时将安排科研领域介绍、优秀导师报告、实验室参观交流、科研团队咨询会、综合素质考查等系列活动，帮助营员全面了解材料所科研实力，发掘个人科研兴趣，明确未来科研方向，坚定科技报国志向。</p>

<p><strong>&nbsp; &nbsp; &nbsp; 2、活动时间</strong></p>

<p>&nbsp; &nbsp; &nbsp; 线上夏令营拟定于2026年7月上旬（具体时间和安排另行通知）</p>

<p>&nbsp; &nbsp; &nbsp; 线下夏令营拟定于2026年7月下旬（具体时间和安排另行通知）</p>

<p><strong>&nbsp; &nbsp; &nbsp; 3、</strong><strong>申请时间</strong></p>

<p>&nbsp; &nbsp; &nbsp; 2026年4月20日&mdash;6月20日</p>

<p><strong>&nbsp; &nbsp; &nbsp; <span style="font-size:18px;">三、夏令营申请条件</span></strong></p>

<p>&nbsp; &nbsp; &nbsp; 1、全国重点高校材料、化学、物理、机械、自动化、计算机、生物医学工程等相关专业大学三年级在校生（即2027届毕业生）；</p>

<p>&nbsp; &nbsp; &nbsp; 2、对学科专业有浓厚的兴趣与爱好，思维敏捷，热爱专业，热爱科研，遵纪守法，具备较好的科研潜质、人文素养和心理素质；</p>

<p>&nbsp; &nbsp; &nbsp; 3、学习成绩优秀，本科期间成绩排名靠前，对有潜在推免资格者、有出色科研成果者优先接收；</p>

<p>&nbsp; &nbsp; &nbsp; 4、英语达到国家四级或六级水平(425分以上)。</p>

<p><strong>&nbsp; &nbsp; &nbsp; <span style="font-size:18px;">四、夏令营申请流程</span></strong></p>

<p><strong>&nbsp; &nbsp; &nbsp; 1、网上报名：</strong>有意向报名的同学请于2026年4月20日&mdash;6月20日登陆中国科学院大学科教协同育人行动计划网站（<a href="http://kjxt.ucas.ac.cn/">http://kjxt.ucas.ac.cn/</a>），点击页面右侧的&ldquo;大学生夏令营报名&rdquo;（<a href="https://zxsq.ucas.ac.cn/login/index/sc">https://zxsq.ucas.ac.cn/login/index/sc</a>），注册成功后登录系统，承办夏令营单位选择&ldquo;宁波材料技术与工程研究所&rdquo;，并按要求如实填写各项信息。</p>

<p><strong>&nbsp; &nbsp; &nbsp; 2、发送电子版申请材料：</strong>网络报名信息提交成功的同学，请于2026年6月20日前将<strong>电子版申请材料</strong>发送至邮箱<strong>zhaosheng@nimte.ac.cn</strong>，并加入<strong>QQ群：905888326</strong>。</p>

<p><strong>&nbsp; &nbsp; &nbsp; 3、资格初审：</strong>我所研究生处将对电子版申请材料进行审核确认（审核材料的真实性、完备性），并于6月下旬至7月初确定夏令营活动最终入围名单，并同时以邮件、短信方式通知入营者本人。届时未接到入营通知的同学皆为未入选者，不再另行通知。</p>

<p><strong>&nbsp; &nbsp; &nbsp; <span style="font-size:18px;">五、夏令营申请材料</span></strong></p>
