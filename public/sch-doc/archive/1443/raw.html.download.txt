                <div class="article">
                      <h1 class="arti_title">国防科大气象海洋学院深入广东、海南、广西三地中学开展国防科普讲座和招生宣讲活动</h1>
                      <p class="arti_metas"><span class="arti_update">发布日期：2026-09-20</span><span>|</span><span class="arti_views">访问量：<span id="visit_count"><script src="/wm/api/visit/get/article?siteID=9686902889fb4fbb80d61d1f90d3e386&articleID=e1d03b2e64bb44f2be2583769858c6d2" async></script></span></p>
                      <div class="entry">
                         <p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">2026年秋季学期伊始，国防科技大学气象海洋学院结合高中军训，组织专家教授赴广东、海南、广西三省（自治区）多所重点中学，聚焦气象海洋学科特色开展10余场国防科普讲座与招生宣讲活动，覆盖师生逾万人次。</p> 
<p style="line-height: 180%; font-size: 14pt; text-indent: 0em; text-align: center;"><strong><span style="color: rgb(0, 112, 192);">广东</span></strong></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">叶芳副教授赴深圳观澜中学，面向1000余名高一新生开展《在“不确定”中寻找决胜时刻：气象学的浪漫与硬核》专题讲座，讲解气象条件对作战部署和战争局势的重要影响；汪祥副研究员赴深圳外国语学校，面向约800名高一新生开展《AI“算”海：当人工智能遇见风暴海洋》专题讲座，聚焦人工智能与海洋科学交叉前沿，以生动案例展现智能技术赋能海洋环境保障的广阔前景；张文副教授先后走进广州大学附属中学和广州市庆丰实验学校，以“漫谈海洋”为主题，普及海洋基础知识与生态现状，结合我国深海装备科考实践介绍海洋科技发展成果。</p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/670c0c81dcb04fed807aa46983c158e5.png" width="553" height="312" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/e9640234769f49e389d312a418b13b04.png" width="553" height="369" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/472e094b8fac4718b244b9591a35bde3.png" width="553" height="369" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="line-height: 180%; font-size: 14pt; text-indent: 0em; text-align: center;"><strong><span style="color: rgb(0, 112, 192);">海南</span></strong></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">翁利斌副教授在海口中学面向1200名高一学生开展《空间环境在太空安全中的应用》专题讲座；周鹤峰副教授赴三亚中学，为1000名高一学生开展《水下机器人如何耳聪目明、心灵手巧》专题讲座，解析水下智能装备核心技术；在琼海市海桂中学，胡晓阳副研究员面向600名学生作《听海——声呐技术简介》报告，介绍声呐技术百年演进、前沿光纤水听器创新突破及发展趋势；彭军研究员为600名学生作《当超级算力遇上风云变幻：数值天气预报背后的秘密》专题讲座，以“科学方程描述大气、超级算力计算未来、精准预报守护生命”为主线，生动展现数值天气预报科技魅力。</p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/c752ccc5ca51413f9fc79e7229254de3.png" width="553" height="369" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="line-height: 180%; font-size: 14pt; text-indent: 0em; text-align: center;"><span style="color: rgb(0, 112, 192);"><strong>广西</strong></span></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">滕义超副教授为南宁市第三中学青山校区1300余名学生作《气象雷达探秘》讲座，介绍雷达基本原理，分析气象雷达主要分类及未来发展；李书磊副教授、刘欢老师在防城港北部湾中学为1100余名学生开展《认识极地：中国极地科考之路》报告，介绍我国极地科考事业，回顾我国极地科考发展历程；程盼副教授赴柳州铁一中学，为2600余名高一学生开展《战斗机发展与战争》讲座，结合欧美及我国战斗机发展分析战斗机在战争中的重要作用。</p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/8c787e8ceed54d6c85a1073a26da385d.png" width="553" height="369" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/624f2b737bf146baa2e575c1879999e3.png" width="553" height="311" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="text-align:center;text-indent:0px;"><img src="../../images/2026-09/eb35ed3a8981421582b7f9abf3a162c0.jpeg" width="553" height="369" style="-aw-left-pos:0pt; -aw-rel-hpos:column; -aw-rel-vpos:paragraph; -aw-top-pos:0pt; -aw-wrap-type:inline"></p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">本次活动是气象海洋学院落实学校招生工作统一部署，结合中学军训做好2027年招生工作的重要举措。系列讲座紧扣气象海洋学科特色，内容涵盖气象、海洋、空间、智能计算等多个前沿领域，结合高一新生认知规律和兴趣特点设计，将深奥的国防科技知识转化为生动有趣的科普内容，有效拓宽中学生科学视野，让青年学子直观了解国防科技发展现状与前景，激发投身国防科技事业积极性。</p> 
<p style="LINE-HEIGHT: 180%; text-indent: 2em; font-size: 14pt;">下一步，气象海洋学院将继续深化与各地中学的交流合作，不断创新国防科普形式内容、持续扩大宣讲覆盖范围，助力青年学子逐梦强军。</p>

function copyToClipboard(text) {
	if (navigator.clipboard && navigator.clipboard.writeText) {
		// 现代浏览器 API
		navigator.clipboard.writeText(text).then(function() {
			showCopySuccess();
		}).catch(function(err) {
			fallbackCopy(text);
		});
	} else {
		// 兼容旧浏览器
		fallbackCopy(text);
	}
}

// 备用复制方法
function fallbackCopy(text) {
	var textarea = document.createElement('textarea');
	textarea.value = text;
	textarea.style.position = 'fixed';
	textarea.style.opacity = '0';
	document.body.appendChild(textarea);
	textarea.select();
	try {
		document.execCommand('copy');
		showCopySuccess();
	} catch (err) {
		alert('复制失败，请手动复制');
	}
	document.body.removeChild(textarea);
}

// 显示复制成功提示
function showCopySuccess() {
	// 使用 layui 的提示
	if (typeof layui !== 'undefined' && layui.layer) {
		layui.layer.msg('链接已复制到剪贴板', {time: 2000, icon: 1});
	} else {
		alert('链接已复制到剪贴板');
	}
}
