                2025年合肥物质院（科学岛分院）招收攻读硕士学位研究生复试实施办法
            </div>
            <div class="article-author-time-box">

                </div>
                <div class="article-detail-time">
                    2025-03-18

            <div class="article-detail-box">
                <div class="trs_editor_view TRS_UEDITOR trs_paper_default trs_web trs_word"><p style="text-indent:28px;line-height:150%"><strong><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">一、原则</span></strong></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">1、根据《中国科学技术大学2025年硕士研究生招生复试工作方案》，加大研究生的入学复试权重，实行"差额复试"。凡拟录取的考生均须参加复试，复试按"公平"和"公正"的原则，德、智、体全面衡量。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">2、硕士研究生招生考试由初试和复试两部分组成。初试由教育部统一组织，复试由中国科学技术大学研究生院科学岛分院（以下简称“科学岛分院”）组织。复试是研究生招生工作中的一项重要环节，考生必须通过复试，且复试成绩合格者方可参加按总成绩计算的方法，从高分到低分择优录取。复试的重点是考察学生掌握本科阶段知识的广度和深度、综合素质和能力，考核其是否符合硕士研究生的培养要求。</span></p><p style="text-indent:28px;line-height:150%"><strong><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">二、复试的分数线及复试名单</span></strong></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">1、复试分数线由科学岛分院根据中国科学技术大学2025年硕士研究生进入复试初试成绩基本要求、复试人数与招生计划数之比约为1.3:1，以及各专业达线考生的具体情况划定。复试分数线包括初试总成绩分数线和单科成绩分数线。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">2、同时达到总成绩分数线和单科成绩分数线的考生具有参加复试资格。参加复试考生的名单公布在科学岛分院（中国科学院合肥物质科学研究院研究生处）的网页上。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">3、复试名单公布后，考生需按照复试相关通知的具体要求，准备复试材料纸质版和电子版，并按照要求进行提交（具体安排另行通知），由科学岛分院进行审查，并作为复试阶段参考。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; color: rgb(255, 0, 0); letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">4、科学岛分院近期将开通网络信息填报系统，另行通知达线考生线上填报和提交相关报考信息与材料。</span></p><p style="text-indent:28px;line-height:150%"><strong><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">三、复试内容和组织形式</span></strong></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">1、复试是对初试达线考生进行的复查性考核；复试的重点是从德、智、体等方面全面考查考生的综合素质和能力；复试内容包括英语能力测试、专业知识测试、综合素质和能力测试。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">2、科学岛分院研究生复试小组按学科（专业）或报考科研单元为单位组成若干业务能力复试小组，小组成员由相关学科的学科带头人、学术骨干、研究生导师组成，每个复试小组不得少于5人，其中应包括不少于3位研究生导师，外语听说能力较强的老师不少于1名。每个小组设组长1名，负责本组复试的各个环节。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">3、复试组长指令考生用中文做自我介绍，时间1分钟。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">4、英语能力测试。考生从英语试题库中随机抽取一篇英文短文，现场通读一篇，然后进行翻译。考生抽取后的题目，不再重复使用。同时复试专家组可进行英语提问考察。英语能力测试时间一般为5分钟。英语能力测试满分20分。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">5、专业知识测试。专业知识以口试形式进行考察。进一步考查考生的基础知识是否扎实，考生对专业知识掌握的广度和深度（包括对所报考学科前沿知识和研究动态的了解情况），综合并灵活运用所学知识分析及解决问题的能力，应变反应和表达能力，了解考生从事科研工作的潜力和创造力。每位考生的口试时间一般不少于5分钟。专业知识口试满分为20分。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">6、综合素质和能力测试。由复试专家根据考生的实际情况，进行开放性提问。内容包括但不局限于：相关课程知识点，参加的科研实践情况，获得的奖励，已取得的成果，对本学科的认识，将来的学习和研究计划等，通过这些问题对学生的综合素质进行考察。综合素质和能力测试一般不少于10分钟。综合素质和能力测试满分60分。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">7、复试时间一般不少于20分钟，所有考察结束后，由复试专家组组长告诉学生复试结束.</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">8、复试的组织和具体工作安排由科学岛分院负责。复试全程按教育部要求记录、存档。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">9、在录取通知书发出之前，任何人不得对考生做出与录取相关的承诺或暗示。除了单位向考生公布的内容外，任何人不得向考生透露有关复试的内部情况。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">10、复试是研究生入学考试的重要组成部分，是一项严肃认真的工作，须予以高度重视，坚决杜绝不正之风。在复试中造成严重后果的有关人员将受到党纪、政纪处分，直至追究刑事责任。</span></p><p style="text-indent:28px;line-height:150%"><strong><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">四、思想品德考核</span></strong></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">1、思想品德的考核主要考查考生的政治态度、思想品德、工作学习态度、团队合作精神、科研道德及遵纪守法等方面的基本素质。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">2、复试小组在对考生的专业知识考核中，通过与考生的面谈，直接了解考生的思想政治情况。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">3、科学岛分院可通过"函调"向考生所在单位的人事、政工或学生管理部门了解考生的思想品德情况。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">4、思想品德考核不合格者不予录取</span></p><p style="text-indent:28px;line-height:150%"><strong><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">五、录取</span></strong></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">1、录取工作坚持"德智体全面衡量、择优录取、保证质量、宁缺勿滥"的原则。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">2、对不符合报考条件，或在初试和复试中有严重违纪、舞弊情况的考生，经核实后，一律不予录取。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">3、所有考生完成复试后，由工作人员统一收取各组复试专家的打分表，统计各位考生的复试成绩。考生复试成绩为复试专家组各项考核环节打分的平均分。分数在复试结束后进行现场统计，并由复试专家组成员签字确认。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">复试成绩采用百分制，60分及格。复试成绩不及格者或思想品德考核不合格者不予录取。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">复试成绩=英语能力测试平均分＋专业知识测试平均分＋综合素质和能力测试平均分</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">复试结束后，将考生初试成绩和复试成绩按一定比例加权平均后，得出考生总成绩。录取按照招生计划和考生总成绩从高分到低分择优录取。</span></p><p style="text-indent: 28px; line-height: 2em;"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">考生总成绩加权平均采用下列公式：</span><span style="font-family: arial, helvetica, sans-serif; font-size: 16px; letter-spacing: -1px; text-indent: 0em;">考生总成绩＝</span><span style="font-family: arial, helvetica, sans-serif; font-size: 16px; letter-spacing: -1px; text-indent: 0em;">(初试成绩÷5)×50%＋复试成绩×50%</span></p><p style="line-height:150%"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;"> </span></p><p style="text-align:right;line-height:150%"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">合肥物质院研究生处</span></p><p style="text-align:right;line-height:150%"><span style="line-height: 150%; letter-spacing: -1px; font-size: 16px; font-family: arial, helvetica, sans-serif;">中国科学技术大学研究生院科学岛分院</span></p><p style="text-align:right;line-height:150%"><span style="line-height: 150%;                 if (compact) return [Number(compact[1]), Number(compact[2]), Number(compact[3])];
                const dotted = text.match(/(\d{4})\.(\d{1,2})\.(\d{1,2})/);
                if (dotted) return [Number(dotted[1]), Number(dotted[2]), Number(dotted[3])];
                const dated = text.match(/(\d{4})年(\d{1,2})月(\d{1,2})日/);
                if (dated) return [Number(dated[1]), Number(dated[2]), Number(dated[3])];
                const dash1 = text.match(/(\d{4})-(\d{1,2})-(\d{1,2})/);
                if (dash1) return [Number(dash1[1]), Number(dash1[2]), Number(dash1[3])];
                const dash2 = text.match(/(\d{4})-(\d{2})-(\d{2})/);
                if (dash2) return [Number(dash2[1]), Number(dash2[2]), Number(dash2[3])];
