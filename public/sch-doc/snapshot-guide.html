A COPY TO KEEP

重要的资料，
亲手留一份。

桌面与手机共用相同分类。筛选用来找到资料；手动快照用来保留已有原件。

1. 找学校和文件

桌面点击左侧悬浮胶囊，按高校 / 研究所、地区、方向、院校、资料年份与用途逐级选择。点击面包屑修改上一级，点击“返回”回到分类菜单。“查看结果”直接定位到匹配项。

手机用底部导航切换总览、院校、资料和动态；“更多”可以进入本校、监控、笔记、政策、报名与设置。右下角“筛选”展开面板，点击背景或收起按钮关闭。选项较多时可以搜索。

页面的“更多筛选”和胶囊使用同一组条件。院校的资料年份 / 用途只依据已收录的材料，未匹配不等于该院校不招生。修改胶囊上级条件时，后面的条件会重置，避免旧学校与新地区冲突。

2. 一次手动保存

  1. 进入“资料”，点“保存快照”。
  2. 默认优先选择公示 / 名单；也可选全部资料、当前筛选的所有分页，或自己勾选的文件。
  3. 核对份数，按需选择文件夹，再点“保存快照”。
  4. 等读取和压缩完成，在所选文件夹或下载列表确认 ZIP；先检查包内的缺失与校验清单。

打开页面、刷新、打开快照窗口均不会自动打包。只有点击保存才读取原件。进行中可以取消，取消不生成新的 ZIP。

选择“每个来源网址只取最新版本”可以避免重复；需要比较更正前后名单时取消勾选。当前筛选包含所有分页，不局限于屏幕上的 60 条。

3. 文件保存在哪里

支持文件夹访问的桌面浏览器可以通过系统选择器指定目录，授权仅用于本次页面会话；同名文件会加序号，不覆盖已有包。

不支持此接口的手机或浏览器会使用系统下载流程，请在浏览器下载列表或“文件”应用中查看。网页无法绕过系统限制自动指定手机目录，也不会直接连接你电脑的本机服务。

网页版默认文件名：2026-09-19_143025.zip（实际采用设备日期和时间）。本地 Python 助手仍默认保存到项目 snapshot/日期.zip，可在本机设置中改目录。两者读取的是各自已保存的资料。

“已交给浏览器下载”表示已生成 ZIP 并发起下载，不代表网页已经验证手机落盘。若保存目录授权过期，仍可“重新下载刚才的 ZIP”。

  招生年份 /

        标题__版本编号 /

标题、来源网址、保存时间和 SHA256 均保留。原件字节不改写。HTML 等页面以 .download.txt 保留，防止归档脚本在本站运行；阅读使用正文文本。

学校、年份、用途和院系由现有来源与标题规则整理，属于辅助分类。无法判断的招生年份保留“待核实”，不会用抓取日期冒充招生年份；栏目快照归“跨年”。本校推荐资格与目标学校招生、计划名额与拟录取名单仍然区分。

下载失败或哈希不一致都会记录；其余成功文件可以保留。完全没有拿到原件时不会生成假装成功的空包。待归档资源表是全库参考，不算作本次已保存文件。

5. 公示期文件要尽早保存

“公示 / 名单”按标题关键词筛选，可能漏掉名称不典型的附件，不能自动判断公示到期日。找到重要文件后请人工核对学校、标题、名单内容和页数；未匹配时可以通过学校筛选或勾选打包。

中科院及高校都可能调整网站或撤下附件，不能保证某一类单位永不过期。公开站只能下载已发布原件；需要保存尚未发布的新通知，使用本地助手采集或浏览器手动保存，再按本地说明导入。

已有链接不等于原件已经归档，采集失败也不等于没有通知。已经撤下且从未保存的名单无法凭标题恢复。

6. 外观、节能与可访问性

设置中可以关闭悬浮胶囊、默认 mini，切换深浅主题与主题色，调整透明度、模糊及卡片动画。手机的筛选面板具有键盘焦点限制；桌面与手机都支持键盘操作。

玻璃质感使用轻量 CSS 模糊、高光与层次，没有实时截图整页的 WebGL 循环。它是对参考风格的近似，不是同等真实光学折射。卡顿时选“实色”并关闭动效；系统减少动态效果设置会优先生效。

7. 开源与 AI

浏览器压缩采用 fflate 0.8.3，MIT 许可，代码随站点保存、无运行时 CDN，使用独立 Worker 压缩。查看许可证。

分类免费离线，不调用 AI，也不将名单上传给模型。AI / OCR 可作为后续辅助识别能力，但本版没有接入，不会出现只显示开关却没有功能的选项。

快照不是完整应用备份，个人笔记和关注只在当前浏览器。换设备前在“设置 → 备份笔记”导出，再在另一台设备导入。

8. 常见情况

  • 按钮不可用：当前范围没有可用版本，或正在打包；调整筛选或等任务结束。
  • 手机下载失败：保持页面在前台，先按学校分批。手机原文件上限 75 MB，电脑上限 200 MB。
  • 单个文件超时：其余文件仍可保存，查看问题清单；网络恢复后重新手动下载。
  • 目录授权失败：重新选目录，或改用系统下载。
  • 找不到 ZIP：检查浏览器下载列表、下载设置或系统“文件”应用。页面历史记录仅辅助查找，不会扫描你的磁盘。
  • 多次保存：日期时间命名，选定目录内同名加序号；旧包不会自动删除。
  • 外观不更新：刷新页面；必要时强制刷新。无需删除个人笔记或浏览器存储。
