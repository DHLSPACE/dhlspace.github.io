GUIDE / PROJECT NOTES

为你的每一步准备留底。

公开站展示已发布资料，不自动采集官网。查看新版胶囊、手机导航与快照指南 →

面向南昌大学本科生的化工及相关方向研究生资料工作台。目标年份在设置中调整，当前目标与关注院校在总览查看。

直接在院校卡片中查资料

  1. 点击“按年份浏览”，院校卡片在当前框架内展开。
  2. 选择招生年份，再用关键词搜索标题、院系或网址；文件类型、院系和资料类别可以组合。手机点击“筛选”展开这些条件。
  3. 点开一条记录，在原卡片中查看本地正文。上方路径可逐级返回，返回列表保留搜索、筛选和页码。
  4. “已保存”可阅读现有文本、下载原件、查看来源与校验记录；同一来源网址有多个保存版本时可切换版本。没有可用文本的 PDF、表格、图片请下载原件。
  5. “原件未保存”只表示已有通知索引，不会自动访问原站。“跨年”和“年份待核实”单独保留。卡片中的计数按来源网址合并历史版本。

资料类别由标题规则辅助整理，文件类型依据原件扩展名；仅有链接时按链接后缀识别。分类不是学校认定，阅读时以原文为准。本轮未启动新的爬取。

从哪里开始

  1. 在“院校”按省份、化学 / 化工 / 材料等方向筛选，用 ☆ 关注目标。
  2. 展开“校院入口”直达官网、研究生院和相关院系。显示“已接入”才表示存在监控源。
  3. 在“监控”检查逐个来源的上次时间、成功或失败状态，点击“检查”抓取。
  4. 在“资料”按用途 → 招生年份 → 学校 → 院系展开文件，选择原件可打包下载；包内同样分层。
  5. “政策”查看教育部与地方教育厅、考试院。“报名”打开正式系统；校内夏令营、预推免入口以当年通知为准。

本校和目标，是两种用途

本校只有南昌大学。“本校推荐”是本科阶段的推免资格、名额、排名和材料要求。南昌大学也可以是目标学校，其接收硕士、接收推免等文件归“目标申请”。推荐资格不等于目标学校接收计划。

分类是根据标题和来源自动整理，无法代替原文。文件标题中的唯一明确年份作为招生年份；多年份文件与栏目快照归“跨年”，无法确认的归“待核实”。发布日期和抓取日期独立保留。

研究方向与收录范围

保留化工、化学、材料、电化学、生物化学、半导体、分析化学、有机合成和能源环境相关候选。研究所分“核心相关”和“交叉拓展”。数学、天文、纯计算机等非优先单位移出主目录，原目录备份保留。

美术等无关学院通知不进入默认资料和动态视图，也不自动加入新的详情归档。既有原件未删除，“资料”里可勾选显示非相关旧资料。学科标签是选择线索，具体研究课题、跨专业条件、考试科目和招生资格需核对当年招生目录。

怎么看抓取状态

“链接已核验”仅表示本轮官网可访问。“已接入”表示实测了栏目标题、日期和链接并保存解析规则。“已保存版本”才表示本机已有文件。访问失败、解析失败、待检查分开显示；没有抓到不等于没有公告。

官网、常设名录和报名系统主要提供链接，不持续抓取综合新闻。尚无依据保证所有历史公告长期保留，因此招生政策、复试与录取等重要文件仍保存版本。需要登录、验证码或站点禁止抓取时，请本人打开官网查看。

本轮是有范围的扩展采集：每校多个栏目、默认前两页，每来源先保存少量最新相关详情和附件，余下进入队列。可在“监控”补采历史，或在“资料”继续归档队列。

外观、运行与备份

顶部导航使用文字；手机底部“...”打开全部栏目。点击“设置”调整主题、配色、导航与卡片不透明度、玻璃模糊；偏好只保存于当前浏览器。

双击“启动助手.cmd”打开本机程序。每日自动检查使用项目已有的“设置每日检查.cmd”，电脑需处于可运行且联网的状态。关闭浏览器不会停止服务，设置页可退出。

备份请复制整个“研招监控助手”文件夹。已有文件路径不变，新原件按用途和招生年份写入；ZIP与索引统一按新分类排列。JSON索引不包含原始附件，不能替代完整备份。
