数据说明与开源参考

探针使用官方 Codex CLI 的 account/rateLimits/read，仅读取额度，不发起模型任务。重置时间来自 resetsAt；耗尽预估根据近一小时同一重置窗口的用量变化线性计算，至少需要 15 分钟采样，不代表保证可用时间。

CodexBar：桌面菜单栏额度监控。Codex Monitor：本机用量与任务仪表盘。Codex Usage Monitor：本机探针与静态网页的架构参考。Self-Hosted Web Monitor：偏重本地会话与 credits 统计。

页面与探针为本站独立实现。GitHub Pages 和 raw 数据可能有缓存；页面每 60 秒读取快照，探针默认每 5 分钟采集。超过 3 个采样周期（至少 15 分钟）标记过期。页面不推测固定的每日或每周重置日。

CONNECT YOUR PROBE

接入你的 Codex

在已登录 Codex 的设备上运行。支持 Windows、macOS 和 Linux，需要 Node.js 22+ 与 GitHub CLI。

  1. 确认 Codex 和 GitHub CLI 已登录
    codex login
gh auth login
  2. 下载本站仓库并启动探针
    git clone --depth 1 https://github.com/DHLSPACE/dhlspace.github.io.git
cd dhlspace.github.io
node public/si/probe.mjs --publish

    保持终端运行；每 5 分钟上传到本站独立的 si-data 分支。停止采集按 Ctrl+C。使用 API Key 的账户可能没有订阅额度窗口。

  3. 回来查看，无需在网页填任何令牌

    需要本站仓库的写入权限。上传的额度百分比、套餐、时间及历史会公开；不会上传邮箱、账号 ID、密钥或对话。

本地查看 / 自定义数据源

仅采集到本地：node public/si/probe.mjs --once，然后导入生成的 .si/status.json。不会上传内容。

需支持跨域读取；地址只保存在此浏览器。不要填含有令牌的地址。
