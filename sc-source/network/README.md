`public/sc/network/index.html` 是可独立打开的专题目录。`research/` 包含9份独立研究报告，`downloads/` 提供三表Excel总索引、公开JSON和CSV，`downloads/physics/` 提供各人的论文CSV、第一署名CSV和BibTeX。公开输出采用字段白名单；原网页快照、查询响应、私人笔记及本机路径保留在本地。

本目录为本地 `scholar-network/tools/` 下构建脚本的公开副本。复用时保持原来的目录结构，人物主数据、原始来源与研究中间状态由本地知识库维护。`build_library.py` 生成数据、报告和目录；`build_workbook.mjs` 生成三表Excel；发布前再次运行构建器同步下载文件。本轮发布使用单独的暂存目录，并保留本地另行进行的人物关系图工作。

现有GitHub Pages工作流递归复制 `public/sc` 到 `_site/sc`。本轮只更新物理专题、首页人数提示和相关构建源文件，保留原论文快照及其他项目路径。

本地检查覆盖人物与来源引用、196条论文及作者位置、下载文件、旧档案保留、页面交互逻辑、内部链接和公开字段。Node VM检查不替代真实浏览器或手机视觉验收。
