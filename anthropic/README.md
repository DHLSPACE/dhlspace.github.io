# Anthropic IPO filing notes

Updated 2026-11-03. Chinese research report comparing the 2026-10-26 S-1 with the 2026-11-02 S-1/A.

- `index.html`: self-contained, responsive report with official source links and an illustrative IPO proceeds calculator.
- `Anthropic_S1A_2026-11-03.pdf`: 14-page, searchable report with an embedded Chinese font.
- `report-data.json`: report sections and numerical data.

The earlier user-referenced analysis was not located in accessible files or this repository. This report reconstructs the comparison baseline from the original official S-1; it does not claim a paragraph-by-paragraph merger of the earlier analysis.

All IPO terms left blank in the filing remain unknown. The calculator uses hypothetical inputs.
