Knowledge
Depth & Discovery.

知识的价值不在于收藏了多少，而在于你能否独立推导、计算、验证、比较，并据此做出更好的判断。

以化学工程与科研为专业核心，以数学、计算和统计为第二基础，以科学技术史、商业、制度和人文为长期横向视野。这里不是另一个无限扩张的百科，而是一份有验收标准的个人研究路线。

01 / Critical diagnosis

广度已经形成，深度需要证据。

现有课程、竞赛、研究讨论、GitHub 作品和知识库证明了持续探索，但不能把“已建档”“已阅读”直接视为“能够独立研究”。以下给出三个长期成长层级。

Core

专业护城河

化工热力学、分离与传递、催化、工程安全。用真实计算和实验解释问题。

Methods

第二条深度能力

数学、统计、数值分析、Python、证据评估与学术英语。把结果变得可检验。

Context

跨学科解释力

技术史、资本、制度、组织与文学。解释为什么技术出现、扩散或失败。

核心约束：同一季度最多运行两个主项目和一个轻量探索。现有知识库优先链接与引用，不建立重复数据库。
01

从信息到能力

公式经过无提示推导、程序测试、实验复核后才升级为“已验证”。

02

从兴趣到问题

一个研究专题必须具备可回答的问题、边界和可交付的结论。

03

从部署到作品

网页是作品容器；源数据、方法、误差与局限才构成研究质量。

02 / Existing domains

已有领域：下一层深度在哪里？

按专业、科研、基础方法、跨学科、人文和知识系统展开。每项都有现有证据、待补能力、日常动作与验收作品。P0/P1/P2 表示投入优先级，不是掌握程度评分。

没有匹配项。可以修改关键词或筛选条件。

03 / New domains

未系统深入的领域：先补基础，再跨界。

“未系统深入”只表示已有材料缺少足够的连续学习证据，不等于从未接触。A：立即补基础；B：紧邻现有主线；C：保持候选观察。新增领域都必须有一个可检验的入门成果。

没有匹配项。

优先进入顺序：概率统计/实验设计 → 数值分析 → 测量与不确定性 → 科学论证与写作。完成这些，再根据科研方向判断反应工程、过程系统、电化学或技术经济是否值得深入。
04 / Proof of work

14 个项目，不要求同时启动。

项目的排序依据为对当前学业与科研的贡献、复利型技能、可交付作品和机会成本。S 为当前核心；A 为本年可持续推进；B 为有明确问题时再进入。

没有匹配项。

05 / Compounding system

日积月累，必须形成反馈闭环。

20′

低负荷日

10分钟无提示提取 + 10分钟纠错。考试或实验密集日保证核心不脱节。

60′

标准自主学习

35分钟深入 + 15分钟应用 + 10分钟记录。工作量随课程安排调整。

120′

项目深度时段

75分钟制作 + 30分钟测试 + 15分钟整理。适合周末或非考试密集期。
