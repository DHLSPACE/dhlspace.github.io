# SI — 美国竞业限制、硅谷制度与 AI 人才流动

网页：https://162383.xyz/si/

核验日期：2026-11-05（北京时间）。人工核验快照，不自动追踪更新。

## 内容

- 50 州与 DC：普通雇员离职后竞业概览，含来源、时间、边界。
- 合同效力、适用法、NDA、商业秘密、禁止招揽与劳动市场反垄断。
- 硅谷历史和经济研究；与中国大陆的有限概念比较。
- OpenAI / Anthropic 29 条公开人物记录、8 类职能和 9 条人才流动案例。
- 中英术语、来源索引与持续更新字段。

普通雇员概览不穷尽职业例外、企业出售与合伙安排，不对任何个人的未公开合同作结论。旧判例用于一般框架，核验日不等于判决日。州表分类为学习索引，非官方评级。

## 使用

`index.html` 为无外部依赖的单文件页面，可以下载后离线阅读。网页支持州别、人员公司、术语和来源筛选；浏览器打印可保存 PDF。打印时恢复全部记录，并展开边界说明。

`knowledge.json` 为结构化研究数据。外部证据链接需要联网。

## 再生成

仅需 Python 3 标准库：

```sh
python si/build.py
node --check si/app.js
```

源资料位于 `research/`；叙述章节为 `research/chapters.html`。修改后运行生成器，提交源资料及生成的 `index.html`、`knowledge.json`。不要仅编辑生成页后忘记修改输入。

## 更新规则

1. 保留 `verified_on` 与来源发布日；动态页面不能伪造发布日期。
2. 法案通过、签署与生效分开；尤其 WA 2027-06-30、IL 2027 门槛与 CA stay-or-pay 日期。
3. 任命公告的 “will join” 不自动改成已到岗；旧任职保留历史证据。
4. 官方当前领导页、法条优先；媒体与镜像明确标注。不可公开取得的合同、员工所在地和汇报关系保持未知。
5. `CHANGELOG.md` 记录修订和证据；法定工资门槛须带年份。

部署沿用仓库的 GitHub Pages workflow，静态构建复制 `si/` 到 `_site/si/`。本模块不依赖 API、账号、跟踪脚本或构建依赖。
