01 / THE QUESTION

刚离职，就能加入竞争对手吗？

在加州，普通雇员通常可以离职后加入竞争者；在美国其他州，要按当地规则和合同判断。任何地方都不能从“允许跳槽”推导出“可以带走商业秘密”。

直接回答你的四个问题
  1. 允许“无缝衔接”吗？可能允许；美国没有通用的离职冷却期。但还须核对通知期、是否仍受雇、有效竞业、禁令和其他义务。
  2. 只是硅谷特色吗？加州的强流动保护很突出，但北达科他、俄克拉何马、明尼苏达也有广泛禁令。各州例外和覆盖日期不同。
  3. 签字就产生法律效力吗？签字是证据，不会把违反强制性法律的条款变成有效条款。在允许竞业的州，也仍须满足法定与判例条件。
  4. 美国已经全国禁止了吗？没有。FTC 的全国规则被撤销，2026-02-12 已从 CFR 删除；各州法和特定联邦执法仍重要。[F01] [F02] [F03]

本页是公开资料的制度研究与学习资料，不是对任何个人合同的法律结论。所有“当前”均指 2026-11-05 的检索快照；未来生效的法律另列日期。

02 / SEPARATE THE OBLIGATIONS

一份入职文件，可能装着六种不同约束

约束约束什么跳槽时怎样理解
离职后竞业 Non-compete你接下来在哪里、为谁做什么先查适用州法；部分州广泛禁止，部分州有收入、时限、通知和对价要求。
保密 NDA特定信息的使用与披露竞业无效不代表 NDA 自动失效；若 NDA 过宽到实质禁止执业，也可能被审查。
商业秘密 Trade secrets受到法定保护的秘密信息即使没有签 NDA，秘密侵占也可能产生责任。[F06] [F07]
禁止招揽 Non-solicit招揽原客户或原同事州别、对象、主动招揽与被动接触、范围都重要；不能笼统说“美国都允许”。
通知期、在职义务、Garden leave雇佣关系何时真正结束公开宣布加入下一家公司，不证明已经开始工作；通知期内仍可能负有忠实、保密等义务。
奖金返还、股权归属、IP钱与成果归属法律上能去，经济上也可能放弃未归属股权；返还条款与成果归属须独立判断。

签署 → 有效 → 可执行 → 得到禁令或赔偿是四个不同问题。一条竞业条款无效，通常不等于劳动合同、工资约定和所有保密条款一起无效；还要检查可分割性与适用法。

在允许竞业的州，常见审查问题是：有没有合法利益需要保护；范围、时间、地域是否合理；有没有足够对价；通知是否合规；员工是否受收入或职业豁免；签订与解除日期是否落入新法；法院可否修窄过宽条款。各州表中的“条件允许”表示可能成立，不是默认雇主一定胜诉。

03 / WHICH LAW APPLIES?

不是看公司在哪个州注册就够了

公司注册地、总部、员工真实工作地、居住地、合同选法与争议解决地，可能是六个不同答案。远程员工、跨州搬家和在一个州签约后去另一个州工作，尤其需要分别记录。

1

先确定关系与日期

普通雇员、承包人、合伙人还是出售企业的股东？签订、续签、改约、离职日期分别是什么？

2

确定工作与合同连接点

实际主要在哪里工作、住哪里？选哪州法、在哪诉讼或仲裁？强制性保护是否覆盖？

3

逐条分类

究竟是禁业、保密、禁止招揽、通知期，还是返还奖金？标题不能替代实质。

4

套用当时生效的规则

门槛、职业、期限、通知、对价、解雇原因和法定例外。核对已通过但尚未生效的新法。

5

查实际争议与协商

有没有书面豁免、缩小范围、等待期、和解或禁令？只凭一条社交媒体消息无法补齐这些事实。

加州为什么特别重要？

BPC §16600 对普通雇佣关系中的竞业限制采取广泛无效规则，不能仅因“范围窄”“员工工资高”“员工自愿签字”就绕开。企业出售、合伙或成员关系解散等法定例外必须单独分析；普通员工持有一些股权，不自动等于符合企业出售例外。2024 年的 SB699 / AB1076 还强化了对无效协议的约束和员工救济。[F03] [F04]

Labor Code §925 对主要居住并工作于加州的雇员，限制雇主强制选择外州法院或剥夺加州实体保护；对由独立律师实际参与协商的某些条款有例外。这不是“在合同写加州”或“搬到加州”就必然解决所有跨州冲突。[F05]

联邦层面：规则失败，不等于没有执法

2024 年全国竞业规则未能生效；FTC 于 2025 年接受其被撤销的结果，2026 年正式删除相应规则。旧新闻写的高管例外、统一生效日等，不能当成现行全国法。另一方面，FTC 在 2026 年仍对 Rollins 的竞业安排形成特定同意令。一个企业的命令，不能外推成所有公司的协议都无效。[F01] [F02] [F11]

05 / KNOWLEDGE VS. SECRETS

可以带走技能；不意味着可以使用原公司的秘密

美国联邦商业秘密定义关注两点：所有者采取合理保密措施；信息因为不公开、无法通过正当途径轻易获得而具有独立经济价值。公司秘密可以是源代码、实验记录、模型权重、未公开训练方案、客户价格或数据组合；是否符合要件须有事实支持。[F06]

情形制度上的区别
化工工程师熟练使用传热关联式，凭经验发现设备异常公开知识、一般技能与独立判断通常可以继续使用。第九巡回法院示范指引明确区分个人技能与商业秘密。[F08]
把原公司的未公开催化剂配方、实验数据库复制给新公司可能涉及秘密侵占、保密和成果归属；能合法跳槽并不提供豁免。
没有拷贝文件，但凭记忆复现保密的工艺窗口“存在脑子里”不是免责任规则；记忆中的具体秘密也可能受保护。一般经验和特定秘密须区分。
PM 使用通用的需求访谈与路线图方法方法本身可能属于通用技能；不能据此复制原公司未公开客户、收入、发布计划和内部评估。
研究员加入竞争实验室，工作主题相近相近主题不等于已经侵占秘密。DTSA 的就业限制须基于受威胁侵占的证据，不能只因“他知道秘密”就阻止雇用。[F07]

上述为教学假设，不是在指控任何被提及的公司或员工。公开论文、开源许可证允许使用的代码、自己重新开展的合法研究，与原雇主的未公开资料，需要分别追踪来源。

公司之间约好“不挖人”，又是另一条法律线

如果两个竞争雇主约定不招聘对方员工，问题转向劳动市场反垄断。DOJ / FTC 的 2025 年指引指出，特定工资合谋和裸露的不挖人安排可能带来民事甚至刑事责任；真正附属于合法合作、必要且适度的限制要另行分析。员工签的客户禁止招揽条款，不应与企业之间的市场分割混为一谈。[F09]

2010 年，DOJ 与 Adobe、Apple、Google、Intel、Intuit、Pixar 就限制相互招揽员工的安排达成和解。这个例子说明，企业担心人才流失，并不能当然允许其共同封锁招聘市场；它不证明今天的 AI 公司有类似协议。[F10]

一个合理机制是：人才带着通用经验换团队，形成信任网络、共同语言和新公司；竞争者更易招人，员工也更有谈判选择。同时，雇主希望保护秘密与培训投入，可能使用保密、权限管理、股权留任和合法竞业安排。这里是机制分析，不是对硅谷的单因果证明。

原始研究给出更细的图景：Johnson、Lavetti 与 Lipsitz 的跨州研究发现，较强竞业可执行性伴随较低收入和流动；另一篇发明人研究发现，较强执行可能提高企业研发投入，却减少发明人流动与知识扩散。[E01] [E02] 费城联储的 Michigan 研究则未支持“执行竞业必然压低创业进入率”的简单说法，并观察到部分就业指标上升。样本、时期、政策变化与结果指标不同，不能把这些研究概括成一个没有条件的口号。[E03]

10 / TRANSFER THE KNOWLEDGE

把美国规则和你熟悉的概念对上

中国大陆是另一套制度。2025 年人社部指引强调适用人员、秘密接触、必要合理范围、经济补偿和最长两年；同年的司法解释也处理了未接触秘密、限制超出合理比例等情况。指引、法律和司法解释的法律层级不同。[C01] [C02]

常见直觉在美国研究时要改成的提问
离职后限制两年，公司要按月给钱吧？哪一州？是否要求补偿或其他对价？美国没有统一的“都补偿、最多两年”规则。
大公司都是 Delaware 注册，应该看 Delaware 法？注册地不等于雇佣法适用地；查工作地、居住地、合同选法和强制性保护。
高管和高级研究员肯定都能被限制？加州普通雇佣竞业不因高薪就当然有效；有些州的收入门槛只回答是否可能限制。
都叫 AI 公司，做相同岗位就是违约？先确认有效约定与受保护利益，再看具体业务、职责、时空范围与豁免。
合同不能执行，就完全不用管？另查保密、秘密、在职义务、IP、股权、返还与实际禁令；诉讼成本也可能影响决策。

12 / BILINGUAL GLOSSARY

中英术语：以后看到新闻就能对号入座

英文中文白话解释
Non-compete / NCA竞业限制／不竞争约定离职后不得加入竞争者或自行开展竞争业务；各州有效性不同。
Restrictive covenant限制性契约总称，可包括竞业、禁止招揽等；不能看到这个标题就认定整份协议无效。
NDA / Confidentiality保密协议／保密义务限制披露或使用特定信息。有效的保密义务通常可以在跳槽后延续；过宽条款也可能被审查。
Trade secret商业秘密信息须具有因秘密产生的经济价值，并采取合理保密措施；不是公司声称秘密就必然成立。
Misappropriation不当获取、使用或披露／侵占保护的是秘密，不是把员工拥有的一切知识都据为己有。记住秘密也不意味着有权拿去使用。
Non-solicitation禁止招揽通常针对客户或员工；必须看州法与具体文字，不自动等同可执行的 NDA。
No-poach / No-hire企业之间不挖人／不雇用协议竞争雇主之间限制招聘的约定，可能产生反垄断责任；不同于员工向雇主作出的承诺。
Garden leave花园假期／带薪通知期员工在通知期内仍受雇但离开业务；与离职后无薪禁业不同，各州也可能专门规制。
Consideration合同对价交换承诺所获得的法律价值。新工作、额外利益、继续雇用是否足够，要看州法和签约时点。
Legitimate business interest合法商业利益商业秘密、特定客户关系等可能被保护；单纯不希望竞争通常不够。
Choice of law / Forum法律选择／法院或仲裁地选哪州法、在哪里解决争议是两个问题；公司注册地也不必然决定适用法。
Void / Unenforceable / Voidable无效／不可执行／可撤销结论与救济不同，须读法条。签署、有效、可执行、实际能拿到禁令是不同层次。
Blue pencil / Reformation删改／司法限缩修订有些州允许删去或改窄过宽条款，有些州拒绝替雇主重写。
TRO / Injunction临时限制令／禁令争议可能先影响入职，再决定最终责任；是否有权申请与法院是否准许并不相同。
At-will employment任意雇佣通常可由双方终止雇用的基线，受法定例外约束；不自动消灭离职后的有效义务。
Vesting / Clawback股权归属／追索返还未归属股权流失、奖金返还可能影响跳槽成本；不一定是禁业，也不能保证所有设计合法。
IP assignment / Patent知识产权转让／专利成果归属、使用专利与能否换雇主是不同问题；不能用竞业失效推导专利可以自由使用。
Pre-training / Post-training预训练／后训练前者建立基础模型能力，后者通过指令、偏好、强化学习等改善可用性与行为。
Alignment / Safety / Security对齐／安全性／安全防护分别关注目标与行为、风险评估与防护、系统和信息的攻击防御；在公司内部会交叉但不完全等同。
PM / Engineering / GTM产品管理／工程／商业推广PM 决定用户问题和优先级；工程实现与运行；GTM 包括销售、市场、方案与客户成功。
PBC / Nonprofit / Board公益公司／非营利机构／董事会法律形式、控制与监督机制，不能从一个组织称谓直接推断产品线或员工汇报关系。
