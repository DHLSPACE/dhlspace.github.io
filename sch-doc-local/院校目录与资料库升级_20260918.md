# 院校目录与资料库升级 · 2026-09-18

继续使用当前文件夹中的本地助手。无需安装新的依赖、申请 API 或购买服务。已有来源、笔记和原件保留，`claude-gen` 原参考文件未改动。

## 使用顺序

1. 双击 `启动助手.cmd`，默认进入 **院校目录**。点击 ☆ 关注目标学校，使用地区、名称、985 / 研究所筛选；可以切换卡片与列表。
2. 点 **接入栏目**，优先返回本地已整理入口，不调用联网搜索。选择具体招生或学院通知栏目试抓，核对标题、日期、链接后确认保存。收藏不等于启用监控。
3. 在 **监控来源** 检查已接入栏目。在 **通知与变更 → 已发现的全部通知** 点“保存这条通知与附件”。
4. 到 **资料归档** 点“继续归档队列”。一次有多个网址时使用“批量粘贴网址”，每行一个，最多30个，同批归属同一来源。重复网址不会重复加入。失败会保留实际原因。
5. 资料库可按学校、PDF / Word / Excel / 图片 / 网页、标题或网址筛选，默认仅展示每个来源网址的最新保存版本。取消勾选可以看历史版本；筛选不会删除历史原件。
6. 勾选需要的版本，点“打包下载”。ZIP 按学校分目录，包括原始文件、文本、来源校验记录和总索引。每批最多200个版本、原件与文本等总计250MB；文件缺失会明确报错，不生成看似完整的缺件包。跨页已选项目会保留，点击“清空选择”可清除。

“已保存版本”是快照数量，正文和附件分别计数，不等于独立招生通知数。队列已加入不等于原件下载成功。

## 哪些院校已经覆盖

- **39所985高校**全部列入目录。校名、地区和候选招生入口参考 `claude-gen` 中的目录；985名单依据为[教育部原名单](https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html)。具体入口未逐站实测，均标为“参考入口，待试抓核验”。
- **115个中科院研究单位目录条目**：根据本轮实际取得的[中科院官方研究单位目录](https://www.cas.cn/zz/jg/ys/yj/)提取名称和官网，并保留原目录的星号说明。原页保存为 `research/cas-directory-20260918.html`。地理标签中无法从目录或单位名称确定的部分显示“京外（详见官网）”。
- 这是中科院目录覆盖，不是全国所有部委、行业和企业研究院所全集。机构列入目录也不表示其独立招生，须查当年简章。其他研究所可沿用“添加学校 / 网址”接入。
- 非985的211及其他高校不进入新目标目录；现有南昌大学本校资格来源和其他已保存来源仍在“监控来源”中，保留本科推免规则与原有历史。
- **目录收录、关注、接入来源、实际保存**分别统计。不把官网首页直接当可用通知爬虫，不把未验证单位显示为采集成功。

## 配色

右上角 **配色**：森林绿、海盐蓝、暮光紫、玫瑰粉、暖琥珀、石墨灰六组预设；支持自选主题色与渐变终点、开启/关闭渐变、三种渐变方向，以及舒展/紧凑密度。深色、浅色、跟随系统仍由“外观”选择。

配色、排列和密度保存在当前浏览器；清除网站数据后重置。关注名单保存在本机 SQLite，刷新和服务重启后保留，完整文件夹备份会包含它。当前 Git 同步只备份原有结构化表，不单独同步关注名单或浏览器偏好。

## 本地获取方式的选择

日常使用内置目录和官网静态栏目即可，无需新增API。沿用“设置每日检查.cmd”实现本机每日检查，电脑需要开机、联网并满足任务运行条件。网络或官网策略失败时，先在普通浏览器核对，再手动保存并导入原件。

原有 Brave Search API 保留为可选功能；本轮没有申请账号或配置密钥。它只帮助查找未知入口，不能替代受限官网的原件访问。
