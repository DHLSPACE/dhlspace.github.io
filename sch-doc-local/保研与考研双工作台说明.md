# 保研与考研双工作台

2026-10-07 · 本地改版；2026-10-11 · GitHub Pages 发布

页面顶部的「保研 / 考研」按钮可切换工作台，也支持键盘左右方向键。两个工作台分别保留当前栏目、院校搜索、筛选条件及资料、通知、笔记的筛选。院校关注名单与官方原件共用。

保研以本校推荐、夏令营、推免接收和材料归档为主线；考研以择校、初试、复试和调剂为主线。原来的监控、资料、笔记、政策、报名及手动快照继续使用。

院校卡片每页显示 12 所，提供省份、专业方向、院校类型、资料主题和排序。点击「进入院校」打开独立详情窗口，可跨年份搜索标题、院系和链接中的专业代码，组合年份、院系、文件类型、主题及「仅看已保存原件」。点击记录读取已有正文、下载原件、选择历史版本或查看来源与校验记录。未保存原件的记录显示通知索引和官网链接。

分区依据现有标题与栏目名称自动整理：明确推免、夏令营、推荐资格与直博的记录归保研；明确统考、初试、考试大纲、分数线、复试或调剂的记录归考研；推免复试仍归保研。招生目录、简章及无法确定路线的资料共用，并在详情中标记「通用资料」。同时明确出现统考和推免的标题共用。交换、放假、教学安排及本科实验班等明确无关通知从展示中排除，原始记录保留。标题分类并非逐篇正文核验，需结合原文确认适用范围。

新增笔记默认使用当前工作台的「保研准备 / 考研准备」类别，可在编辑器中改为更具体的统计口径；已有通用笔记仍共用。两个工作台共用同一套采集来源和手动备份。

「待收录」表示本机资料库没有匹配记录，不表示院校没有发布。当前目录沿用已有 85 所候选院校与研究所；没有新增未经核验的科目、分数线或招生人数。

性能改动包括院校与记录索引缓存、每页 12 张卡片、140 毫秒搜索防抖、最多 8 份正文请求缓存、只处理新增界面节点的图标转换，以及移除旧版重复列表渲染。监控卡片先显示院校摘要，展开时才生成来源与入口。本机空闲时每 15 秒检查轻量变更标识，有变更才读取全量资料；运行采集时改为每 3 秒检查，后台页面暂停检查。切换工作台不访问院校官网。

主要文件为 `static/admissions-model.js`、`static/admissions.js`、`static/admissions.css`。`research/prepare_admissions_ui.py` 只准备公开站静态资源与本机程序副本，不读取数据库、不复制新数据、不推送或部署；保留公开 `data.json` 原样。

验证命令：

```powershell
node tests/test_admissions_model.cjs
python -B -m unittest discover -s tests -p test_admissions_http.py
```

重启本机助手并刷新页面后生效。[公开工作台](https://162383.xyz/sch-doc/)通过 GitHub Pages 提供，使用已发布的资料快照；联网采集、API 密钥和个人笔记保留在本机。
