# 研招监控助手：中文使用说明

面向南昌大学化工相关专业本科生，重点入学年份 **2028**。本项目在独立子文件夹内完成；原参考说明另存为 `项目说明书_参考原文.md`，仅作为参考。

**2026-09-18 院校目录与资料库升级版**：默认进入39所985与115个中科院目录条目的院校目录，支持关注与筛选、六组配色和自选双色渐变、资料批量入队与原件ZIP打包。无需新增API或依赖。使用步骤和核验范围见 [院校目录与资料库升级说明](院校目录与资料库升级_20260918.md)。上一版本说明保留在 `本地升级说明.md`。

## 1. 你先做这两步

1. 双击 **启动助手.cmd**，浏览器会打开资料站。
2. 进入 **院校目录** 收藏并接入目标院校栏目；已有来源可直接点 **立即检查全部**。首批整理仍在 **信息笔记** 中。

首批检索和程序采集是两种证据：笔记是已核对网页后的人工整理；只有“资料归档”中的文件才是实际保存的原文。待核实数字没有被补成假数据。具体首批联网情况见 `验收记录.md`。

你的电脑已检测到 Python 3.13.2；程序只需要 Python 3.10+，**不需要 pip 安装，不需要付费软件、账号、API Key 或插件**。日常用现有 Edge / Chrome 浏览器即可，CSV 用 Excel / WPS 或记事本打开。

## 2. 窗口里有什么

| 页签 | 使用方法 |
| --- | --- |
| 概览与准备路线 | 看统计和第一批研究资料入口，按2028届准备 |
| 监控来源 | 添加、编辑、暂停学校网址；单独检查；补采历史 |
| 通知与变更 | 切换“变更记录”与“全部通知”；按学校、标题、年份搜索；标记已读 |
| 资料归档 | 读纯文本、下载原始文件、查看网址/时间/哈希值；看详情和附件失败状态 |
| 信息笔记 | 填学校、入学年份、口径、数值、来源、截止日期、核实状态；按学校年份筛选；CSV导出 |
| 设置与帮助 | 调整目标年份、每轮归档量、网络代理；导出全部数据；退出服务 |

监控源并不等于全国高校全集：首批集中覆盖南昌大学、华工、重大、过程工程所、大连化物所，并扩展北化、华理及政策入口。可以随时加学校。

## 3. 我不懂代码，怎么添加学校？

1. 点“监控来源 → 添加学校 / 网址”，输入校名、学院名或官网 URL。
2. 校名查询已整理的官网入口并尝试联网搜索；Bing 自动访问受限时，可在设置中配置自己的 Brave Search API 密钥。失败显示实际原因和浏览器搜索链接，不伪造结果。
3. URL 直接试抓；门户先选栏目。列表须识别至少两条重复结构的标题、有效日期和链接，才会出现确认按钮。
4. 核对真实预览，填写归属学校、来源类型和信息类别，勾选核对框，再点“确认并保存到项目”。未通过试抓不能加入。
5. 数据库与 `sources/custom.json` 同时保存；编辑、暂停、置顶也写入配置。JSON 保存解析规则，不生成可执行代码。
6. 默认每24小时检查、每轮一页，可在编辑中调整。首次正式采集建立历史基线，试抓通过不表示附件已经归档。

如果要监控某篇通知悄悄修改，类型选“单篇通知”；直接PDF链接选“单个附件”。若只想尽快保存一个链接，到“资料归档 → 粘贴网址归档”。它会进入队列，随后点击“继续归档队列”。

变更原网址会新建来源并暂停旧来源，以保留旧历史归属。初次导入的预设来源属于内置初始清单；暂停状态在重启后保留。

## 4. 自动保存的范围

- 保存列表的原始 HTML、文本和来源记录。首次建档标为历史基线，后续新增/标题日期修改单独列出；之前的条目不会因为翻页消失而删除。
- 发现的全部通知都进入条目库；标题含推免、招生、录取、复试、名额、夏令营、化工、化学等关键词的详情进入自动归档队列。这个规则仅用于节约下载量，不做AI重要性判断。
- 默认每源前2页；页面支持“下一页/下页”静态链接时自动翻页。可编辑页数，或点“补采历史”最多20页。只覆盖已扫描页，不保证把网站历史清空式爬完。
- 单轮默认处理25个详情/附件，剩余队列保留；可在设置调到200。新附件优先；检查队列可多次运行。失败项按来源间隔重试，不能通过不断点按钮强行突破网站限制。
- 保存静态链接、嵌入PDF阅读器中的静态文件地址、正文容器内的图片。支持PDF、Word、Excel等附件，单文件25MB上限。无法从脚本或认证系统发现的下载须手动补充。
- 已进入队列的详情和附件按来源间隔复查；同网址文件内容改变会保留新版本。HTML采用去掉浏览次数后的文本/附件链接比较；PDF等二进制使用SHA-256比较。
- 原始HTML不包含完整网站外部CSS/字体；读文本最稳定。图片/扫描PDF没有自动OCR，程序不会自动算名单人数或录取最低分。
- 遵守网站robots声明，不模拟登录、不识别验证码、不关闭HTTPS证书校验。空解析和跳转登录页按失败处理，成功基线不被覆盖。

## 5. 关掉窗口后，如何每天自动查？

双击 **设置每日检查.cmd**。它创建本用户的 Windows 任务 `GraduateAdmissionsMonitor`：每天09:00运行一次，到期来源才检查，结束后退出。无需管理员权限和密码，不安装常驻服务。

任务设置了“错过计划后尽快运行”。**电脑关机、睡眠时不保证执行；需要已登录Windows且联网，恢复可运行状态后才有机会补查。无法补回已在关机期间删除的公告。** 不要把“关窗口也能查”理解成“关电脑也能查”。

打开“开始 → 任务计划程序 → 任务计划程序库”，找到 `GraduateAdmissionsMonitor`：

1. 双击任务，打开“触发器”，编辑09:00或增加每日第二个时段。
2. 如果要每6小时运行，可以在“高级设置”设置每6小时重复、持续1天。
3. 同时把对应来源的检查间隔设置为6小时。任务启动频率与来源间隔共同决定实际检查频率。
4. 点击“运行”试跑，之后打开窗口看来源的“上次检查”。不要只看任务结果码；每个来源可能独立失败。

取消时双击 **取消每日检查.cmd**。移动整个项目后，重新双击设置脚本，使任务路径指向新位置。

本次交付提供设置脚本，是否已启用以 `验收记录.md` 为准。软件提醒在窗口内显示；不发送邮件、不使用Codex定时任务、不上传个人笔记。关闭浏览器不会停止服务器，可在“设置与帮助”点击“退出本地服务”。

## 6. 官网打不开或下载失败时

1. 点该来源“打开官网”，用普通浏览器验证。如果浏览器也打不开，优先检查当前校园网、VPN/代理，或稍后换网络。
2. 浏览器可读但程序TLS错误时，在设置中尝试使用你当前系统代理的地址。`direct`表示程序直连，空白表示系统设置。不要填写不明第三方代理。程序不会替你修改电脑全局网络。
3. HTTP 401/403/412、验证码、统一身份认证跳转都只提示手动处理；名单移除不能靠自动重试恢复。
4. 需要登录才能看到的内容由你在正常浏览器查看并下载，回到“资料归档 → 导入手动保存的文件”，填原网址后选择PDF、MHTML、图片、Word或Excel。其来源标记是“手动导入”。
5. 网页手工保存优先使用浏览器打印为PDF，或另存为单文件MHTML；若保存“完整网页”，请把HTML和配套文件夹一起保管，导入功能单次只导入一个文件。
6. 首批资料提到的官方名额原件尚未查到时，向本科教务或学院询问，收到后导入并填笔记。不要把搜索摘要或培训机构估计当官方证据。

## 7. 数据在哪里，如何备份？

```
研招监控助手/
  启动助手.cmd / 立即采集.cmd / 设置每日检查.cmd / 取消每日检查.cmd
  README.md / 先看这里_首批信息与准备路线.md / 验收记录.md
  app.py / collector.py / network.py / storage.py / launch.pyw / boot.ps1
  sources/           每站解析器与初始来源清单
  static/            中文浏览器界面
  data/
    records.sqlite3  主数据库：笔记、来源、状态、变更
    snapshots/       学校/抓取日期/原始文件、文本、来源说明
    manual/          手工导入原件
    exports/         可读的JSON、UTF-8 CSV
    last_check.log   命令行/计划任务的最近运行日志
  research/          开发时公开来源访问记录、首批研究数据
  tests/             独立的功能测试
```

完整备份：退出服务并等待计划采集结束，复制整个子文件夹到移动硬盘或自己选择的备份位置。JSON/CSV不包含附件原文件，不能单独代替完整备份。存档保留修订版本，不自动删除旧文件，磁盘占用会逐渐增加。

## 8. 备用启动命令

在本项目文件夹空白处按Shift+右键打开终端：

```powershell
python -B app.py
```

手动运行一次采集并退出：

```powershell
python -B app.py --check --force
```

只检查到期来源（计划任务使用）：

```powershell
python -B app.py --check
```

端口8765占用时：

```powershell
python -B app.py --port 8766
```

若另一台电脑没有Python，从 [Python官方Windows下载页](https://www.python.org/downloads/windows/) 安装3.10以上版本，勾选“Add python.exe to PATH”，重新打开启动脚本即可。无需安装 `research/browser-qa`，那只是交付测试工具。

## 9. 维护边界

该程序是有范围的公开网页保存工具，不是全国研招数据库。高校改版后可能要调整 `sources/` 中的解析函数。没有名单时不自动推算录取概率，未公开的教育部/学院推荐名额无法由爬虫变出来。收到官方材料后，把数字、年份、口径和原件一同补入，资料库会逐年积累。
