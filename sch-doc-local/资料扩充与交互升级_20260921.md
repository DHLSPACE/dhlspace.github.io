## API 的实际用途

- **Brave**：批量发现学校、研究生院、化学化工和相关院系入口；按学校、年份、推免／复试、文件类型继续搜索具体通知与附件。监控中的“联网补充”可直接搜索，再“选择并试抓”。搜索摘要只作线索，采集依据来自原站。
- **Gemini**：在“院校 → 年份 → 记录 → 正文”点击“AI 摘要与待办”，读取该份本机已存正文，提取摘要、院系、招生年份、截止日期、下一步与原文证据。已过期日期提示历史参考；缺失字段写待核实。正文最多发送前 16,000 字符，超过时界面说明。模型为实测可用的 `gemini-3.5-flash-lite`。
- 摘要单独保存到 `data/ai-summaries`，绑定原件 ID 与 SHA-256，不改写原文；再次查看相同版本读取缓存。网页正文中的指令作为不可信内容处理。
- 密钥仅保存在本机 SQLite 设置；状态接口返回“已配置”标志，代码、公开网页、JSON 导出和 Git 同步不包含密钥。
- **公开网站**展示已生成并随原件发布的 AI 辅助摘要，不向 Brave/Gemini 发请求，也不访问读者电脑上的服务。实时搜索、生成摘要和采集在本机程序使用。个人数据库笔记不发布，只沿用既有公开研究笔记种子。

接入依据：[Brave 官方搜索接口](https://api-dashboard.search.brave.com/api-reference/web/search/get)、[Brave 鉴权说明](https://api-dashboard.search.brave.com/documentation/guides/authentication)、[Gemini 官方 API](https://ai.google.dev/api)。两项 API 均完成真实请求测试；测试结果位于本机 `data/api_test_20260921.json`。

## 交互变化

1. 监控以大学／研究所为父卡片，默认收起；进入后按五层入口和已接入来源浏览。设置与操作收进子卡片，浅色／暗色共用现有主题和玻璃参数。
2. 每页可选 6／12／24／48 个单位，默认展开数单独选择；显示页数，支持直接跳页。每个来源的“采集页数”仍独立控制原站抓取深度。
3. 右下角悬浮导航随页面内容显示“收起”，并支持顶部、底部、上一级、下一级；院校阅读按院校／年份／记录层级返回，其他页面优先折叠或展开内容，再使用页面访问历史。
4. 手机顶部导航下滑淡出、上滑恢复；键盘焦点进入导航时恢复。左下角筛选按钮可上下拖动，位置记忆且限制在安全区域内，拖动不会误开筛选；轻点仍可打开。减少动态效果偏好会被遵守。
