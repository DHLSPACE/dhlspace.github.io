# Graduate Atlas 界面 v8 验收

## 功能

- 黑白皇冠 SVG、文字导航、三点更多菜单；统一图标与透明玻璃引导箭头。
- 桌面自适应卡片列数与手机紧凑布局，CAS 标签顶部对齐，长校名完整换行。
- 院校卡片内按“年份 → 记录 → 正文”逐级浏览；保留当前工作台、返回路径和筛选状态。
- 关键词、文件类型、院系、资料类别筛选；手机额外条件可折叠。
- 已保存正文、原件下载、来源记录与历史版本切换；索引记录和未知年份明确标注。
- 更新网站帮助与本机说明。现有主题、透明度、模糊和快照功能继续使用。

## 验证

- 40 项本机真实资料交互检查通过。

- 42 项 Python 回归测试通过，Vite 生产构建通过。
- 23 个发布资源与生产构建逐字节一致；发布清单记录 SHA256，并对页面引用附加资源哈希版本。
- 深色、浅色、手机截图经过检查；浏览器未报告运行错误。验收使用桌面 Edge 不同视口，非手机实机测试。
