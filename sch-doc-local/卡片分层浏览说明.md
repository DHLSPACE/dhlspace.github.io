# Graduate Atlas · 卡片分层浏览

1. 在“院校”找到学校或研究所，点击 **按年份浏览**。
2. 在原卡片中选择年份。数字年份倒序排列；跨年栏目和年份待核实资料独立显示。
3. 按关键词、文件类型、院系和资料类别筛选。手机先点击 **筛选**，显示额外条件。
4. 点开记录，在卡片内阅读已保存正文；点击路径中的年份返回列表，保留搜索、筛选和页码。
5. 下载原件、查看来源记录；有多个保存版本时可选择时间。点击 **收起** 返回普通卡片。

## 数据和显示范围

- 本机版本使用已有本地资料。网页版本使用已经发布的资料快照，不连接本机 API。
- 这次界面升级不执行新采集，不自动访问卡片中的官网链接；手动点击“官方来源”才打开原站。
- 历史文件按“来源 + 原网址”合并为一条记录，所有已保存版本仍可切换；原有资料库保留。
- “原件未保存”只有已有通知索引，不提供虚构正文；文本提取为空或失败时明确提示下载原件。
- 年份沿用已有分类与依据，不拿发布日期、抓取日期替代招生年份。资料类别由标题规则整理，需核对原文。
- 文件类型是辅助筛选，不额外增加必选层级；PDF、Word、Excel、图片、网页和其他格式分别标注。链接记录的类型仅由后缀识别。
- 正文以纯文本呈现，不执行存档中的脚本，也不自动嵌入外部网站；PDF、表格和图片的排版请看原件。

## 外观与操作

黑白皇冠使用项目自己的 SVG 图形，浅色为黑、深色为白；顶部与手机导航以文字为主，“...”打开更多栏目。现有 Liquid Glass 透明度、模糊、配色和减少动态效果设置继续可用。

## 发布范围

本轮向 `public/sch-doc/` 发布界面，向 `sch-doc-local/` 同步本机程序代码与说明。公开资料继续沿用此前已发布内容，不上传数据库、个人笔记、API 密钥或尚未公开的本机新采集文件。原始资料日期和界面构建日期分开记录。
