# 本地胶囊与快照操作指南

适用版本：2026-09-19 v7。双击 `启动助手.cmd`，打开 <http://127.0.0.1:8765>。本地助手负责采集和保存；公开网站仅提供已发布资料。网站操作说明见 `static/snapshot-guide.html`。

## 1. 最常用的操作

1. 进入“院校”，在左侧胶囊选择栏目 → 高校 / 研究所 → 地区 → 方向 → 具体单位 → 资料年份 → 用途。
2. 看完目录，在“动态”找到需要保留的通知，点“保存”。进入“资料”点“继续归档队列”，等到原件成功保存。
3. 在“资料”点“本地快照”，默认选择“公示 / 名单”，点一次“保存快照”。文件直接写入本机保存目录，不再通过浏览器下载弹窗。

“打开快照”只是查看范围和目录；**只有点击“保存快照”才创建 ZIP**。打开网页、刷新、查看状态、进入设置均不创建快照。原有“立即检查全部”、归档队列、你以前自行启用的 Windows 采集计划仍是独立功能，本次不新增任何定时打包任务。

## 2. 左侧胶囊怎样使用

- 顶部主导航、页面原筛选栏仍然存在。两套筛选读写同一组值。
- 点击某一项进入下一级；顶部小标签是已选条件，点击可修改；“返回”回到分类菜单。
- 逐级操作时，修改上级会清空后面的条件，避免选了新地区却仍被旧学校限制。选择“全部”可跳过该级。
- “−”缩成左下角 mini 托盘；点击托盘展开。键盘 Escape 也可收起。
- 设置 → 外观 → 悬浮胶囊与动效，可彻底关闭胶囊、切换 mini、关闭动画。选择保存在当前浏览器。
- 手机默认 mini，右下角托盘展开为底部筛选面板；“查看结果”收起并定位列表。桌面展开时正文给胶囊留出空间。手机底部提供“总览、院校、资料、动态、更多”导航。长分类列表支持搜索。
- 院校目录的年份 / 用途表示“本机已有对应资料的单位”，不是当年招生资格或官网资料覆盖保证。未采集的单位在选定资料年份后可能被排除。

各栏目的条件不同：

| 栏目 | 胶囊内容 |
| --- | --- |
| 院校 | 高校 / 研究所 / 关注、地区、方向、具体单位、资料年份、用途 |
| 资料 | 用途、年份、地区、学校、院系、公示名单、文件格式 |
| 政策 | 国家 / 地方政策、地区 |
| 动态 | 用途、年份、变更记录 / 全部通知 |
| 监控 | 用途、学校、来源类型、类别、采集状态 |
| 笔记 | 学校 |
| 总览、本校、报名、设置 | 提供前往院校、地区政策、资料与快照的入口 |

## 3. 玻璃和卡片效果

深浅模式、六套预设色及自定义配色继续沿用。胶囊使用同一组颜色和透明度。

- **轻量玻璃**：默认，CSS 背景模糊、饱和度、边缘高光和阴影。
- **通透玻璃**：高光更明显，仍保持最低底色以保证文字可读。
- **实色**：关闭新增胶囊和主要表面的模糊，适合节能和长时间阅读。
- 卡片在鼠标悬停时平滑抬升、轻微放大并改变阴影，移出时平滑恢复。系统要求“减少动画”时自动停用。

参考：[LiquidGlass 演示](https://liquid-glass.ybouane.com/)、[源码](https://github.com/ybouane/liquidglass)、[package.json](https://github.com/ybouane/liquidglass/blob/main/package.json)。检查时包声明 MIT，使用 WebGL 和 html-to-image。其官方说明指出 DOM 栅格化较昂贵、每实例独立 WebGL 上下文，且有根元素及字体等约束。

**本版参考其视觉语言，自行实现轻量 CSS 效果，没有安装或复制该库，也不声称实现了同等真实光学折射。** 无运行时 CDN、第三方遥测、新增 GPU 渲染循环。未对参考库作完整安全审计，也未测得它在本机长列表上的性能，暂不把它作为默认依赖。轻量效果仍受显卡、浏览器和模糊强度影响；卡顿时用实色并关闭动效。

## 4. 保存目录和文件名

默认位置是本项目下单独的 `snapshot` 文件夹：

```text
研招监控助手/
  snapshot/
    2026-09-18.zip
    2026-09-18_01.zip
```

同一天多次保存自动加序号，**不覆盖旧包**，日期采用电脑本地日期。

- 在快照窗口点“更换文件夹…”，或设置 → 手动快照 → “选择文件夹…”，使用系统目录选择器。
- 如果目录选择器不可用，可以直接填写绝对路径（例如 `D:\研招留底`），点击“保存路径”。
- 取消目录选择不会改变当前目录；“恢复默认”回到项目的 `snapshot`。
- 路径设置仅选择将来的输出位置，不移动、改名或删除旧快照。
- 打包进行中不能改路径或正常退出服务；完成后会显示完整路径、体积和问题数量。

## 5. 四种打包范围

| 选项 | 包含什么 |
| --- | --- |
| 公示 / 名单 | 从已保存资料标题识别公示、拟录取、录取名单、复试名单、入围名单等；不把栏目首页混入名单 |
| 全部已保存资料 | 全库原件，包含旧资料；异常响应页不算成功资料 |
| 资料页当前筛选 | 当前条件匹配的所有分页，不局限于眼前 60 条 |
| 勾选的资料 | 你明确勾选的版本，可跨页选择 |

默认“每个来源网址只取最新版本”。需要对照公示更正时取消该选项，可保存历史版本。勾选范围里的“最新”指选中版本中的最新版本。

ZIP 使用免费、开源的 Python 标准库 `zipfile`，无需额外安装压缩或 AI 服务；按块写出，不把全部原件装进内存。单包原件读入上限 4 GiB，超限时终止并清理本次未完成 ZIP，按学校 / 年份分批即可。

## 6. ZIP 里面是什么

```text
日期.zip
├ 学校名称/
│ └ 招生年份/
│   └ 用途（目标 / 本校 / 政策）/
│     └ 院系/
│       └ 通知标题__版本编号/
│         ├ 原件.pdf（或 Word、Excel、图片等）
│         ├ 正文.txt
│         └ 来源.json
├ 分类目录.csv
├ 来源索引.json
├ 未完成与校验问题.json
└ 阅读说明.txt
```

- 目录明确写学校、院系和标题；过长名称被截短，唯一版本编号防止同名混淆。完整标题仍在索引中。
- 分类沿用页面的本地规则：来源学校、院系、标题年份、用途。无法确定的招生年份是“待核实”，栏目快照是“跨年”；不拿抓取时间代替招生年份。
- 原件保持字节不变；每个导出文件有 SHA256。原件哈希与入库值不一致时保留实际文件并明确警告。
- HTML 以 `.html.download.txt` 等文本扩展名保存，防止误打开执行原站脚本；可用文本编辑器看源码，阅读正文用 `正文.txt`。
- 目录表不是来源事实，分类仍需人工核对。CSV 对公式开头文字进行转义，避免 Excel 将其作为公式运行。
- 缺失的文件不伪造、不伪装成功；其余可读文件仍打包，结果显示问题数。即使 ZIP 生成，也应先看问题清单。
- 待归档清单是全库资源参考，公示模式仅列标题匹配项；不表示全部待归档项都属于你选中的学校或本次范围。
- 本包是资料快照，**不是完整应用备份**。迁移或恢复全部笔记、来源与历史状态，应另备份整个项目；勿将数据库、名单或私密配置推送到公开仓库。

## 7. 公示期快到或官网撤下怎么办

不要等到打包当天才第一次打开通知。ZIP 只打包已经成功保存在本机的材料，不能把链接变成尚未抓到的原件。

1. “动态”找到通知，点“保存”，到“资料”点“继续归档队列”。
2. 检查正文和附件是否分别成功；“有通知条目”不等于“附件已保存”。
3. 官网验证码、登录、反爬或网络失败时，用浏览器手动下载 PDF/Word/图片，或打印为 PDF；再通过“导入手动保存的文件”指定学校来源和原网址。
4. 选择“公示 / 名单”，核对数量后保存快照。有不符合标题关键词的名单，直接勾选或通过学校筛选打包。
5. 看保存路径，打开 ZIP 的分类目录和问题清单；对特别重要的名单，打开对应 PDF 人工核对页数、标题、学校及名单内容。

系统目前不自动推断公示结束日，不做名单 OCR，也不证明截图/PDF内容完整。中科院和高校都可能改版、撤稿或附件失效，不能假定某一类机构永久保留。已经下架且从未保存的原件，系统无法凭标题恢复。

## 8. AI 是可选的后续能力

当前实现不调用 AI，没有暗中上传名单、扣费或下载模型。免费本地规则已能完成按学校、年份、用途、院系分包。

AI/OCR 可以在将来辅助扫描文件识别、建议分类或提取待核对截止日期；需要另行评估本地模型硬件、中文识别准确率、模型许可与隐私。本次没有把尚未接入的 AI 做成可用开关。任何 AI 结果应单独标为“推测 / 待核对”，不能覆盖原件或原始记录。

## 9. 常见情况

| 情况 | 操作 |
| --- | --- |
| 公示匹配数为 0 | 确认原件已经成功入库；试“全部已保存资料”或手动勾选。标题规则会漏检 |
| 筛选后目录空了 | 清空筛选；年份/用途只依据已有资料，未采集不等于不招生 |
| 显示快照接口不可用 | 退出旧的本地服务，重新双击启动助手，刷新网页 |
| 更换目录无弹窗 | 看窗口是否在后台；取消后也可用设置里的绝对路径 |
| 无写入权限或磁盘满 | 更换到有权限、空间充足的目录再手动保存 |
| 长路径无法解压 | 解压到较短路径，例如 `D:\研招`；索引中保留完整学校和标题 |
| ZIP 有校验警告 | 不把该文件当作已核验原件；对照原网址、来源记录或自己的备份 |
| 中途强制关闭进程 | 本次 ZIP 可能不完整，人工检查后处理；重新打包生成新序号，不覆盖旧包 |
| 想清理旧快照 | 本版不自动删除。在资源管理器核对日期和内容后手动整理 |

## 10. 实现与证据边界

新增 `snapshot_export.py`、`static/local-tools.js`、`static/local-tools.css`；在现有服务接入受本机 token 和同源检查保护的快照接口。默认仍只监听 127.0.0.1。新增打包过程不联网、不执行原件内容，索引不包含代理或搜索密钥。

目录按规则归类，原件字节与推导信息分别保留；具体单元测试、浏览器检查及限制见 `research/胶囊快照验收.md`。未对所有官方资料逐页人工验真，未宣称参考 WebGL 库经过完整安全审计。
